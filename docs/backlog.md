## 실물 도서관

- **운영 기관으로 묶는 테이블** (예: 세종시립도서관 = 전자도서관 일반 + 구독형 + 실물 분관들): 사이클 02에서는 자격을 전자도서관(이용 단위)마다 두고 기관 테이블은 두지 않기로 함. 실물 도서관 사이클을 시작할 때 **반드시 다시 검토**: 기관 테이블을 둘지, 이용 단위가 기관을 가리킬지, 기관 단위 표시(같은 도서관 묶어 보기)가 필요한지 — 사용자, 2026-09-28 (사이클 02 design-delta, `docs/cycles/02-library-expansion/design-delta.md`)

- 도서관 정보나루 `bookExist` API: 도서관별 소장·대출 가능 여부 제공, 전날 기준 (https://www.data4library.kr/apiUtilization, 확인 2026-09-27)
