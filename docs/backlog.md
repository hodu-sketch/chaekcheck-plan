# Backlog

아직 어느 사이클에도 들어가지 않은 아이디어만 모은 목록입니다. 사이클을 시작할 때 여기서 고르고, 고른 항목은 지운 뒤 사이클 `scope.md`에 적습니다.

- 한 줄 요약 뒤의 **원문** 링크는 [`backlog-archive.md`](backlog-archive.md)의 원래 글(출처·사용자 발언·배경)로 갑니다.
- 끝났거나 버린 항목은 `backlog-archive.md`에만 있습니다(2026-11-05 정리).
- `[확인 필요]`: 이미 했는지 확실하지 않은 항목. 사이클을 고를 때 dev 코드나 회고로 확인합니다.
- 새 아이디어는 알맞은 주제 아래에 한 줄로 더합니다(내용, 출처, 날짜).
