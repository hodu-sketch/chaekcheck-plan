수집기가 이동진 추천도서 목록도 모으게 합니다.
정할 것 4개를 골라 주세요.

범위 결정 8개는 모두 반영했습니다. #2에 "수집 서비스가 이것도 같이 하도록 했으면 좋겠어"라고 적어 주셔서, 도서관 전자책 목록을 모으는 dev 수집기가 한 달에 한 번 이동진 추천도서의 새 책을 찾아 목록 파일의 새 줄을 만들게 합니다. 서울대 100선은 2005년 목록이라 바뀌지 않고, 사서 추천도서는 이미 서버가 주 1회 받으므로 수집기 일은 이동진 추천도서 하나입니다.

먼저 알아야 할 것:
유튜브 페이지는 프로그램으로 읽으면 안 됩니다

유튜브 약관은 로봇·봇·스크래퍼 같은 자동화된 수단으로 접근하는 것을 막습니다. 예외는 robots.txt를 따르는 공개 검색엔진과 유튜브의 사전 서면 승인뿐입니다. 그래서 수집기는 공식 YouTube Data API로 읽어야 합니다.

이번 조사(44권)는 이 세션이 브라우저로 재생목록 페이지를 한 번 열어 읽은 것입니다. 매달 프로그램이 같은 일을 하면 약관에 걸립니다.

YouTube Data API는 하루 10,000단위를 무료로 주고, 재생목록 한 번 읽기는 1단위입니다. 한 달에 몇 단위면 됩니다. 대신 API로 받은 공개 영상 정보(제목·설명)는 30일까지만 저장하고, 그 뒤에는 지우거나 새로 받아야 합니다.

근거: YouTube 서비스 약관 https://www.youtube.com/t/terms (발효 2022-01-05), YouTube Data API 할당량 https://developers.google.com/youtube/v3/determine_quota_cost , YouTube API 개발자 정책 III.E.4 https://developers.google.com/youtube/terms/developer-policies (모두 2026-10-15 확인).

파란 칸은 이미 정한 것(목록 파일, 수집기가 맡음), 노란 칸은 사람이 하는 일입니다.

1유튜브는 공식 API로 읽기

[안] 수집기가 YouTube Data API로 「이달의 책」 재생목록(과 연말 올해의 책 영상)을 한 달에 한 번 읽어, 목록 파일에 없는 새 영상을 찾습니다. API 키는 다른 비밀 값처럼 dev의 .env에 둡니다.

예: 2026년 11월 수집 때 재생목록에 새 영상이 하나 보이면, 그 영상 주소와 올린 날로 "2026-11" 줄 후보를 만듭니다.

다른 선택: 수집기 대신 사람이 매달 재생목록을 보고 줄을 더하기. API 키가 필요 없지만 "수집 서비스가 같이" 하자는 말씀과 다릅니다. 페이지를 프로그램으로 읽는 방법은 약관 때문에 권하지 않습니다.

2책 이름에서 책 정보 찾기

[안] 영상 제목과 설명란에서 [ ], 《 》, 〈 〉, 『 』 안 글자나 🔖 표시 뒤 글자를 책 이름으로 뽑고, 국립중앙도서관 ISBN 서지 API로 ISBN·저자·출판사를 찾습니다. 책 이름이 없거나 여러 책이 맞으면 "확인 필요"로 남깁니다.

지금까지 31개 영상(재생목록 29개, 2023년 연말 2개) 가운데 제목·설명란에 책 이름이 없던 영상이 하나(2026년 2월) 있었습니다. 그런 달은 사람이 책 이름을 적습니다. 표지도 같은 ISBN 서지 API에서 받으므로(범위 결정 #5) 출처가 하나로 모입니다.

다른 선택: 알라딘 분류 페이지에서 찾기. 이번 조사에서는 썼지만, 프로그램으로 읽는 것은 알라딘 이용 조건을 확인하기 전에는 하지 않습니다.

3분야와 최종 확인은 사람이

[안] 수집기는 새 줄 후보만 만들고, 분야(9개 중 하나)를 넣고 줄을 확정하는 것은 사람이 합니다. 한 달에 한 권 안팎이라 몇 분이면 됩니다.

분야는 이번에 알라딘 분류의 첫 경로로 나눴습니다. 국립중앙도서관 API가 분야로 쓸 만한 값(한국십진분류 등)을 주는지는 아직 확인하지 못해, 그 전까지는 사람이 정합니다.

다른 선택: 수집기가 분야까지 자동으로 넣고 바로 확정. 손이 덜 가지만 틀린 분야가 화면에 바로 나올 수 있습니다.

4유튜브 정보는 30일 규칙에 맞게

[안] 목록 파일에는 영상 주소(영상 ID)와 추천 연·월만 남기고, 영상 제목·설명은 저장하지 않습니다. 수집기가 한 달에 한 번 다시 읽으므로 30일 안에 새로 받는 셈입니다.

책 이름·저자·ISBN은 국립중앙도서관에서 받은 책 정보라 유튜브 30일 규칙과 상관없습니다. 영상 ID를 오래 저장해도 되는지는 정책에서 확인하지 못해, 개발 전에 다시 봅니다.

다른 선택: 영상 제목까지 저장해 책 창에 보이기. 30일마다 새로 받아야 하고, 영상 설명을 옮기지 않기로 한 결정과도 멀어집니다.
