추천도서 명세를 썼습니다.
정할 것 13개를 골라 주세요.

범위에서 정한 14가지는 그대로 옮겼고, 사서추천도서(사이클 14)에서 정한 화면 규칙은 세 목록에 똑같이 씁니다. 아래 13개는 명세를 쓰며 새로 나온 작은 규칙입니다. 판정은 설계 진행 가능입니다. 국립중앙도서관 ISBN 서지 API 시험(키·분류·표지)은 개발 전에, 표지 이용 조건과 서울대 100선 목록 게시 여부는 배포 전에 확인합니다.

명세를 쓰며 새로 확인한 것

국립중앙도서관 ISBN 서지 API는 표지 그림 주소와 한국십진분류(KDC)를 줍니다. 수집기의 자동 분야를 KDC로 정할 수 있습니다.

  • ISBN 서지 API 결과 항목에 표지(TITLE_URL), 한국십진분류(KDC), ISBN, 저자, 발행처가 있고, ISBN·제목·저자로 찾을 수 있습니다.
  • 국립중앙도서관 Open API는 회원가입 → 인증키 신청 → 담당자 승인 순서입니다. 사서추천도서 키로 ISBN 서지 API도 부를 수 있는지는 시험해 봐야 압니다.
  • 유튜브 API 정책은 유튜브 정보를 보여 주는 서비스가 YouTube 서비스 약관 링크를 보이라고 합니다(III.A.1).

근거: 국립중앙도서관 ISBN 서지정보 https://www.nl.go.kr/NL/contents/N31101030500.do , Open API 이용안내 https://www.nl.go.kr/NL/contents/N31101010000.do , YouTube API 개발자 정책 https://developers.google.com/youtube/terms/developer-policies (2026-10-15 확인).

머리말 메뉴

메뉴를 여닫는 세부 두 가지입니다.

1PC에서 열고 닫는 때,
큰 메뉴 글자를 누르면

[안] 마우스를 0.5초 멈추면 열고, 메뉴 밖으로 나간 뒤 0.5초 지나면 닫습니다. 큰 메뉴 글자를 누르면 펼친 칸의 첫 항목으로 갑니다(「추천도서」 → 이동진 추천도서, 「마이페이지」 → 내 도서관 관리).

예: 마우스로 머리말을 스치고 지나가면 메뉴가 열리지 않습니다. 사용성 연구 회사 NN/g가 메가 메뉴에 권하는 값입니다.

다른 선택: 올리자마자 열고 바로 닫기. 빠르지만 스치기만 해도 메뉴가 깜빡입니다.

2로그인 전 「내 도서관 관리」

[안] 로그인하지 않았을 때도 메뉴에 보이고, 누르면 지금 내 도서관 관리 화면이 로그인 전에 하는 대로 동작합니다. 지금 동작은 설계 때 dev 코드로 확인합니다.

다른 선택: 로그인 전에는 「마이페이지」 칸을 숨김. 메뉴가 짧아지지만 로그인하면 메뉴가 바뀌어 헷갈릴 수 있습니다.

세 목록 공통

우리 책을 못 찾은 책, 주소와 이용 기록입니다.

3우리 전자책을 못 찾은 책도 보이기

[안] 서울대 100선 13권, 이동진 8권처럼 모은 도서관에 전자책이 없는 책도 목록에 넣고 흐린 제목 글자 표지로 보입니다. 누르면 사서추천도서처럼 희망도서 안내가 열립니다.

예: 서울대 100선 한국문학의 「광장」은 흐리게 보이고, 누르면 "이용하는 전자도서관 사이트에서 희망도서로 신청해 보세요" 안내가 뜹니다.

다른 선택: 못 찾은 책은 빼기. 화면은 깔끔하지만 서울대 100선이 87권이 되어 "100선"과 맞지 않습니다.

4주소와 이용 기록

[안] 사서 추천도서는 지금 주소 /picks 그대로, 이동진 추천도서와 서울대 100선은 각자 주소를 가집니다(이름은 설계). 이용 기록(사이클 15)의 분야 보기·책 창 열기를 새 두 목록에도 남기고, 어느 목록인지 함께 적습니다.

주소가 따로 있으면 즐겨찾기나 뒤로 가기가 목록마다 됩니다.

다른 선택: 이용 기록은 사서추천도서만. 새 목록이 얼마나 쓰이는지 알 수 없습니다.

목록 파일

서울대 100선의 애매한 판, 이동진 목록 범위, 분야 기준입니다.

5서울대 100선 애매한 판 5권은 직접 고정

[안] 규칙으로 거르지 못한 5권(연암집, 춘향전, 실천이성비판, 페더랄리스트, 미국의 민주주의)은 목록 파일에 판(책 이름·저자·출판사)을 직접 적어 고정합니다.

예: 「춘향전」은 규칙대로면 어린이책 출판사 판이 뽑히는데, 파일에 적은 판으로 맞춥니다. 고를 판은 설계 때 후보를 보여 드립니다.

다른 선택: 규칙 결과 그대로. 손이 안 가지만 줄인 판이나 어린이 판이 나올 수 있습니다.

6이동진 목록 범위와 겹치는 책

[안] 조사한 44권 모두(2023년 12월 올해의 책 7권 포함)와 앞으로의 책을 넣습니다. 이달의 책과 올해의 책에 같은 책이 나오면 한 번만, 연·월은 이달의 책 달입니다. 한 영상의 여러 책(예소연 4편)은 따로 같은 달로 넣고, 실린 책을 모르는 「마음 깊은 숨」은 찾을 때까지 뺍니다.

예: 「대온실 수리 보고서」는 2024년 11월 이달의 책이자 2024 올해의 책이라 "24.11" 한 번만 보입니다.

다른 선택: 이달의 책만(2024년 1월부터). 33권으로 줄고, 올해의 책에만 나온 11권(2023년 7권, 2024·2025년 각 2권)이 빠집니다.

7지금 44권의 분야도 KDC로 다시 매기기

[안] 수집기가 앞으로 KDC로 분야를 정하므로, 지금 44권(알라딘 분류로 나눔)도 같은 KDC 대응표로 다시 매겨 기준을 하나로 합니다. KDC는 API로만 얻어서, 개발 때 시험한 뒤 분야가 달라지는 책을 보여 드리고 확정합니다.

다른 선택: 지금 44권은 알라딘 분류 그대로 두고 새 책만 KDC. 손이 안 가지만 같은 분야 안에 기준이 둘이 됩니다.

9수집기 돌리는 때

[안] 사람이 다른 수집을 돌릴 때, 지난 이동진 확인에서 한 달 넘게 지났으면 함께 합니다. 실패하면(키 거절·할당량·응답 없음) 목록 파일을 건드리지 않고 기록에 한 줄 남깁니다.

지금 수집기는 사람이 돌리는 프로그램이라 따로 예약 작업을 두지 않습니다.

다른 선택: 매달 1일 자동 예약. 잊지 않지만 수집기를 늘 켜 둘 곳(서버)이 필요합니다.

10새 줄이 화면에 나오는 때

[안] 수집기가 목록 파일에 새 줄을 더하면, 다음 서버 시작 때 화면에 나옵니다. 파일을 운영 서버로 옮기는 길은 설계에서 정합니다.

다른 선택: 서버를 다시 켜지 않아도 하루 한 번 파일을 다시 읽기. 바로 보이지만 서버에 일이 하나 늘어납니다.

12이동진 책 창 세부

[안] 올해의 책이면 추천 줄 끝에 " · 2025 올해의 책"을 붙입니다. [영상 보기]는 유튜브를 새 탭으로 열고, 전자책이 없는 책의 희망도서 안내에도 [영상 보기]를 둡니다.

예: "이동진 평론가가 「파이아키아」 영상에서 추천 (2025년 5월) · 2025 올해의 책"

다른 선택: [영상 보기]는 전자책이 있는 책의 창에만. 없는 책을 누른 사람은 영상으로 갈 길이 없습니다.

13상태 문구

[안] 목록이 아직 없으면 "아직 이동진 추천도서를 준비하고 있어요", 화면 요청이 실패하면 "이동진 추천도서를 불러오지 못했어요. 잠시 뒤에 다시 해 주세요." 서울대 100선도 같은 꼴입니다.

사서추천도서(사이클 14)에서 정한 문구와 같은 꼴이라, 세 목록이 같은 말투가 됩니다.

다른 선택: 세 목록 공통 문구 하나("추천도서를 불러오지 못했어요"). 짧지만 어느 목록인지 안 보입니다.
