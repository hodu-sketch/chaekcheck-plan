정할 것 13개를 골라 주세요.

범위에서 정한 14가지는 그대로 옮겼고, 사서추천도서(사이클 14)에서 정한 화면 규칙은 세 목록에 똑같이 씁니다. 아래 13개는 명세를 쓰며 새로 나온 작은 규칙입니다. 판정은 설계 진행 가능입니다. 국립중앙도서관 ISBN 서지 API 시험(키·분류·표지)은 개발 전에, 표지 이용 조건과 서울대 100선 목록 게시 여부는 배포 전에 확인합니다.

명세를 쓰며 새로 확인한 것

국립중앙도서관 ISBN 서지 API는 표지 그림 주소와 한국십진분류(KDC)를 줍니다. 수집기의 자동 분야를 KDC로 정할 수 있습니다.

  • ISBN 서지 API 결과 항목에 표지(TITLE_URL), 한국십진분류(KDC), ISBN, 저자, 발행처가 있고, ISBN·제목·저자로 찾을 수 있습니다.
  • 국립중앙도서관 Open API는 회원가입 → 인증키 신청 → 담당자 승인 순서입니다. 사서추천도서 키로 ISBN 서지 API도 부를 수 있는지는 시험해 봐야 압니다.
  • 유튜브 API 정책은 유튜브 정보를 보여 주는 서비스가 YouTube 서비스 약관 링크를 보이라고 합니다(III.A.1).

6이동진 목록 범위와 겹치는 책

[안] 조사한 44권 모두(2023년 12월 올해의 책 7권 포함)와 앞으로의 책을 넣습니다. 이달의 책과 올해의 책에 같은 책이 나오면 한 번만, 연·월은 이달의 책 달입니다. 한 영상의 여러 책(예소연 4편)은 따로 같은 달로 넣고, 실린 책을 모르는 「마음 깊은 숨」은 찾을 때까지 뺍니다.

예: 「대온실 수리 보고서」는 2024년 11월 이달의 책이자 2024 올해의 책이라 "24.11" 한 번만 보입니다.

다른 선택: 이달의 책만(2024년 1월부터). 33권으로 줄고, 올해의 책에만 나온 11권(2023년 7권, 2024·2025년 각 2권)이 빠집니다.

7지금 44권의 분야도 KDC로 다시 매기기

[안] 수집기가 앞으로 KDC로 분야를 정하므로, 지금 44권(알라딘 분류로 나눔)도 같은 KDC 대응표로 다시 매겨 기준을 하나로 합니다. KDC는 API로만 얻어서, 개발 때 시험한 뒤 분야가 달라지는 책을 보여 드리고 확정합니다.

다른 선택: 지금 44권은 알라딘 분류 그대로 두고 새 책만 KDC. 손이 안 가지만 같은 분야 안에 기준이 둘이 됩니다.

답: KDC가 무엇인가

KDC(한국십진분류법)는 도서관이 책을 주제별로 꽂으려고 붙이는 분류 번호입니다. 한국도서관협회가 만들고, 모든 주제를 000부터 900까지 큰 갈래 10개로 나눈 뒤 다시 10개씩 잘게 나눕니다.

10새 줄이 화면에 나오는 때

[안] 수집기가 목록 파일에 새 줄을 더하면, 다음 서버 시작 때 화면에 나옵니다. 파일을 운영 서버로 옮기는 길은 설계에서 정합니다.

다른 선택: 서버를 다시 켜지 않아도 하루 한 번 파일을 다시 읽기. 바로 보이지만 서버에 일이 하나 늘어납니다.

답: 목록 파일과 DB는 어떤 관계인가

맞습니다. 화면은 DB만 읽습니다. 목록 파일은 새 책을 DB에 넣기 위한 입력이고, 언제 어떻게 DB로 옮기느냐가 10번입니다.

③ 운영 서버가 매일 파일 다시 읽기목록 파일을 운영 서버 폴더에 올리면 하루 한 번 읽어 DB에 넣음재시작 없음파일을 운영 서버에 올리는 길이 새로 필요

전자책 목록이 이미 ② 길(ADR-0078: 내 PC에서 가져오기 파일을 만들어 운영에 반영)로 들어가고, 9번에서 "수집기를 돌릴 때 함께"를 승인하셨으니 ②를 권합니다. 이렇게 하면 범위 #2의 "서버가 켜질 때 DB에 넣음"이 "가져오기 반영 때 DB에 넣음"으로 바뀝니다. ②로 하시려면 10번에 기타로 "②"라고 적어 주세요.

더 물으신 것: 추천도서는 가동할 때 한 번 읽고 DB는 안 들여다보나

아닙니다. 지금 사서추천도서는 서버가 켜질 때, 그 뒤 10분마다, 목록을 새로 받은 직후에 DB를 다시 읽어 메모리에 담아 둡니다. 화면 요청은 그 메모리에서 바로 답합니다.

그래서 어느 길로든 DB에 새 줄이 들어가기만 하면 10분 안에 화면에 나옵니다. 서버를 다시 켜야 하는 것은 ① 길(파일을 서버가 켜질 때만 읽음)뿐이고, ② 길(가져오기 반영 때 DB에 넣음)이면 재시작 없이 다음 10분 안에 보입니다. 그래서 ②를 권합니다.

12이동진 책 창 세부

[안] 올해의 책이면 추천 줄 끝에 " · 2025 올해의 책"을 붙입니다. [영상 보기]는 유튜브를 새 탭으로 열고, 전자책이 없는 책의 희망도서 안내에도 [영상 보기]를 둡니다.

예: "이동진 평론가가 「파이아키아」 영상에서 추천 (2025년 5월) · 2025 올해의 책"

다른 선택: [영상 보기]는 전자책이 있는 책의 창에만. 없는 책을 누른 사람은 영상으로 갈 길이 없습니다.
