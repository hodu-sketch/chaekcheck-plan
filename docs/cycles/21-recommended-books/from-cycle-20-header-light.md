# 사이클 20 → 사이클 21: 머리말에 들어가는 조회 상태 점 (메뉴 설계 때 자리 맞추기)

- 쓴 날: 2026-10-15, 사이클 20 세션. 사이클 21이 머리말을 정보나루식 큰 메뉴로 바꾸므로(21 scope "머리말 메뉴 방식" [확정]), 20이 머리말에 더하는 것을 알려 둠. 자세한 것은 `../20-lookup-status-and-extension/flow.md` H절, `spec.md` R1·R5·R10·R14
- 20이 머리말에 더하는 것 [확정] (2026-10-15):
  1. **조회 상태 점 + 글** — 「로그인/로그아웃」 바로 왼쪽. 초록 「조회 원활」 / 노랑 「조회 붐빔」 / 빨강 「조회 혼잡」 / 회색 「상태 모름」 / 확장 모드 파란 「내 브라우저에서 조회 중」. 바뀔 때 움직임 없음. 첫 응답 전에는 자리만 비움
  2. 폰(640px 이하): 점만, 누르면 말풍선(팝오버)으로 글 + 「지금 찾는 사람이 많아 검색이 거절될 수 있어요」. 21이 폰 오른쪽 위에 메뉴 버튼을 두면 **점은 그 메뉴 버튼 왼쪽** (20 쪽 제안, 21 설계에서 확정)
  3. **머리말은 모든 화면에서 같음** — 약관(`/terms`)·처리방침(`/privacy`)에서도 메뉴·점·로그인 보임 (사용자: "그것들도 같아야지", 2026-10-15). dev `AppLayout.tsx`의 `legal` 분기를 없앰. 21이 머리말을 다시 짤 때 이 예외를 되살리지 않도록
- 순서: 20과 21 어느 쪽이 먼저 dev에 가든, 뒤에 가는 쪽이 머리말 코드에 앞쪽 것을 맞춤. 점의 자리 규칙("로그인 왼쪽", 폰은 메뉴 버튼 왼쪽)만 지키면 됨

## 바뀜 (2026-10-17)

사이클 21이 폰 ☰를 없애고 머리말 줄을 누르면 메뉴가 열리게 바꿔서(사용자 결정), 점과 메뉴가 부딪히지 않는 다섯 규칙을 정함: [확정] (사용자 승인, 2026-10-17, 사이클 21 dev 결과 검토 #9; 결정 페이지 `docs/cycles/21-recommended-books/easy/2026-10-17-dev-result-review.html`). 원문은 `../20-lookup-status-and-extension/design-delta.md` "머리말 점과 폰 '줄 누르면 메뉴'" 줄. ① 점(44px)은 오른쪽 끝 묶음 안 — 눌러도 메뉴 안 열림 ② 메뉴와 말풍선은 동시에 안 열림 ③ Esc는 하나만 닫음 ④ 320px 한 줄 확인 ⑤ "폰은 ☰ 왼쪽" → "「로그인」 바로 왼쪽, ☰ 없음". 사이클 21 쪽 명세 R1-5·R1-6, ADR-0127의 ☰ 문구도 이에 맞춰 고칠 것(사이클 21 마무리 때)
