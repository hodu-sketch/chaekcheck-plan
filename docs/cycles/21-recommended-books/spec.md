- 바탕: 사이클 14 사서추천도서 명세 `../14-librarian-picks/spec.md` (아래 "C14"). 적지 않은 규칙은 C14 그대로이고, 세 목록에 똑같이 씀

## 사용자 이야기

- 책을 고르려는 사람이 머리말 「추천도서」에서 이동진 추천도서 · 사서 추천도서 · 서울대 100선 가운데 하나를 골라, 분야별로 표지를 넘기며 내 도서관에서 빌릴 수 있는 책을 찾고 싶다. 무엇을 읽을지 정할 때 믿을 만한 목록을 보고 싶어서 [확정] (사용자: "그 추천 도서 목록이 괜찮거든", 2026-10-15)
- 이동진 평론가의 추천을 본 사람이 그 책이 왜 추천됐는지 원래 영상으로 가 보고 싶다 [확정] (사용자: "나는 그냥 유튜브 링크랑 같이 주려고 했어", 2026-10-15)
- 운영하는 사람(사용자)이 매달 새 이달의 책을 손으로 넣지 않아도 되게 하고 싶다 [확정] (사용자: "수집 서비스가 이것도 같이 하도록 했으면 좋겠어", 2026-10-15)

## 동작 규칙

### R1. 머리말 메뉴

- R1-1 [확정] (scope #9) 큰 메뉴 둘: 「추천도서」(이동진 추천도서, 사서 추천도서, 서울대 100선), 「마이페이지」(내 도서관 관리). 책 검색은 「책첵」 로고. 「사서추천도서」 머리말 링크는 없어짐 (C14 R7-1을 바꿈)
- R1-2 [확정] (scope 머리말 메뉴 방식) PC: 큰 메뉴에 마우스를 올리면 머리말 아래로 두 칸이 함께 펼쳐짐. 아래 화면은 덮지 않고 펼친 칸 아래에 그림자·선 (scope #9 메모)
- R1-3 [확정] (사용자 승인, 2026-10-15, 명세 결정 #1) PC 열고 닫기와 누르기: 마우스를 0.5초 멈추면 열고, 메뉴 밖으로 나간 뒤 0.5초 지나면 닫음. 큰 메뉴 글자를 누르면 펼친 칸의 첫 항목으로 감(「추천도서」 → 이동진 추천도서, 「마이페이지」 → 내 도서관 관리). 둘 다 NN/g "Mega Menus Work Well for Site Navigation" 권고 (https://www.nngroup.com/articles/mega-menus-work-well/ , 2026-10-15 확인)
- R1-5 [확정] (scope #10) 폭 640px 이하: 큰 메뉴를 숨기고 오른쪽 위 ☰. 누르면 같은 메뉴가 위에서 펼쳐지고 아래는 어둡게 덮임. ✕나 덮인 곳을 누르면 닫힘. 641px 이상 태블릿은 PC처럼 보이고 누르면 펼침
- R1-6 [확정] (사이클 20 `from-cycle-20-header-light.md`) 조회 상태 점은 「로그인」 바로 왼쪽, 폰은 점만이고 ☰ 왼쪽. 머리말은 약관·처리방침 화면까지 모든 화면에서 같음
- R1-7 [확정] (사용자 승인, 2026-10-15, 명세 결정 #2) 「내 도서관 관리」는 로그인하지 않았을 때도 메뉴에 보이고, 누르면 지금 내 도서관 관리 화면(`/my-libraries`)으로 감. **고침(2026-10-16, dev 코드 확인)**: 로그인 전에도 로그인 안내 없이 같은 화면이 열리고 고른 도서관은 이 브라우저에 저장됨 (사이클 07 spec R3-6, dev `MyLibrariesPage.tsx` 39행). 처음 문장의 "로그인 안내"는 실제와 달라 고침. 메뉴는 링크만 걺

### R2. 세 목록 공통

- R2-1 [확정] (scope 이미 정한 것) 화면 모양은 C14 그대로: 분야 하나가 한 화면, 표지 3×3, ◀ ▶ 9권씩, 아래 가운데 [분야 ▾], 휠·스와이프 한 번에 다음 분야
- R2-2 [확정] (scope #1·#7) 같은 책 고르기: 맞는 우리 책(목록 줄)이 여럿이면 보유량이 가장 많은 것. 보유량 = 구독형이 아닌 도서관 수 + 구독형 도서관에 하나라도 있으면 1. 같으면 책 번호가 작은 것(C14 R3-2). 여러 권짜리는 그 판의 1권. 사서 추천도서도 이 규칙으로 바뀜 (C14 R3-2의 "가진 도서관이 가장 많은"을 바꿈) **더함 (2026-10-16, 설계 검토 #3·#7)**: 보유량은 지금 켜진 도서관만 셈. 여러 권짜리 1권은 사서 추천도서도 서버가 고를 때 지킴
- R2-3 [확정] (C14 R3-3) 맞은 책을 검색하는 도서관 중 한 곳이라도 가지면 또렷하게, 아니면 흐리게
- R2-4 [확정] (사용자 승인, 2026-10-15, 명세 결정 #3) 우리 책을 못 찾은 책(서울대 100선 13권, 이동진 8권, 2026-10-15 측정)도 목록에 넣고 흐린 제목 글자 표지로 보임. 누르면 C14 희망도서 안내(S15)
- R2-5 [확정] (C14 R7-3) 로그인하지 않아도 볼 수 있음
- R2-6 [확정] (사용자 승인, 2026-10-15, 명세 결정 #4, 메모: "/picks 아래"로) 주소와 이용 기록: 세 목록을 모두 `/picks` 아래에 둠 — 예 `/picks/leedongjin`, `/picks/librarian`, `/picks/snu100`(끝 이름은 설계). 예전 `/picks`는 사서 추천도서로 넘겨 줌. 뒤로 가기·책 화면에서 돌아오기는 C14 AC-20처럼 목록마다 자리 기억. 이용 기록(사이클 15)의 분야 보기·책 창 열기를 새 두 목록에도 남기고 어느 목록인지 함께 적음

### R3. 목록 파일과 서버에 넣기

- R3-1 [확정] (scope #2, 명세 결정 #10) 이동진 추천도서·서울대 100선은 dev 저장소의 목록 파일에 두고, 전자책 목록 가져오기에 실어 운영 반영 때 DB에 넣음 (R4-7). 사서 추천도서는 지금처럼 국립중앙도서관 API에서 주 1회 받음
- R3-2 [확정] (scope #4) 서울대 100선: 목차 100권, 분야 5개(한국문학, 외국문학, 동양사상, 서양사상, 과학기술), 분야 안 순서는 목차 번호
- R3-3 [확정] (scope #3) 서울대 100선의 "같은 책": 본제목(괄호·부제·끝 권 번호·"세트"·"완역본"·"개정판" 뗌) + 저자. 영어 원서·어린이·만화·논술·"공부가 되는" 판 뺌. 선집 15권은 같은 저자의 선집 가운데서. 저자 열쇠는 조사 `snu-100/picks.md` 표
- R3-4 [확정] (사용자 승인, 2026-10-15, 명세 결정 #5, 메모: "수집기가") 이동진 추천도서·서울대 100선의 판 고르기(R2-2 보유량 최대, R3-3 같은 책 범위)는 **수집기가** 가져오기 파일을 만들 때 하고, 고른 판을 목록 파일 한 줄의 "고정 판" 칸(출판사, 필요하면 ISBN)에 적어 R4-7 길로 보냄. 가져오기 파일을 만들 때 고정 판을 우리 책 번호로 맞춰 저장하고 서버는 읽기만 함 (설계 결정 #4, ADR-0124). 수집기 거르기 규칙을 더함: 출판사 이름에 "어린이"가 든 판, 저자 칸에 "번역AI"가 든 판, "[100분 고전]" 같은 요약 시리즈는 뺌 → 춘향전·실천이성비판·연암집이 자동으로 풀림. 규칙으로 못 가리는 책(미국의 민주주의, 페더랄리스트)은 "확인 필요"로 남기고 사람이 고정 판 칸에 적음. 사서 추천도서는 지금처럼 서버가 맞춤
- R3-5 [확정] (사용자 승인, 2026-10-15, 명세 결정 #6) 이동진 추천도서 범위와 겹침: 조사한 44권 모두(2023년 12월 올해의 책 7권 포함)와 앞으로의 이달의 책·올해의 책. 같은 분야 안에서 같은 책이 겹치면 **가장 최근 추천만 남기고 나머지는 지움** (사용자 메모: "책이 같은 카테고리 내에서 중복이 되면 최신 것을 살리고 나머지를 지워") → 이달의 책이면서 그해 올해의 책인 책은 올해의 책(그해 12월)으로 남음. 예: 「대온실 수리 보고서」는 "24.11"이 아니라 "24.12"(2024 올해의 책). 올해의 책에만 나온 책은 그해 12월. 한 영상에 책이 여럿이면(2025년 3월 예소연 4편 등) 각 책을 따로 같은 달로 넣음. 실린 책을 모르는 「마음 깊은 숨」은 찾을 때까지 넣지 않음. 같은 달 안 순서는 영상에서 소개한 순서
- R3-8 [확정] (scope 이미 정한 것) 이동진 분야 안 순서: 추천 연·월 최근 먼저
- R3-9 [확정] (사용자 승인, 2026-10-15, 명세 결정 #7) 이동진 분야 9개를 수집기 자동 분야와 같은 근거로 맞추기: 지금 44권의 분야(알라딘 분류 기준)도 R4-4의 KDC 대응표로 다시 매겨, 앞으로 들어올 책과 기준을 하나로 함. KDC는 API로만 얻으므로, 개발 때 API 호출 시험 뒤 지금과 분야가 달라지는 책을 보여 드리고 확정 **바뀜 (2026-10-16)** [확정] (사용자 승인, 2026-10-16, [API 시험 뒤 결정](easy/2026-10-16-step0-decisions.html) #2): 국립중앙도서관 ISBN 서지 API가 이동진 43권 모두 KDC를 비워 줌(dev 0단계 시험) → 다시 매기지 않고 **조사 때 정한 분야 그대로** 씀(`docs/research/leedongjin-picks/picks.md` 5절)

### R4. 수집기가 이동진 추천도서 모으기

- R4-1 [확정] (scope #11) 수집기가 한 달에 한 번 YouTube Data API로 재생목록 「이달의 책」(`PLUpgTv3bu9rGxQBAMVaMvam27P0YbiY29`)과 채널의 올해의 책 영상을 읽어 목록 파일에 없는 새 영상을 찾음. API 키는 dev `.env`. 페이지를 프로그램으로 읽지 않음(유튜브 약관)
- R4-2 [확정] (scope #12) 책 이름: 영상 제목·설명란의 [ ], 《 》, 〈 〉, 『 』 안 글자나 🔖 표시 뒤. 국립중앙도서관 ISBN 서지 API로 ISBN·저자·출판사·KDC를 찾음. 책 이름이 없거나 여러 책이 맞으면 그 영상을 "확인 필요"로 남김
- R4-3 [확정] (scope #13) 수집기가 분야까지 넣고 바로 확정. 분야 목록도 필요하면 수집기 쪽에서 더하거나 고침 **바뀜 (2026-10-16)** [확정] (사용자 승인, 2026-10-16, [API 시험 뒤 결정](easy/2026-10-16-step0-decisions.html) #1): 자동으로 정할 근거(KDC)가 없어, 수집기는 새 책을 "확인 필요" 파일에 넣으며 ISBN 서지 `SUBJECT`(주제 한 자리)로 고른 분야를 **제안만** 하고, 사람이 목록 파일 분야 칸을 정해 적으면 목록에 들어감(한 달 1~4권)
- R4-4 [확정] (사용자 승인, 2026-10-15, 명세 결정 #8) 자동 분야 = ISBN 서지 API의 KDC를 아래 표로 9개 분야에 대응. KDC가 비면 "확인 필요" **바뀜 (2026-10-16)**: 아래 표는 쓰지 않음(KDC가 없음, R4-3 바뀜). 수집기의 분야 제안은 `SUBJECT` 한 자리 → 분야 대응(9 역사, 4·5 과학·의학 등, 8·3·1은 여럿 가운데 하나로 제안) [안]

  | KDC | 분야 |
  |---|---|
  | 813 (한국 소설), 811 (한국 시) | 한국 소설 |
  | 823·833·843·853·863·873·883 등 외국 소설, 외국 시 | 외국 소설 |
  | 814·818 및 각 외국문학의 수필(…4)·잡저(…8) | 에세이 |
  | 657 (만화) | 그래픽노블 |
  | 000·100·200·700, 800 문학 이론 | 인문·철학 |
  | 900 (역사·지리·전기) | 역사 |
  | 300 (320·325 빼고), 340·350 | 사회·정치 |
  | 320 (경제), 325 (경영) | 경제·자기계발 |
  | 400·500 (자연과학·기술과학) | 과학·의학 |
  | 600 (예술, 657 빼고) | 에세이 |

## 수용 기준

C14 AC-2, AC-3, AC-5, AC-7~AC-10, AC-16, AC-18~AC-21은 세 목록에 이름만 바꿔 그대로.

- AC-1: PC에서 머리말 「추천도서」에 마우스를 0.5초 올리면 → 머리말 아래로 「추천도서」(이동진 추천도서, 사서 추천도서, 서울대 100선)·「마이페이지」(내 도서관 관리) 두 칸이 함께 펼쳐지고, 아래 화면은 어두워지지 않는다
- AC-2: 폭 375px에서 → 큰 메뉴 대신 ☰가 보이고, 누르면 같은 메뉴가 펼쳐지며 아래가 어두워진다. 어두운 곳을 누르면 닫힌다. 320px에서 「책첵」, 조회 상태 점, 「로그인」, ☰가 한 줄에 들어간다
- AC-3: 이용약관·개인정보 처리방침 화면에서도 머리말이 같다
- AC-4: 「서울대 100선」을 열면 → 「전체」 첫 9권이 목차 1~9번 순서로, 표지 아래 번호와 함께 보이고, 분야 목록이 전체, 한국문학, 외국문학, 동양사상, 서양사상, 과학기술 순이다
- AC-5: 「이동진 추천도서」를 열면 → 「전체」 첫 권이 가장 최근 추천(2026-10-15 기준 2026년 6월 「히스토리아 비테이」)이고 표지 아래 "26.06"이 보인다
- AC-6: 서울대 100선 「구운몽」처럼 판이 여러 개인 책은 → 보유량(구독형 도서관은 몇 곳이든 1)이 가장 많은 판이 맞춰진다 (API 응답의 책 번호로 확인)

- AC-11: 수집기 시험에서 재생목록에 목록 파일에 없는 영상이 하나 있으면 → 목록 파일에 새 줄(영상 ID, 연·월, 책 이름, 저자, ISBN, 분야)이 하나 생긴다. 영상 제목·설명은 파일에 없다
