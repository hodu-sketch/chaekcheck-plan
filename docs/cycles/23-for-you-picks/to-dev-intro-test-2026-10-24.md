## 1. 원문이 없는 책 수 (요청 없음)

- 서비스 책 전체와 "보유 도서관이 많은 3만 권"(사전 시험의 후보 풀과 같은 기준) 각각에서
  - `holding.intro_raw`가 한 줄이라도 있는 책 수
  - 없지만 **같은 책 묶음 번호(book_id)의 다른 도서관 줄**에 원문이 있는 책 수 (차례 ①)
  - 그래도 없는 책 수, 그 책들이 어느 플랫폼에서만 왔는지(알라딘·포털·서울 등)

## 2. 다른 출처로 채워지는 수 (표본만)

차례 ① 뒤에도 원문이 없는 책에서 무작위 50권(시드 23)으로:

| 차례 | 출처 | 하기 전에 |
|---|---|---|
| ② | 카카오 책 검색 API `contents` | 카카오 개발자 약관·운영정책에서 결과 저장·가공(요약·임베딩 입력)이 되는지 먼저 확인하고 원문 링크·확인일을 적어 줌. 안 되면 호출하지 않음 |
| ③ | 도서관 정보나루 도서 상세 | 인증키가 이미 있을 때만. 응답에 소개 칸이 있는지, 전자책이 있는지 |
| ④ | 국립중앙도서관 ISBN 서지 API `BOOK_INTRODUCTION` | 인증키가 이미 있을 때만. 2021-02까지 자료라는 점 확인 |

- 출처마다: 채워진 권수 / 50, 글 길이 가운데값, 이용 조건 요약(원문 링크·확인일)
- 키가 없거나 약관이 막으면 그 칸은 "못 함"과 이유만

## 3. 이웃 다시 재기 (KURE-v1)

- 사전 시험과 같은 기준 책 30권·같은 3만 권 후보 풀
- 입력: `제목 · 저자 · 출판사 · 연도` + 소개 앞부분 300자(①로 채운 것까지만; ②~④는 1·2절 결과를 보고 plan이 정함)
- 결과: 30권 × 이웃 20권 표(사전 시험 `neighbours.tsv`와 같은 칸 + 소개를 넣었는지 칸), 1,000권 시간, 3만 권 시간
- 사전 시험에서 엉뚱했던 「대구」·「에밀」·「신곡」·「햄릿」·「캔터베리 이야기」의 이웃 1~5를 전후로 나란히
