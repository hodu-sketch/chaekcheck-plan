탈퇴 도중 멈췄을 때
로그인과 다른 전용 코드를 두겠습니다.

앞 페이지 항목 5에서 "탈퇴 전용 코드가 있어야 할 것 같다"고 하셔서(미승인), 새로 둘 코드의 이름과 화면 문구를 제안합니다. 항목은 하나입니다.

1지금 있는 탈퇴 코드와 새로 둘 두 가지

지금 탈퇴 코드는 다섯 개입니다. 새로 두 개를 더해 모두 일곱 개가 됩니다. 새 두 개는 로그인용 코드와 같은 상황에 쓰이지만, 화면이 "탈퇴"를 안내할 수 있게 이름과 문구를 따로 둡니다.

코드언제화면 문구
withdraw_reauthenticated재인증 성공(웹이 탈퇴 요청을 보냄)탈퇴 처리 중
withdraw_account_mismatch다른 계정으로 확인함가입한 계정으로 확인해 주세요
withdraw_cancelled제공자 화면에서 취소함탈퇴를 취소했어요
withdraw_provider_error네이버·카카오 쪽 오류네이버(카카오) 쪽 문제로 본인 확인을 하지 못했어요. 잠시 뒤 다시 해 주세요
withdraw_login_expired우리 로그인이 풀려 있음(리프레시 기록 없음)로그인이 풀렸어요. 다시 로그인한 뒤 탈퇴해 주세요
withdraw_request_expired (새 이름)재인증을 시작할 때 저장해 둔 요청이 없음. 예: 제공자 화면에서 10분 넘게 머무름본인 확인 시간이 지났어요. 탈퇴를 다시 눌러 주세요
withdraw_state_mismatch (새 이름)저장해 둔 요청은 있는데 돌아온 요청의 확인 값(state)이 다름안전하지 않은 요청이라 멈췄어요. 탈퇴를 다시 눌러 주세요

1탈퇴 재인증에서 요청이 만료되었거나 확인 값이 맞지 않을 때 위 두 코드(withdraw_request_expired, withdraw_state_mismatch)를 새로 둠 [안]

예: 탈퇴하려고 카카오에서 다시 로그인하는 화면에서 15분 동안 머물다가 돌아오면, 지금은 "로그인 시간이 지났어요. 다시 해 주세요"가 나와서 로그인을 하라는 말로 읽힙니다. 새 코드를 두면 "본인 확인 시간이 지났어요. 탈퇴를 다시 눌러 주세요"가 나옵니다.

바뀌는 곳: 우리 서버가 재인증 콜백에서 보내는 코드 두 곳, 화면의 문구 두 개, 설계의 결과 코드 표. 이미 만든 dev 코드를 두 줄 고치는 정도의 작은 변경이며, 사이클 06의 "사이클 05 보완"으로 인계서에 넣습니다. 이름과 문구는 제 제안이고 dev 코드나 공식 문서에서 가져온 것이 아닙니다.

다른 선택 ① 이름은 같게 두고 문구만 탈퇴에 맞게 화면이 바꿔 보여 줌(코드 하나로 두 상황을 구분하려면 요청이 탈퇴 재인증이었다는 정보를 서버가 따로 넘겨야 해서 오히려 복잡해짐). ② 위 제안을 승인하되 이름이나 문구를 바꿔서: 기타에 적어 주세요.
