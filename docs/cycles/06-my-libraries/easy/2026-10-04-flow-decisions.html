내 도서관 화면을 어떻게 둘지
여덟 가지를 정해 주세요.

화면 흐름 flow.md를 쉬운 말로 풀었습니다. 그림은 위치와 순서만 보여 주고, 색과 모양은 실제 디자인이 아닙니다. 지금 화면은 dev 코드에서 확인했습니다(2026-10-04, 읽기만). 로그인하지 않은 사람의 화면은 바뀌지 않습니다.

1화면이 어떻게 이어지나

새 화면은 둘입니다. "내 도서관" 관리 화면(S10)과, 처음 로그인했을 때 지역을 옮길지 묻는 작은 창(S11)입니다. 나머지는 지금 화면에 글자와 버튼이 조금 더해집니다.

로그인→S11 지역 옮기기 묻기
(이 브라우저에 지역이 있을 때 한 번)→S1 검색 (로그인 후)
S1 "내 도서관" 줄의 관리
또는 ⚙ 설정 → 내 도서관→S10 내 도서관→지역 변경: S2 지역 고르기 창
(로그인 후에는 서버에 저장)

글자만 바뀌는 곳: 가입 동의 화면과 개인정보 처리방침의 수집 항목에 "거주지·직장 지역, 직접 추가한 도서관"을 더하고(명세에서 정함), 탈퇴 안내의 지워지는 것 목록에 "저장한 지역과 내 도서관"을 더합니다.

2검색 화면 (로그인 후)

지금의 "내 지역" 줄 자리에 "내 도서관" 줄이 오고, 스위치의 두 번째 칸이 "내 도서관"이 됩니다. 내 도서관이 있으면 처음부터 켜져 있습니다(명세에서 정함).

1로그인 후 검색 화면의 "내 지역" 줄을 "내 도서관" 줄로 바꿈: 거주 · 직장 · 직접 추가 N곳 · 관리 [안]

예: "내 도서관 · 거주 서울 마포구 · 직장 서울 중구 · 직접 추가 3곳 · 관리". 아무것도 없으면 "내 도서관이 비어 있어요. 지역을 고르거나 도서관을 추가하세요 · 관리". 폰에서 줄이 길면 지역 이름을 줄이고 "외"를 붙입니다. "관리"를 누르면 내 도서관 화면(S10)으로 갑니다.

다른 선택 "내 지역" 줄은 그대로 두고 그 아래에 "직접 추가 3곳 · 관리" 줄을 하나 더 둠. 한 줄이 늘어 결과가 아래로 밀립니다.

2로그인 후 스위치의 글자를 "전체 도서관 | 내 도서관"으로 바꿈 [안]

로그인 전에는 지금처럼 "전체 도서관 | 가입 가능한 곳"(지역이 없으면 "누구나 가입")입니다. 로그인 후 "내 도서관"을 켜면 지역으로 자동 들어온 곳 + 누구나 가입하는 곳 + 직접 추가한 곳에서 찾습니다(명세에서 정함).

다른 선택 로그인 후에도 "가입 가능한 곳"이라는 글자를 그대로 씀. 직접 추가한 곳은 가입 자격과 상관없이 들어가므로 글자와 뜻이 어긋납니다.

3내 도서관을 불러오는 동안이나 불러오지 못했을 때도 검색은 막지 않고 전체 기준으로 찾음 [안]

예: 로그인 직후 서버에서 내 도서관을 받는 0.몇 초 동안 줄에 "불러오는 중"이 보이고, 그 사이 검색하면 전체 도서관에서 찾습니다. 불러오지 못하면 줄에 "내 도서관을 불러오지 못했어요 · 다시 시도"가 보이고 스위치는 전체로 둡니다.

다른 선택 불러올 때까지 검색 버튼을 막음. 서버가 느리면 검색을 못 합니다.

4내 도서관 관리는 별도 화면(주소 /my-libraries)으로 두고, 검색 화면 줄의 "관리"와 ⚙ 설정 창의 새 "내 도서관" 절에서 들어감 [안]

자동 목록이 수십 곳이 될 수 있어 작은 창보다 화면 하나가 읽기 쉽고, 폰에서도 스크롤이 자연스럽습니다. ⚙ 설정 창에는 로그인 후에만 "내 도서관" 절이 생기고 [내 도서관 관리] 버튼 하나만 둡니다. 로그인하지 않은 채 주소로 들어오면 검색 화면으로 보냅니다.

다른 선택 ① 지금 ⚙ 설정 창(작은 창) 안에 다 넣음. 목록이 길면 창이 넘칩니다. ② 들어가는 길을 검색 화면 줄 하나로만. 설정 창에서 찾는 사람이 못 찾을 수 있습니다.

5내 도서관 화면은 위에서부터 지역 → 지역으로 자동(접어 둠) → 직접 추가(펼쳐 둠, 빼기 버튼) → 도서관 추가 검색 순서 [안]

자동 목록은 "지역으로 자동 12곳 ▸"처럼 접어 두고 누르면 도서관 이름과 가입 표시("누구나 가입", "서울 재직" 등)가 펼쳐집니다. 자동 목록에는 빼기 버튼이 없습니다(명세에서 정함: 지역을 바꿔 조절). 직접 추가 목록은 "3/20곳"처럼 몇 곳 남았는지 보이고 줄마다 가입 자격 배지와 [빼기]가 있습니다. 꺼진 도서관이 저장돼 있으면 그 줄에 "지금은 쓸 수 없는 도서관이에요"와 [빼기]가 보입니다.

다른 선택 자동 목록도 펼쳐 둠. 직접 추가 목록과 추가 검색이 아래로 많이 밀립니다.

6도서관 추가는 내 도서관 화면의 이름 검색으로만 함 (이번 사이클) [안]

예: "서울"을 치면 이름에 "서울"이 들어간 서비스 도서관이 나오고 [추가]를 누릅니다. 이미 내 도서관(자동이든 직접이든)에 있는 곳은 "이미 있음"으로 흐리게 보입니다. 20곳이 차면 [추가]가 흐려지고 "직접 추가는 20곳까지예요. 하나를 빼면 추가할 수 있어요"가 보입니다. 명세에서 "고르는 위치"를 화면 단계로 미뤄 둔 항목입니다.

다른 선택 검색 결과의 도서관 줄에도 "내 도서관에 추가" 버튼을 둠. 결과를 보다가 바로 넣을 수 있지만, 결과 줄마다 버튼이 늘어 지금 화면이 복잡해지고 만들 것도 늘어납니다. 다음 사이클(검색 화면 다듬기)에서 다시 볼 수 있습니다.

7추가·빼기는 누르는 즉시 저장하고, 따로 "저장" 버튼을 두지 않음 [안]

[추가]나 [빼기]를 누르면 바로 서버에 저장됩니다. 저장에 실패하면 바꾸기 전 목록으로 돌아가고 "저장하지 못했어요. 잠시 뒤 다시 해 주세요"가 보입니다. 지역은 지금처럼 지역 고르기 창의 "저장"으로 저장합니다.

다른 선택 화면 아래에 "저장" 버튼을 두고 한 번에 저장. 저장을 잊고 나가면 바꾼 것이 사라집니다.

8창의 글과 버튼은 "이 브라우저에 고른 지역이 있어요. 계정에 저장할까요?" + [계정에 저장] [저장하지 않기], 한 번 답하면 같은 계정·같은 브라우저에서 다시 묻지 않음 [안]

계정에 저장 → 그 지역이 서버에 저장되고 검색 화면이 그 지역 기준으로 열립니다. 저장하지 않기 → 계정의 지역은 빈 채로 시작하고, 이 브라우저의 지역은 그대로 남아 로그아웃 뒤에 씁니다. 모양은 로그인 선택 창(사이클 05)과 같게 PC·태블릿은 가운데, 폰은 아래에서 올라옵니다.

다른 선택 "저장하지 않기"를 고른 사람에게 다음 로그인 때 다시 물음. 매번 같은 질문을 받게 됩니다.
