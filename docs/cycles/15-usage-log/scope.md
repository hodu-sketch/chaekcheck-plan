# 사이클 15: 사용자 행동 기록 (검색·도서관 클릭)

시작: 2026-10-12. 다른 사이클과 나란히 미리 하는 plan입니다 (아래 "나란히 도는 사이클과 겹치는 곳").

## 목표 (한 문장)

사용자가 검색하거나 결과에서 도서관으로 넘어갈 때마다 기록을 한 줄씩 DB에 남겨, 다음 사이클에서 통계를 낼 수 있게 합니다.

- 사용자: "사용자가 검색을 하거나 도서관 페이지를 클릭할 때 정보를 기록해서 나중에 통계에 쓸까 해", "통계는 다음이고 지금은 기록이야" (2026-10-12)

## 포함

결정 근거는 모두 `docs/research/usage-log/storage.md` 6절 (결정 페이지 `docs/research/usage-log/easy/2026-10-12-storage-decisions.html`).

1. **저장할 곳**: 같은 PostgreSQL에 새 schema의 기록 칸 [확정] (사용자 승인, 2026-10-12)
2. **검색 기록**: 사용자가 검색한 처음 요청만 한 줄로 남김. 수집 목록 검색(`GET /api/v1/books`)과 도서관에서 직접 찾기(`GET /api/v1/ebook-searches/stream`) 둘 다. 다음 묶음·대출 수·다음 쪽은 남기지 않음 [확정] (사용자 승인, 2026-10-12)
   - 같은 줄에 검색 조건, 결과 수, 그리고 검색할 때 함께 오는 거주 지역·직장 지역·고른 도서관·범위 [확정] (사용자: "검색 요청을 한 사용자의 정보도 남겼으면 해 지역(직장/거주) 도서관 .. 이런거라던가", 2026-10-12)
3. **도서관 클릭 기록**: 링크는 지금처럼 새 탭으로 바로 열고, 브라우저가 "이 도서관을 눌렀음"만 우리 서버에 따로 보냄 [확정] (사용자 승인, 2026-10-12). 보내는 방법은 `sendBeacon`에서 `fetch` keepalive로 바뀜 (spec R2-1, 2026-10-13). 누르는 곳 여섯(결과 카드, 가입 링크, 가입 안내 보기, 도서관 첫 화면, 로고, 요약 막대의 이름)은 `storage.md` 1.2절
4. **남기지 않는 것**: 회원 번호·IP·브라우저 식별값 [확정] (사용자 승인, 2026-10-12)
5. **보관 1년**: 1년이 지난 원본 기록은 지움 [확정] (사용자 승인, 2026-10-12). 지우는 방법(서버가 매일 자동 / 사람이 명령) 서버가 매일 자동으로 지움 [확정] (사용자 승인, 2026-10-12, `easy/2026-10-12-scope-decisions.html`)
6. **쓰는 방식** [확정: 설계의 출발점] (사용자 승인, 2026-10-12, `easy/2026-10-12-scope-decisions.html`): 검색 응답과 떨어져서 쓰기, 몇 초마다 묶어 한 트랜잭션, 기록 트랜잭션만 비동기 커밋, Spring Modulith 이벤트는 쓰지 않음 (`storage.md` 2.7절). `/design-delta`에서 정함

7. **더 남기는 행동** [확정] (사용자: "이거 했으면 좋겠어 어지간한면 기록하고 싶어", 2026-10-13, `easy/2026-10-13-more-actions.html`): 책 상세 열기, 더 보기 세 종류, 사서 추천 목록·책 창 열기, 지역 설정·내 도서관 바꾸기, 직접 찾기 도서관별 응답 (spec R5·R6)

## 제외 (backlog.md로 보낸 항목)

- 통계(집계, 그래프, 운영자 화면) — 다음 사이클 (사용자, 2026-10-12)
- 회원 번호·IP·브라우저 식별값으로 같은 사람의 행동 잇기 — 결정 4로 하지 않음
- 화면 머문 시간, 스크롤 등 (포함 7 밖의 행동)
- 분석 전용 저장소(ClickHouse 등)로 옮기기 — 통계가 느려질 때 (`storage.md` 2.8절)
- 개인정보 처리방침 문구 — 사이클 16이 씀. 이 사이클은 무엇을 모으는지만 16에 넘김 (16 `scope.md` 포함 5)

## 완료 기준 (사용자가 확인할 수 있는 것)

기록은 화면에 보이지 않으므로, 화면에서 한 행동이 DB에 남는지로 확인합니다.

- 검색을 한 번 하면 기록 칸에 한 줄이 생기고, "다음 묶음"·"더 보기"를 눌러도 줄이 늘지 않는다
- 그 줄에 검색어, 결과 수, 거주·직장 지역, 고른 도서관이 들어 있다
- 결과 카드를 누르면 전자도서관 새 탭이 지금처럼 바로 열리고, 기록 칸에 누른 도서관과 누른 곳이 한 줄 생긴다 (여섯 곳 모두)
- 기록 칸에 회원 번호·IP 칸이 없다
- 1년이 지난 기록이 지워진다 (테스트로 확인)
- 기록을 켜기 전과 후의 검색 응답 시간·서비스와 DB 메모리가 크게 다르지 않다 (측정값으로 확인, 기준은 `/feature-spec`에서) [확정] (사용자 승인, 2026-10-12, `easy/2026-10-12-scope-decisions.html`)
- 기록을 보는 방법: SQL 또는 Claude 명령 (운영자 화면 없음) [확정] (사용자 승인, 2026-10-12, `easy/2026-10-12-scope-decisions.html`)
