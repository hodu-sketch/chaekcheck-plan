## 계획대로 된 것

- 규칙 함수 `SameTextKey`(패키지 내부)를 `collection` 안에 두고 묶는 방식 모두가 같은 함수를 부름 (ADR-0082 결정 1)
- 같은 키 안 ISBN이 둘 이상이면 ISBN마다 한 책, ISBN 없는 묶음끼리 한 책 (결정 2, 세부 7). 국가서지(③)에서 붙인 ISBN도 셈
- 자리 채움 값: 저자 "기타"·"unknown", 출판사 "기타"·"미상"·"unknown"은 값 없음, 첫 저자가 자리 채움이면 다음 저자 (spec R2, `SameTextKey.java` 36·39·338~345행). 화면 표시는 그대로 (AC-2)
- 권 표시 형식 `n=…|s=…|e=…`, 판 낱말 11개(긴 것 먼저) (spec R3-2 앞부분, 42~43행)
- 저자 없음·"편"만 있음은 합치지 않음 (R4)
- dry run 전용 빼기 설정(진짜 가져오기에서 켜면 시작 안 함), `compare_grouping.py regroup`, 로그 전용 카운터 (결정 4-1·4-2·6)
- "출판일 2년 차이" 표본 순서 단순화, `current` 흉내 코드(`MapShape`, `hashMapOrder`, `WideKey`) 지움 (결정 5)
- `compact` 메모리 증가 거의 없음: 힙 최고 2,303~2,325MB, Remark 뒤 1,359~1,376MB(옛 규칙 2,320 / 1,357MB) [확정] (dev 측정, 3250·3348·3474행)

## 새로 알게 된 제약

- **합쳐지며 사라진 번호는 다시 쓰지 않음**(ADR-0062): 반영 1회차에서 사라진 92,252개 번호는 다시 반영해도 돌아오지 않고, 작가 이름 제목으로 잘못 합쳐졌던 작품들은 2회차에서 새 번호를 받음 (dev 3438행). 아직 배포 전이라 바깥 주소는 없음
- **부제 나누기는 도서관 목록에 달림**: `SubtitleParts`는 "같은 도서관이 따로 가지는지"로 나누므로 도서관을 더하거나 빼면 같은 사본이라도 나뉨이 바뀔 수 있음 [확정] (`SubtitleParts.java` 16~18행). 한 도서관이 같은 책을 두 공급사에서 따로 들인 경우가 흔해 한쪽에 부제가 없으면 이 신호를 쓰지 않음 (한 도서관이 옛 책 둘 이상을 가진 책 13,851권, dev 3470행)
- **꺾쇠 저자 표기** 「<김정은>,<김지혜> 저」: 대표 저자가 이 표기면 첫 저자가 달라져 같은 책이 안 합쳐짐. R5에서 합쳐진 7,047권 중 2,944권이 이 표기(새 도서관이 들어오며 대표 저자가 보통 표기로 바뀌어 합쳐짐), AC-3 미통과 원인 중 하나. 고치려면 `catalog.normalize`(저자 정리) 변경 → 이번 범위 밖 (dev 3360·3458행)
- **8자 경계**: 짧은 부제 조각 기준 8자 때문에 「살림지식총서 81 / 081」, 「… 01권 / 01」이 두 줄로 남음 → "확실하지 않으면 합치지 않음"에 맞아 받아들임. 짧은 부제 안 시리즈 번호(「- 수학자 86」)도 맨 제목과 따로 (dev 3346행). 끝 숫자 규칙·앞의 0 빼기는 같은 책을 수천 권 갈라 되돌림 (dev 3343~3344행)
- **작가 이름 제목 규칙의 부작용**: 저자 이름이 상표와 같은 「사이다경제」 / 「사이다경제 - …」가 두 줄 (dev 3443행)
- **출판연도 폭**(확정 규칙, 1950년 이전 제외, 1,458,744권): 0년 1,291,161 / 1년 62,680 / 2년 21,599 / 3~4년 34,835 / 5~9년 30,812 / 10년 이상 17,657. 같은 상품 코드·같은 ISBN인데 날짜가 몇 년 다른 예가 있어 출판일로 판을 가르기 어려움 (dev 3420행)
- **측정 시간은 PC 부하가 섞임**: 사이클 12 내보내기 `compact` 43분 12초(사이클 11은 약 22분)는 같은 PC의 다른 작업 탓으로 보고 시간 비교에 쓰지 않음 (dev 3401행). 긴 측정 동안 다른 세션의 빌드를 멈춰야 함 (dev 3147행)
- `GET /api/v1/books?title=묘왕동주 1&exact=title`이 500 `internal_error` — 사이클 12와 무관, dev가 "별도 작업으로 넘김" (dev 3440행)
- 「묘왕동주」는 책은 있으나 화면에 보이는 소장 도서관이 0곳(`holdingLibraryCount` 0) (dev 3439행)
