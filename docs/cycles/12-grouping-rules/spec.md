## 사용자 이야기

- 이용자는 「상법총칙 상행위」를 찾을 때, 2014년 판과 2020년 판을 따로 보고 싶다 — 판마다 내용이 달라 원하는 판을 가진 도서관을 골라야 하니까
- 이용자는 「백만장자 마인드」처럼 부제 표기만 다른 같은 책을 한 줄로 보고 싶다 — 같은 책이 여러 줄로 나뉘면 가진 도서관을 한눈에 못 보니까
- 이용자는 전에 저장하거나 공유한 책 주소가 규칙이 바뀐 뒤에도 맞는 책(나뉘었으면 가장 가까운 판)을 열기를 바란다
- 운영자(사용자)는 규칙을 바꾼 가져오기에서 얼마나 합쳐지고 나뉘었는지, 번호가 어떻게 이어졌는지 기록으로 보고 싶다

## 동작 규칙

### R1. 판이 다른 책은 합치지 않음 (④)

- R1-1: 네 번째 단계(같은 글자)에서 두 묶음이 각자 **계산한 종이책 ISBN**(②의 교보식 번호에서 계산, ③의 국가서지에서 붙인 ISBN 포함)을 가지고 있고 그 값이 다르면 합치지 않음 [확정] (5.5 Q2)
- R1-2: 한쪽 또는 양쪽이 ISBN을 모르면 지금처럼 글자로 판단 [확정] (5.5 Q2)
- R1-3: 세 묶음 이상이 글자로 이어질 때, ISBN이 서로 다른 두 묶음이 ISBN 없는 묶음을 사이에 두고 한 책이 되지 않게 함. 예: A(ISBN 1)·B(ISBN 없음)·C(ISBN 2)의 글자가 모두 같으면 A와 C는 따로. B는 **어느 쪽에도 붙이지 않고 따로 둠** [확정] (사용자 승인 "이대로 해줘", 2026-10-12, `easy/2026-10-12-spec-decisions.html`) (다른 선택: 소장이 더 많은 쪽에 붙임 — 줄이 하나 줄지만 B가 다른 판일 수 있음) ISBN 없는 묶음이 여럿이면 그들끼리는 한 책(예 A·B1·B2·C → 3권) [확정] (사용자 승인 "전부 승인", 2026-10-12, `easy/2026-10-12-design-decisions.html`) 세부 7

### R2. 자리 채움 값은 값 없음 (④)

- R2-1: 저자(첫 저자)나 출판사가 아래 목록이면 값 없음으로 보고 네 번째 단계에서 합치지 않음 [확정] (5.5 Q3)
- R2-2: 목록 [확정] (사용자 승인 "이대로 해줘", 2026-10-12, `easy/2026-10-12-spec-decisions.html`) — 비교는 정리한 글자(공백·대소문자 무시)로
  - 출판사: "기타", "미상", "unknown", "." (책 수: 기타 18,195, "." 1,232; 미상·unknown은 적음)
  - 저자: "기타", "unknown", "." (책 수: 기타 31,448, Unknown 1,796, "." 1,299)
  - 그대로 글자로 보는 것 [확정] (사용자 승인 "이대로 해줘", 2026-10-12, `easy/2026-10-12-spec-decisions.html`): 저자 "작자미상"(10,111)·"작자 미상"·"작가미상"·"미상", 저자·출판사 "편집부"(6,110 / 5,241) — 출판사가 실제 이름이면 같은 출판사의 같은 제목이라 같은 책일 가능성이 큼(예: 고전 「춘향전」 작자미상). 출판사 "북큐브"는 실제 출판사로 그대로 [확정] (사용자: "3 그대로 놔주고", 2026-10-12)
- R2-4: 첫 저자가 자리 채움 값이면 다음 저자(지은이·역할 모름)를 씀. 실명이 없으면 값 없음 [확정] (사용자 승인 "전부 승인", 2026-10-12, `easy/2026-10-12-design-decisions.html`) 세부 8
- R2-3: 자리 채움 값은 검색·화면 표시에는 그대로 둠(지금처럼 "기타"로 보임) [확정] (사용자 승인 "전부 승인", 2026-10-12)

### R3. 부제·시리즈 표시는 떼고, 권 표시는 지킴 (④)

- R3-1: 네 번째 단계의 비교 제목을 전체 제목(`titleNorm`)에서 **본제목**(`mainTitleNorm`: 앞 `[…]`·`〈…〉` 시리즈 표시를 떼고 첫 ` : `·` - ` 앞)으로 바꿈 [확정] (5.5 Q4) (2026-10-12 넓힘) 꼬리 목록(R3-3)에 든 이용 안내 꼬리는 비교 제목 끝에서도 뗌 [확정] (사용자 승인 "전부 승인", 2026-10-12, `easy/2026-10-12-design-decisions.html` 4번)
- R3-2: 단, 두 책의 **권 표시**가 다르면 합치지 않음. 권 표시 = 전체 제목에서 뽑은 [확정] (사용자 승인 "이대로 해줘", 2026-10-12, `easy/2026-10-12-spec-decisions.html`)
  - 숫자 목록(순서대로, 예 「수학 1」 → [1], 「묘왕동주 1 - 상」 → [1], 「오키나와 셀프트래블(2018-2019)」 → [2018, 2019], 「이기적 유전자(40주년 기념판)」 → [40])
  - 상·중·하·上·中·下 (괄호 안, 공백·`-`·`.` 뒤, 끝 또는 "권" 앞)
  - 판 표시 낱말: 개정, 증보, 전면개정, 특별판, 기념판, 리커버, 완결, 외전, 합본, 세트, 시즌 (있고 없음과 낱말이 같아야 함)
- R3-3: 꼬리 표시는 권 표시에서 뺌 [확정] (사용자 승인 "전부 승인", 2026-10-12): "[오디오북]"·"[디지털 구연동화]" 같은 앞 대괄호(본제목에서 이미 빠짐), "(PC만 열람 가능)" 같은 이용 안내 괄호 — 목록은 설계에서 데이터로 정함 [확인 필요: 데이터 대조]
- R3-4: 예 [확정] (사용자 승인 "이대로 해줘", 2026-10-12, `easy/2026-10-12-spec-decisions.html`)
  - 「백만장자 마인드」 / 「백만장자 마인드 - 부를 끌어 당기는」 → 한 권 (권 표시 둘 다 없음)
  - 「납치범들 : 콘스탄스 던랩」 / 「납치범들 - 콘스탄스 던랩」 → 한 권
  - 「오개념 탈출 프로젝트 - 수학 1」 / 「- 수학 2」 → 따로 ([1] ≠ [2])
  - 「묘왕동주 1 - 상」 / 「1 - 하」 → 따로 (상 ≠ 하)
  - 「이기적 유전자」 / 「이기적 유전자(40주년 기념판)」 → 따로 ([] ≠ [40], 기념판)
  - 「삼체 3부 - 사신의 영생」 / 「삼체 3부」 → 한 권 ([3] = [3])
- R3-5: 판이 다를 수 있는데 권 표시가 없는 경우(예: 판 표시 없는 개정판)는 R1(ISBN)이 막음. ISBN도 없으면 합쳐짐(지금과 같음)

### R4. 저자 없음 (④)

- R4-1: 저자(지은이·역할 모름)가 없으면 합치지 않는 지금 규칙 유지 [확정] (5.5 Q5)
- R4-2: "편"·"엮음"·"편저"·"엮은이"만 있는 책(지금 코드는 편집자 역할로 읽어 저자 없음, `Contributors.java` `ROLE_WORDS`; 저자 표시가 이렇게 끝나는 책 약 25,402권, 정규식 셈): 편집자를 저자 대신 쓰지 않고 지금처럼 따로 둠 [확정] (사용자 승인 "이대로 해줘", 2026-10-12, `easy/2026-10-12-spec-decisions.html`) (다른 선택: 저자가 없을 때만 첫 편집자를 대신 씀)

### R5. 새로 넣은 도서관이 이어 붙인 것 확인

- R5-1: R1~R4로 고친 규칙으로, 사이클 07에서 새로 넣은 도서관 2,394곳을 넣은 결과와 뺀 결과를 dry run으로 비교해 "기존 도서관 275곳의 따로 있던 책이 새 도서관 책 때문에 합쳐진 것"을 목록으로 뽑음 [확정] (5.5 Q6)
- R5-2: 목록에서 표본 20권을 사이트로 확인해 잘못 합친 것의 공통점이 보이면 규칙을 더함(사용자에게 다시 질문). 공통점이 없으면 받아들임 [확정] (사용자 승인 "전부 승인", 2026-10-12)

### R6. ISBN API

- R6-1: 이번 사이클에서는 국가서지 다음 단계로 ISBN API를 넣지 않음 (사용자 조건 "유의미하면"에 대해 표본 결과로 판단) [확정] (사용자 승인 "이대로 해줘", 2026-10-12, `easy/2026-10-12-spec-decisions.html`) — 근거: 표본 100권(ISBN 모르는 책, 웹소설 회차·"기타" 제외) 중 46권만 결과가 있고, 결과가 둘 이상인 18권도 대부분 같은 판의 종이책·전자책 짝이었음(다른 판으로 보이는 것은 「영구 평화론」 범우사/서광사 등 소수). ISBN 모르는 책이 1,341,109권(83%)이라 1초 1건이면 약 15일, 하루 한도는 공식 문서에 없음 (`same-book-isbn.md` 5.6, 시험 2026-10-12). 다른 선택: 넣는다(사용자 조건 "유의미하면 국가서지 다음에") — 그러면 하루 한도 문의와 몇 날에 나눠 부르는 설계가 필요

### R7. 책 번호 확인

- R7-1: 번호 잇기 규칙은 바꾸지 않음(ADR-0062: 새 책마다 (도서관, 책 코드)가 가장 많이 겹치는 옛 번호, 합쳐지면 가장 작은 번호, 나뉘면 많이 겹치는 쪽이 옛 번호, 안내표 없음, 번호 재사용 안 함) [확정]
- R7-2: 규칙을 바꾼 첫 가져오기에서 가져오기 기록에 이어 씀·새 번호·사라진 번호 수를 남김(지금 남기는 값 그대로인지 설계에서 확인) [확정] (사용자 승인 "전부 승인", 2026-10-12)
- R7-3: 표본 확인: R1로 나뉜 책 5권, R3으로 합쳐진 책 5권의 옛 주소를 열어 규칙대로인지 봄 [확정] (5.5 Q8)

### R8. 묶는 방식

- R8-1: 새 규칙은 `compact`·`sql` 둘 다에 넣고 `current`는 지움. 둘 다 사이클 11 결과 비교를 통과하지 못하면 `current`를 남기고 새 규칙도 넣음 [확정] (ADR-0079 덧붙임)
- R8-2: 두 방식의 새 규칙 결과가 같은지 사이클 11 R-B5와 같은 방식(같은 사본, 책마다 비교, 번호까지)으로 확인 [확정] (ADR-0079 덧붙임 "감수하는 점")
- R8-3: dev는 사이클 11 측정 전에 새 규칙 코드·테스트·비교 도구를 시작함(측정 중인 코드를 건드리지 않게 별도 작업 폴더). 실데이터 dry run·가져오기와 `current` 지우기는 측정 뒤 [확정] (사용자: "아니 근데 dev개발 사이클 11측정 안 끝나도 할 수 있지 않아?" → 제안 → "전부 승인", 2026-10-12)

## 상태별 동작

- 로딩·결과 없음·외부 API 오류: 화면은 바뀌지 않음(지금 검색 화면 규칙 그대로)
- 가져오기 실패: 지금 가져오기(사이클 08·11)와 같음 — 바꿔 끼우기 전 실패면 서비스 그대로
- 합쳐짐·나뉨으로 사라진 번호의 주소: "책을 찾을 수 없어요"(지금 그대로, 안내표 없음) [확정] (ADR-0062)

## 수용 기준

- AC-1: 새 규칙으로 가져온 뒤 「상법총칙 상행위」(박영사)를 검색하면 2014·2015·2020년 판이 서로 다른 줄로 나오고, 각 줄의 도서관이 그 판을 가진 곳뿐이다
- AC-2: 「햄릿」(저자·출판사 "기타", 북큐브)이 두 줄로 나온다
- AC-3: 「백만장자 마인드」(율리시즈)와 「백만장자 마인드 - 부를 끌어 당기는」이 저자가 같으면 한 줄로 나온다 (한쪽은 사이트 저자 칸이 비어 있어 그 줄은 R4로 따로 남을 수 있음 — 표본은 저자가 있는 줄로 봄)
- AC-4: 「오개념 탈출 프로젝트 - 수학 1」과 「- 수학 2」, 「묘왕동주 1 - 상·중·하」는 따로 나온다
- AC-5: 가져오기 기록에 이어 쓴 번호·새 번호·사라진 번호 수가 있고, R1로 나뉜 책 5권·R3으로 합쳐진 책 5권의 옛 주소가 R7-1대로 열린다
- AC-6: `compact`와 `sql`로 같은 사본을 가져온 결과가 책마다 같다(다른 책 0권, 번호까지)
- AC-7: R5 비교 결과(새 도서관 때문에 합쳐진 기존 책 목록과 표본 확인)가 dev `plan-feedback.md`에 있다
- AC-8: 바꾸기 전후 책 수가 기록에 있다(기준: 1,619,668)

## 비목표

- 검색 화면·책 화면 모양 바꾸기(예: 판 목록을 한 화면에 묶어 보여 주기) — 이번 슬라이스는 묶기 규칙만
- 대표 제목·대표 출판일 고르는 규칙 바꾸기 — 그대로 (`same-book-isbn.md` 5.2)
- 회원이 저장한 책 번호 고쳐 쓰기 — 저장 기능이 아직 없음 (ADR-0062)
