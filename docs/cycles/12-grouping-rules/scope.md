## 앞 사이클 (11) 상태와 미결

- 사이클 11은 dev가 측정(11단계) 중. 끝난 부분(A 가져오기 따로 하기 전부, B 세 묶는 방식 구현)은 중간 회고 `../11-separate-import/retro.md`(2026-10-12, 근거 dev `plan-feedback.md` "# 사이클 11" 중간 전달 `ac26ee2`)와 `docs/current/`에 반영함
- **미결 (사이클 11 최종 회고 때)** [확인 필요]
  - 11단계 측정 결과: 세 방식(`current`·`compact`·`sql`) × 여섯 관점 × 두 번, 결과 비교(다른 책 0권인지), 옛 사본 한 번
  - 기본 묶는 방식 고르기(R-B7: 결과 비교 통과 + 43분 안 + 힙이 가장 작은 것) — 사용자가 정함
  - dev 코드 대조(`PgTools`·`ImportTransfer`·`CompactGrouping`·`SqlGrouping`)
- **이 사이클에 걸리는 것**: 새 묶기 규칙은 `compact`·`sql` 둘 다에 넣고 `current`는 지움. 단 측정에서 둘 다 결과 비교를 통과하지 못하면 `current`를 남기고 새 규칙도 넣음 (ADR-0079 덧붙임, 사용자 승인 2026-10-12). 그래서 **dev 개발 시작은 사이클 11 측정과 기본 방식 결정 뒤** [안]. plan의 spec·flow·설계는 먼저 진행

## 목표 (한 문장) [안]

같은 책은 한 권으로, 판이 다른 책·서로 다른 책은 따로 보이도록 책 묶기 규칙을 고치고, 다시 가져와도 책 주소(`/books/{bookId}`)가 규칙대로 이어지는지 확인한다.

## 포함 — 방향은 정해짐 (`../../research/ebook-catalog/same-book-isbn.md` 5.5절, 사용자 승인 2026-10-12)

1. **판이 다른 책 나누기** (Q2): 두 책의 계산한 종이책 ISBN이 둘 다 있고 서로 다르면 네 번째 단계(같은 글자)에서 합치지 않음. ISBN을 모르는 쪽은 지금처럼
2. **자리 채움 값** (Q3): 저자·출판사가 "기타" 같은 자리 채움 값이면 값 없음으로 보고 네 번째 단계에서 합치지 않음. 값 목록은 spec에서 정함
3. **부제·시리즈 표시** (Q4): 부제와 앞 시리즈 표시를 떼고 비교하되 권 번호가 다르면 합치지 않음. dev dry run 표본으로 확인
4. **저자 없음** (Q5): 저자가 없으면 합치지 않는 지금 규칙 유지. "편"·"엮음"만 있는 경우를 저자로 읽을지는 코드 확인 뒤 다시 질문
5. **사이클 07에서 새로 넣은 도서관 2,394곳의 책이 이어 붙인 것** (Q6): 그 도서관들을 넣고 뺀 두 묶기 결과를 dry run으로 비교해 잘못 합친 것만 고침. 1~3 뒤에
6. **ISBN API 표본** (Q7): 국립중앙도서관 ISBN API로 ISBN 모르는 책 100권 안팎을 확인. 의미 있으면 국가서지(③) 다음 단계로 씀 (사용자: "만약에 유의미하게 의미가 있다고 하면 국가서지 다음에 국립중앙도서관 isbn api를 사용하는 걸로 하자")
7. **책 번호 확인** (Q8): 규칙을 바꾼 가져오기에서 합쳐지고 나뉜 책의 번호가 ADR-0062 규칙(가장 많이 겹치는 옛 번호, 합쳐지면 가장 작은 번호)대로 갔는지 가져오기 로그와 표본으로 확인
8. **묶는 방식 정리**: `compact`·`sql`에 새 규칙, `current` 지움(조건은 위). 두 방식 결과 비교(사이클 11 R-B5와 같은 방식)

## 제외 (backlog에 있음)

- 회원이 저장한 책 번호를 옛 → 새로 고쳐 쓰기 — 책 저장 기능(알림) 사이클에서 (ADR-0062 결과)
- ISBN API를 서비스에 상시 연결 — 6번 표본 결과를 본 뒤 따로 질문
- `48090…` 번호(교보 자체 번호로 보임)와 대표 출판일 규칙은 그대로 (`same-book-isbn.md` 5.4·결정 페이지 카드 8)
- 정해진 때마다 자동 갱신, 수집기를 dev로 옮기기(사이클 13)

## 완료 기준 (사용자가 화면에서 확인할 수 있는 것) [안]

- 「상법총칙 상행위」(박영사)를 검색하면 2014·2015·2020년 판이 따로 나오고, 각 줄은 그 판을 가진 도서관만 보인다
- 「햄릿」(저자·출판사 "기타")처럼 자리 채움 값으로 합쳐졌던 다른 전자책이 따로 나온다
- 「백만장자 마인드」와 「백만장자 마인드 - 부를 끌어 당기는」처럼 부제만 다른 같은 책은 한 줄로, 「오개념 탈출 프로젝트 - 수학 1」·「- 수학 2」처럼 권이 다른 책은 따로 나온다
- 규칙을 바꾸기 전에 열어 둔 책 주소(`/books/{bookId}`)를 다시 열면, 나뉜 책은 소장이 더 많이 겹치는 쪽 판이, 합쳐진 책은 합쳐진 책이 열린다
- 가져오기 기록에 이어 쓴 번호·새 번호·사라진 번호 수가 남는다
