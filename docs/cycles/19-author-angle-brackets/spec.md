## 사용자 이야기

- 책을 찾는 사람은 같은 책이 검색 결과에 한 줄로 보이길 바란다. 도서관마다 저자를 「<모리세 시게토모> 저」, 「모리세 시게토모」, 「김근아 저자」처럼 다르게 적어도 그 책을 가진 도서관이 한 줄에 모여야 어디서 빌릴지 고를 수 있다
- 저자 이름으로 찾는 사람은 꺾쇠·괄호·붙은 역할 낱말 표기로 적힌 책도 보통 표기처럼 찾고 싶다 (예: "김정은", "루이스 캐럴")
- 책 화면을 보는 사람은 저자 칸에 「<김정은>」 같은 기호 없이 이름만 보고 싶다
- 운영자는 첫 공개 전에 고친 규칙으로 책 목록을 한 번 다시 가져와, 공개 첫날부터 같은 책이 모인 목록을 내고 싶다

## 동작 규칙

### R1. 저자 정리 (`catalog.normalize` — 저장할 사람 이름, 비교용 이름, 저자 검색어에 같이 쓰임)

- R1-1. 꺾쇠: 저자 칸의 `<`·`>`를 뗀다. 넓은 꺾쇠 `＜`·`＞`도 같다(비교용 글자 바꿈 NFKC에서 같은 글자가 됨) [확정] (범위 결정 #1). 짝이 맞지 않는 꺾쇠(「＜율곡 이이,신사임당 저/이근오 편」)도 글자를 하나씩 뺀다 [확정] (사용자 승인, 2026-10-15, [명세 결정](easy/2026-10-15-spec-decisions.html) #2)
  - 예: 「<김정은>,<김지혜> 저」 → 사람 「김정은」(지은이), 「김지혜」(지은이). 「<모리세 시게토모> 저/<이민연> 역」 → 「모리세 시게토모」(지은이), 「이민연」(옮긴이)
- R1-2. 다른 괄호 `〈 〉`·`「 」`·`《 》`는 괄호 표시만 떼고 안의 글자는 남긴다. `[ ]`는 그대로 둔다 [확정] (사용자, 2026-10-15, 확인 결과 결정 #2)
  - 예: 「KBS 〈슈퍼차이나〉 제작팀」 → 「KBS 슈퍼차이나 제작팀」. 「존 버거 [지음]」 → 그대로
- R1-3. 역할 낱말 뒤 띄어쓰기가 빠진 표기: 한 덩이가 `앞 이름 + (저|저자|지음|지은이|글) + 한글 2~4자 + (역|옮김|옮긴이|번역|역자|그림)`이면 두 사람으로 나눈다. 그 뒤에 다시 `한글 2~4자 + (감수|편집|엮음|편|기획|해설|그림|사진|역|옮김)`이 붙으면 셋째 사람까지 나눈다. 붙은 낱말 앞에 역할 낱말이 이미 따로 적혀 있으면 자르지 않는다(보호 장치) [확정] (세 원인 #3, 확인 결과 결정 #5)
  - 예: 「루이스 캐럴 저이소연 역」 → 루이스 캐럴(지은이), 이소연(옮긴이). 「마키타 겐지 저전선영 역강재헌 감수」 → 마키타 겐지(지은이), 전선영(옮긴이), 강재헌(감수). 「발터 글라소프 글/…」 → 자르지 않음
- R1-4. 저자 검색어도 R1-1·R1-2와 같이 정리한다: 사용자가 "<김정은>"이나 "KBS 〈슈퍼차이나〉"로 찾아도 정리된 이름과 맞음 [확정] (사용자 승인, 2026-10-15, [명세 결정](easy/2026-10-15-spec-decisions.html) #3)
- R1-5. 책 화면 저자 칸(대표 저자 표기)도 R1-1·R1-2로 정리한 글을 보인다. 대표 저자는 지금처럼 묶음 안에서 가장 많은 도서관이 쓴 원문 표기를 고르고(dev `I/BookGrouping.java` 351·385행, 예: 「백만장자 마인드」는 「모리세 시게토모」 76줄 > 꺾쇠 표기 5줄), **가져올 때 책 표 저자 칸(`book.author_display`)에 기호를 뗀 글을 넣는다**. R1-3에 걸린 붙은 역할 표기는 같은 때 역할 낱말 뒤를 띄어 넣는다(「밥 프록터 저이재경 역조성희 감수」 → 「밥 프록터 저 이재경 역 조성희 감수」, 보호 장치로 빠진 표기는 그대로) [확정] (사용자: "고쳐 주는게 좋지 않을까? 이거 추가하는 것도 그렇게 어렵지 않아 보이는데", 2026-10-15, [화면 흐름 결정](easy/2026-10-15-flow-decisions.html) #1 미승인) — 화면 코드는 바꾸지 않음 [확정] (사용자 승인: "그래", 2026-10-15, [명세 결정](easy/2026-10-15-spec-decisions.html) #4)
  - 예: 묶음에서 「<김정은>,<김지혜> 저」가 가장 많아도 화면에는 「김정은,김지혜 저」

### R2. 같은 책 묶기 (`collection` 가져오기, 세 묶는 방식 `compact`·`objects`·`sql` 모두 같은 결과)

- R2-1. 첫 저자는 R1로 정리한 이름을 쓴다 → 꺾쇠·다른 괄호·붙은 역할 낱말 때문에 갈렸던 책이 모임 [확정]
- R2-2. 제목 앞 괄호: 같은 책을 견줄 제목(④ 비교 제목)에서만 맨 앞 괄호 `( … )` 하나를 뗀다. 화면 제목·제목 검색은 그대로 [확정] (세 원인 #2, 근거 KORMARC 245 "표제 배열", https://librarian.nl.go.kr/kormarc/KSX6006-0/sub/20X_24X_245.html, 확인 2026-10-15)
  - 떼지 않는 괄호 낱말 [확정] (확인 결과 결정 #3): 판(개정판·개정2판·증보·증보판·4판·리커버·2nd EDITION·4th EDITION), 원서·번역(영어원서·영어 원서·영문 번역판·한영대역·원문·완역·고본완역), 형태(오디오북·전자책·체험판·무료체험판·만화·큰글자책), 뒷권(속)
  - 맞추는 법: 괄호 안 글자를 공백 무시하고 목록 낱말과 같으면 남긴다. 목록 밖이라도 "…판"으로 끝나거나 "EDITION"이 들어 있으면 판으로 보아 남긴다 [확정] (사용자 승인, 2026-10-15, [명세 결정](easy/2026-10-15-spec-decisions.html) #5). 까닭: 같은 책 견주기의 판 낱말 목록(개정·증보·특별판 등 11개, dev `I/SameTextKey.java` 42행)은 「(3판)」(75줄)·「(제2판)」(83줄)을 못 잡음
  - 떼고 남는 제목이 비면 떼지 않는다 [확정] (research.md (b)-1)
  - 예: 「(부를 끌어 당기는) 백만장자 마인드」 ↔ 「백만장자 마인드」 같은 책으로 견줌. 「(만화) 삼국지」 ↔ 「삼국지」 따로
- R2-3. 공급사 상품 코드가 같으면 저자를 보지 않고 같은 책으로 본다 [확정] (확인 결과 결정 #4)
  - 같은 코드로 보는 값: 북큐브 줄의 공급사 코드, 교보 화면 줄의 상품 번호, YES24 화면 줄의 상품 번호 (예: 목원대 북큐브 1210492004114 = 명지대·부천 교보 1210492004114, 전주 북큐브 108608605 = YES24 108608605)
  - **같은 공급사의 코드끼리만 견준다. 제목 조건은 두지 않는다** [확정] (사용자: "같은 공급사의 코드끼리만 견주고, 제목 조건은 두지 않습니다. 이걸로 해줘", 2026-10-15, [명세 결정](easy/2026-10-15-spec-decisions.html) #6). 까닭: 9자리 번호를 북큐브 자체 코드와 YES24 상품 번호가 함께 써서 공급사를 안 보면 다른 책끼리 같은 번호가 됨([research.md](research.md) "공급사 코드 모양")
  - 줄마다 (공급사 묶음, 코드) 짝으로 본다. 공급사 이름은 화면마다 달라(「교보문고」·「교보 전자책」·「(주)교보문고」, 「YES24」·「예스이십사」·「YES24 전자책」, 「와이투북스」·「Y2Books 전자책」 등) 같은 공급사로 묶는 이름 목록을 dev 규칙 파일에 둔다. 공급사가 비어 있는 줄은 코드로 모으지 않는다 [확정] (같은 결정). 목록 내용은 dev가 수집 DB의 공급사 이름으로 만들고 plan에 보고 [확인 필요: dev]
- R2-4. 저자·출판사가 뒤바뀐 세 도서관(수집 번호 11·12·15)은 가져올 때 두 칸을 바꿔 읽는다. 도서관 번호는 dev 규칙 파일(`scripts/library/rules/` 꼴)에 적고, 고친 수집기로 새로 받은 사본을 가져올 때 지운다 [확정] (세 원인 #5)

## 수용 기준

- AC-1: 「채널 전쟁」(청림출판), 「다재다능 코틀린 프로그래밍」(영진닷컴)처럼 꺾쇠 표기 줄과 보통 표기 줄이 있던 책을 제목으로 찾으면 → 검색 결과에 한 줄로 보인다
- AC-2: 「백만장자 마인드」(율리시즈)를 찾으면 → 「모리세 시게토모」, 「<모리세 시게토모> 저/<이민연> 역」, 「김근아 저자」(상품 코드가 같은 줄), 「(부를 끌어 당기는) 백만장자 마인드」, 저자·출판사가 뒤바뀌었던 대구·경기도교육청 줄이 같은 책으로 모인다. 괄호 없이 수식어를 붙인 「부를 끌어 당기는 백만장자 마인드」 줄은 따로 남는다(backlog)
- AC-3: 저자 "김정은"으로 단어 검색과 정확히 일치 검색을 하면 → 꺾쇠 표기였던 책이 둘 다 나온다
- AC-4: 꺾쇠·다른 괄호 표기였던 책의 상세 화면을 열면 → 저자 칸에 `<`·`>`·`〈`·`〉`·`「`·`」`·`《`·`》`가 없다. `[ ]`가 있던 「존 버거 [지음]」 같은 표기는 그대로다
- AC-5: 「슈퍼차이나」(가나출판사)를 찾으면 → 「KBS 〈슈퍼차이나〉 제작팀」 줄과 「KBS 슈퍼차이나 제작팀」 줄이 한 줄로 보인다
- AC-6: 「(만화) 삼국지」와 「삼국지」, 「(개정판) X」와 「X」, 「(속) 에이번리 연대기」와 「에이번리 연대기」는 → 따로 보인다 (저자·출판사가 같아도)
- AC-7: 저자 "루이스 캐럴"로 찾으면 → 「루이스 캐럴 저이소연 역」 표기 책이 나오고, 역할 옮긴이로 "이소연"을 찾아도 나온다. 「마키타 겐지 저전선영 역강재헌 감수」 표기는 사람 표(`book_contributor`)에 지은이(AUTHOR)·옮긴이(TRANSLATOR)·감수(OTHER — 지금 역할 낱말 표 `Contributors.ROLE_WORDS` 54행 그대로) 세 줄로 저장된다 (`ContributorsTests`로 확인; 책 화면은 대표 저자 한 줄만 보여 주므로 역할별 이름은 검색·시험으로 확인, 2026-10-15 고침)
- AC-8: 「발터 글라소프」처럼 보호 장치에 걸리는 외국 이름은 → 잘리지 않고 그대로 한 사람이다 (단위 시험 + 표본)
- AC-9: 대구전자도서관·경기도교육청·전북교육청 줄의 책을 보면 → 저자 칸에 사람 이름, 출판사 칸에 출판사가 있다(예: 「백만장자 마인드」 저자 「모리세 시게토모」, 출판사 「율리시즈」). 저자 "율리시즈"로 찾으면 이 책이 저자로 나오지 않는다

## 비목표

- 화면 모양 바꾸기 — 저자 칸 글이 바뀌는 것 말고는 없음 [확정] (scope 제외)
