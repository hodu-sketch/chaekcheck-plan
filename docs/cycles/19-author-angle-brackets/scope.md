## 목표 (한 문장) [안]

저자를 「<김정은>,<김지혜> 저」, 「<모리세 시게토모> 저/<이민연> 역」처럼 꺾쇠로 쓴 줄도 첫 저자가 「김정은」, 「모리세 시게토모」로 읽히게 저자 정리를 고쳐, 같은 책이 한 줄로 모이고 저자 이름 검색에서도 보통 표기와 똑같이 찾히게 한다.

## 포함

1. 저자 정리 규칙(`catalog.normalize`의 `Contributors`, 검색어 정리에도 쓰임)에서 이름을 감싼 꺾쇠를 다룸 [확정] (사용자 승인, 2026-10-14, 결정 페이지 #1). 넓은 꺾쇠 `＜ ＞`도 같은 글자로 보아 함께 뗌. 다른 괄호 `〈 〉`·`「 」`·`《 》`는 사람 이름이 아니라 단체 이름 안의 프로그램·잡지 이름을 감싸므로(수집 DB 6,006·386·107줄), **괄호 표시만 떼고 안의 글자는 남김** [확정] (사용자: "〈 〉 「 」 《 》의 괄호 표시만 떼고 글자는 남김 으로 하자", 2026-10-15, [확인 결과 결정](easy/2026-10-14-check-results-decisions.html) #2 미승인). 근거: 괄호 표시만 떼면 같은 책의 저자 표기 36쌍이 같아짐([research.md](research.md) "다른 괄호를 떼면"). `[ ]`(8,165줄, 「존 버거 [지음]」·「김구 [金九]」)는 사용자가 고른 목록에 없어 그대로 둠 [확정] (같은 결정). 처음 범위 결정 #3 "실제로 있으면 같이 뗌"을 이것으로 바꿈
2. 고친 규칙으로 내 PC에서 책 목록을 다시 가져옴 [확정] (사용자 승인, 2026-10-14, 결정 페이지 #1; ADR-0069 "정리 규칙을 바꿀 때 다시 가져옴")
3. 운영 역할 DB에 반영 — 사이클 11 방식(내 PC 내보내기 → 운영 `apply`, ADR-0078) [확정] (사용자 승인, 2026-10-14, 결정 페이지 #1)
4. 순서: 사이클 19 반영 → 사이클 17 첫 배포 [확정] (사용자 승인, 2026-10-14, 결정 페이지 #1)
5. 바뀐 결과(책 수, 합쳐짐·나뉨, 표본, 「백만장자 마인드」 줄 수)는 사이클 12 숫자가 아니라 **사이클 18 B 가져오기 결과(복사본 DB, 같은 2026-10-12 사본·같은 도서관 목록)**와 비교 (사용자 승인, 2026-10-15, [확인 결과 결정](easy/2026-10-14-check-results-decisions.html) #8)
6. 꺾쇠가 아닌 원인 셋도 이번에 함께 고침: 저자 칸에 다른 이름이 적힌 줄(「김근아 저자」), 제목 앞 괄호로 본제목이 달라지는 줄(「(부를 끌어 당기는) 백만장자 마인드」), 역할 낱말 뒤 띄어쓰기가 빠진 표기(「루이스 캐럴 저이소연 역」) [확정] (사용자: "같이 고치자", 2026-10-14, [범위 결정](easy/2026-10-14-scope-decisions.html) #2 미승인). 고치는 방법 ([research.md](research.md)):
   - 다른 이름 저자 줄: 확인 결과 목원대 북큐브 「김근아 저자」 줄의 공급사 코드 1210492004114가 명지대·부천 교보 줄(저자 「모리세 시게토모」)의 상품 번호와 같음 → **같은 공급사의 상품 코드가 같으면 저자를 보지 않고 모음** (공급사별로 견줌, 제목 조건 없음 [확정] 명세 결정 #6, ADR-0114) (같은 날·제목·출판사로 모으는 방법은 쓰지 않음) (사용자 승인, 2026-10-15, [확인 결과 결정](easy/2026-10-14-check-results-decisions.html) #4). 코드가 다른 책을 가리키는 경우가 없는지는 dev가 해 볼 때 셈([research.md](research.md) SQL 2)
   - 제목 앞 괄호: 책 묶기 비교 제목에서만 앞 괄호를 떼고, 책 종류 괄호((만화)·(큰글자책)·(영문판)·(오디오북) 등)는 떼지 않음. 화면 제목·검색은 그대로 [확정] (사용자 승인, 2026-10-14, [세 원인](easy/2026-10-14-extra-causes-decisions.html) #2). 근거: KORMARC 245 "표제 배열"은 관제를 원괄호에 묶고 정렬·배열에서 제외할 수 있음 [확정] (https://librarian.nl.go.kr/kormarc/KSX6006-0/sub/20X_24X_245.html, 확인 2026-10-15). 떼지 않을 낱말 목록 (사용자 승인, 2026-10-15, [확인 결과 결정](easy/2026-10-14-check-results-decisions.html) #3): 판(개정판·개정2판·증보·증보판·4판·리커버·2nd EDITION·4th EDITION 등), 원서·번역(영어원서·영어 원서·영문 번역판·한영대역·원문·완역·고본완역), 형태(오디오북·전자책·체험판·무료체험판·만화·큰글자책), 뒷권(속). 목록은 공식 규칙에 없어 수집 데이터로 plan이 고른 것이고, dev가 해 볼 때 합쳐진 책 표본으로 다시 확인해 빠진 낱말을 더함
   - 역할 낱말 띄어쓰기: 좁은 규칙(저·지음·글 + 한글 2~4자 + 역·옮김·그림) + 보호 장치(붙은 낱말 앞에 역할 낱말이 이미 따로 적혀 있으면 자르지 않음) [확정] (사용자: "좁은 규칙 + 보호 장치로 해", 2026-10-14, [세 원인](easy/2026-10-14-extra-causes-decisions.html) #3). 실험(수집 사본 2026-10-12, 읽기 전용): 걸린 567가지·1,303줄 중 외국 이름 10가지·39줄(「발터 글라소프」 등)은 보호 장치로 빠지고 557가지·1,264줄이 잘림. 둘째 이름 뒤 감수·편집 등이 또 붙는 모양(「마키타 겐지 저전선영 역강재헌 감수」, 수집 DB 40줄·32가지)도 같은 좁은 규칙을 한 번 더 이어 셋째 역할(감수·편집·엮음·편·기획·해설·그림·사진·역·옮김)까지 자름 (사용자 승인, 2026-10-15, [확인 결과 결정](easy/2026-10-14-check-results-decisions.html) #5)
