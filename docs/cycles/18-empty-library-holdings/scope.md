## 포함 [확정] (사용자 승인, 2026-10-14, 범위 결정 #4~#7, 조사 결정 #1~#5, 설계 결정)

   - 국회도서관 44·군포시도서관 261·김천시립도서관 269 — 사이클 13의 "서비스에서는 그대로 켜 둠"(사용자, 2026-10-12)을 바꿈. 군포는 46번 군포시중앙도서관과 같은 사이트로 넘어감을 확인

4. 끄는 방법: `library`의 Liquibase 변경 파일 ([ADR-0109](../../adr/0109-disable-libraries-by-liquibase.md))
5. 새 도서관 넣기 명령(사이클 13)이 가져올 전자책 줄이 0인 곳은 "전자책 0권"으로 뺌 (조사 결정 #2, [ADR-0110](../../adr/0110-library-insert-skips-zero-ebook-sites.md))

7. 비율 0.7 이상 6곳은 덜 모인 것이 아님(사이트 권수에 오디오북·동영상 책 포함) → 기록만 (조사 결정 #5)
