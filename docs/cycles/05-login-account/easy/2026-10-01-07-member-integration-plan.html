1모듈 구성도 (05b 뒤)

auth는 아무 모듈에도 기대지 않습니다. member는 auth(현재 계정, 계정 삭제 이벤트)와 library·region을 읽습니다. catalog·availability는 둘 다 모릅니다.

2결정된 것 세 가지 (사용자, 2026-10-01)

이유는 따로 말씀하지 않아서 문서에는 [이유 미확인]으로 적었습니다. 이유를 알려 주시면 그대로 옮깁니다.
무엇결정뜻
모듈auth + member 둘인증(외부 로그인·세션·탈퇴)과 회원 자료(지역·도서관)를 처음부터 다른 모듈로. 나중에 서비스로 나눌 때 그대로 둘
검색 연결웹이 파라미터로웹이 /me로 지역·직접 추가 목록을 받아 기존 지역 파라미터 + scope=joinable + 새 칸 libraryIds로 보냄. 검색 모듈은 회원을 모름
사이클05a 로그인·계정 → 05b 내 도서관·검색 연결 → 06 알림05a에서 인증 위험(검수·세션·탈퇴)을 먼저 끝냄. 05b에서 "로그인하면 내 도서관이 저장되고 검색에 쓰임"

3사이클마다 들어가는 것

05a는 계정만, 05b는 저장과 검색 연결, 06은 알림입니다.
사이클모듈들어가는 것보이는 것
05aauth네이버·카카오 로그인, 서버 세션, 동의 화면·처리방침 페이지, 로그아웃, 탈퇴(연결 끊기 → 삭제 → 세션 종료), 카카오 웹훅, 계정 삭제 이벤트, CSRF, 네이버 검수 준비로그인 버튼, 로그인 상태, 계정 절
05bmember + 기존 검색에 칸 하나지역 저장(브라우저 값을 서버로 옮기기), 직접 추가 도서관, libraryIds, 설정 창 "내 도서관", "내 도서관만" 스위치, 계정 삭제 이벤트 처리로그인하면 내 도서관이 저장되고 검색에 바로 쓰임
06notification + member(관심 책)관심 책, 상세 페이지 주기 읽기(v1), 전달 수단, 알림 끄기관심 책 표시, 알림 받기
