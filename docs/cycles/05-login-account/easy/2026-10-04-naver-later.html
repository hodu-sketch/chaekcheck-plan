2네이버와 카카오의 차이

카카오는 검수가 없어 공개하는 날 바로 누구나 됩니다. 네이버는 검수를 통과해야 누구나 됩니다.
카카오네이버
만들고 시험하는 동안아무 계정이나 됨멤버관리에 등록한 아이디만 됨
공개한 뒤 누구나 로그인바로 됨검수 승인 뒤에 됨
검수에 내는 것없음로그인부터 가입까지의 화면 캡처, 또는 서비스를 열기 전이면 기획서. 2~3 영업일

검수를 통과하지 않은 채 공개하면, 네이버 버튼을 누른 일반 사용자는 로그인하지 못합니다. 그래서 공개하는 날 네이버 버튼을 보여 주려면 그 전에 검수가 끝나 있어야 합니다.

네이버 API 설정 화면: "애플리케이션이 '개발 중' 상태이면 [멤버관리] 탭에서 등록한 아이디만 네이버 로그인을 이용할 수 있습니다. … 검수가 승인되면 모든 아이디로" (사용자가 붙여 준 화면 글, 2026-10-04). 검수 제출물과 기간: research.md 데이터 출처(네이버 검수 가이드, 2026-10-01 확인)

dev가 만드는 것네이버·카카오 둘 다. 설정으로 로그인 창에 보일 제공자를 고름카카오만. 네이버 쪽 코드(로그인, 탈퇴 본인 확인, 연결 끊김 알림의 암호 확인)는 만들지 않음둘 다. 항상 둘 다 보임
공개하는 날네이버 검수가 안 끝났으면 카카오만 켜서 공개. 검수가 끝나면 설정만 바꿔 네이버를 켬카카오만네이버 검수가 끝날 때까지 공개를 미루거나, 눌러도 안 되는 버튼을 둔 채 공개
네이버를 여는 데 드는 일설정 한 줄사이클을 하나 더 돌려 만들고 시험함없음
네이버 검수화면 캡처로 신청할 수 있음(멤버 아이디로 실제 화면을 찍음)기획서로 신청하거나, 나중에 만든 뒤 신청화면 캡처로 신청
이번에 드는 일설계대로 + 설정 하나가장 적음설계대로

"나"가 이번 일을 가장 줄입니다. 다만 네이버 쪽은 이미 설계와 조사가 끝나 있고(연결 끊김 알림의 암호 세부까지), 앱 등록도 마쳤습니다. 지금 함께 만들면 같은 구조 안에서 한 번에 시험할 수 있고, 나중에 따로 만들면 탈퇴와 정리 작업을 다시 건드려야 합니다.

1"가": 네이버와 카카오를 둘 다 만들고, 로그인 창에 보일 제공자를 설정으로 고름 [확정]

오늘 정하신 "로그인 기능 전체를 켜고 끄는 설정"(ADR-0046)에 제공자별 설정을 하나 더합니다. 예를 들어 카카오만 켜 두면 로그인 창에 카카오 버튼만 보이고, 네이버 쪽 주소는 동작하지 않습니다. 공개하는 날에는 카카오만 켜고, 네이버 검수가 끝나면 네이버를 켭니다.

인계서는 이미 dev에 넘겼으므로, 승인하시면 인계서에 이 항목을 더하고 수용 기준을 하나 더합니다("제공자 설정에서 뺀 제공자는 로그인 창에 보이지 않고 그 주소는 동작하지 않는다").

다른 선택: "나"(카카오만 만듦. 인계서에서 네이버 부분을 빼고 backlog로 옮김), "다"(바꾸지 않음). 고르시려면 미승인이나 기타에 "나" 또는 "다"라고 적어 주세요.
