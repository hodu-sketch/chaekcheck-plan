1조사 결과 다섯 가지

네이버 콜백 방식과 버튼 규칙은 확인이 끝났습니다. 나머지 셋은 개발할 때나 배포 전에 확인합니다.
무엇결과상태
PKCE(로그인 요청에 붙이는 추가 확인 값)네이버는 OIDC 방식 문서에 PKCE 파라미터가 있습니다. 카카오는 문서에 없습니다. 그래서 카카오는 끄고 state 값으로 막고, 네이버는 개발할 때 실제로 보내 보고 되면 켭니다개발 때 시험
네이버에서 식별자만 받기앱을 등록할 때 받을 정보를 고릅니다. 아무것도 안 고르면 식별자만 오는지는 문서에 없습니다. 네이버 개발자센터 화면에서 직접 봐야 합니다. 닉네임이 같이 오더라도 저장하지 않습니다사용자가 화면 확인
네이버 "연결끊기 Callback" 방식네이버가 우리 주소로 POST를 보냅니다. 서명(HmacSHA256)을 확인하고, 암호화된 이용자 번호(AES)를 풀어 그 계정을 지운 뒤 204로 답합니다. 네이버는 실패해도 다시 보내지 않습니다. 원문을 그대로 확인했습니다확인 끝
로그인 버튼 규칙카카오는 노란 바탕(#FEE500)·말풍선·"카카오 로그인". 네이버는 지정된 녹색·로고. 두 버튼을 같은 크기로 나란히 두고, 우리 색으로 바꾸지 않습니다확인 끝
약관·처리방침 글, 보호책임자개인정보보호위원회가 낸 「개인정보 처리방침 작성지침(2025.4.)」을 따라 씁니다(PDF는 아직 안 읽음). 보호책임자는 어느 경우든 운영자 본인을 적으면 됩니다배포 전 글 검토

2화면 흐름

새 화면은 넷입니다: 로그인 선택(S5), 가입 동의(S6), 탈퇴 안내(S7), 약관·처리방침(S8·S9). 검색 화면(S1)과 설정 창(S4)에는 버튼만 더합니다.
화면하는 일
S1 검색 (바뀜)위 오른쪽에 "로그인", 로그인하면 같은 자리에 "로그아웃". 제공자 이름·닉네임은 안 보임
S5 로그인 선택 (새)작은 창에 네이버·카카오 버튼 둘
S6 가입 동의 (새)수집 고지 표와 확인란 셋(이용약관, 개인정보 수집·이용, 만 14세 이상). 셋 다 표시해야 "가입". 가입 전에는 아무것도 저장 안 함
S4 설정 창 (바뀜)"계정" 절에 로그아웃·탈퇴
S7 탈퇴 안내 (새)지워지는 것과 되돌릴 수 없음을 알리고, 제공자 화면에서 한 번 더 본인 확인
S8·S9 (새)이용약관, 개인정보 처리방침 전문. 로그인 없이 열림
