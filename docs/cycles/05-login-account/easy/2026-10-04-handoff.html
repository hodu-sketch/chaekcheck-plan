dev에 넘길 인계서가 나왔습니다.
넘기기 전에 정하실 것이 일곱 가지입니다.

인계서는 dev 프로젝트가 읽고 그대로 만드는 문서입니다(2026-10-04). 인계서 담당 에이전트가 설계 문서와 dev 코드를 읽고 썼습니다. 쓰면서 문서끼리 어긋난 곳 여섯과 설계에 답이 없는 곳 넷을 찾았습니다. 어긋난 곳 가운데 넷은 제가 바로잡았고, 나머지는 정하실 일이라 아래에 적었습니다.

1인계서에 담긴 것

dev가 17단계로 만듭니다. 맨 먼저 "켜고 끄는 설정"을 만들어, 꺼져 있으면 지금 서비스와 똑같이 동작하는 상태를 지키면서 쌓아 갑니다.
단계만드는 것위험
1~2라이브러리 넷, 켜고 끄는 설정, DB 표중간
3~4보안 설정, 토큰 확인, 토큰 내주기와 새로 받기, 로그아웃높음
5~6네이버·카카오 로그인, 가입 동의와 가입, 가입 취소높음
7~8계정 삭제와 "계정 삭제됨" 알림, 탈퇴(다시 로그인)높음
9~10네이버·카카오의 연결 끊김 알림 받기, 하루 한 번 작업 셋(만료 토큰 정리, 카카오 대조, 1년 정리)중간
11~15화면: 로그인 버튼, 로그인 선택 창, 가입 동의, 설정 창의 탈퇴, 탈퇴 안내, 약관·처리방침중간
16운영 웹 서버 설정 예시(보안 헤더)낮음
17실제 네이버·카카오로 수용 기준 21개 확인

"위험"은 잘못 만들면 영향이 큰 정도입니다. 3~8단계는 모든 요청이 지나가거나 계정을 지우는 곳이라 높게 잡혀 있고, 단계마다 자동 테스트가 붙어 있습니다.

dev가 지킬 규칙

규칙내용
조용히 바꾸지 않기설계와 다르게 만들어야 하면 먼저 사용자에게 알리고, 이유를 dev의 기록 파일에 남김
비밀 값키와 시크릿은 환경 변수로만. 코드, 설정 파일, 로그, 대화에 쓰지 않음
사용자에게 묻고 정할 것 셋화면이 로그인 기능이 켜져 있는지 아는 방법, 꺼져 있을 때 DB 표를 만들지, 기록 표용 라이브러리를 어디에 둘지
알고 받아들인 한계버그로 고치지 않고 그대로 둠(로그아웃한 토큰의 15분 등)
기획 저장소고치지 않음

2하실 일

dev가 필요한 주소 문자열을 만들어 드립니다. 키는 환경 변수로만 전달합니다.
할 일언제dev에 알려 줄 것
네이버 앱 등록, 돌아올 주소 두 줄 넣어 보기, 테스터 아이디 등록5단계 전두 줄이 모두 받아지는지
카카오 앱 만들기, 로그인 켜기, 돌아올 주소 두 줄, 시크릿 켜기. 동의항목은 켜지 않음5단계 전두 줄이 모두 받아지는지
네이버 제공 항목 화면에서 아무것도 고르지 않으면 회원번호만 오는지 보기13단계 전화면에서 본 것
카카오의 두 어드민 키가 같은 키인지 보기9단계 전같은지 다른지
카카오 웹훅 주소, 네이버 연결끊기 주소, 카카오 처리방침 주소 등록공개 주소가 생긴 뒤카카오 웹훅이 POST로 되는지
이용약관·처리방침·동의 문구 검토, 문서 버전(시행 날짜) 정하기배포 전문구와 버전

앱 등록 전에도 dev는 가짜 응답으로 자동 테스트를 돌리며 5~10단계를 만들 수 있습니다. 실제 로그인 확인과 17단계만 앱 등록을 기다립니다.

3인계서를 쓰다 찾은 어긋남

여섯 가운데 넷은 문서 표현의 문제라 바로잡았습니다. 둘은 정하실 일입니다(아래 1, 2번).
어긋난 곳처리
명세 한 곳에 "요청마다 DB를 읽지 않는다"가 남아 있었음. 정하신 것은 "로그인이 필요한 요청은 계정을 한 번 조회"명세 문장을 고침
범위 문서에 "설정 창 계정 절(로그아웃, 탈퇴)"가 남아 있었음. 정하신 것은 탈퇴만범위 문서의 "바뀐 것" 표에 더함
설계 문서 머리말이 수용 기준을 18개로 적음. 지금은 21개고침
명세의 출처 표에 네이버 알림의 암호 세부가 "확인 필요"로 남아 있었음. 10월 1일에 원문으로 확인함고침
버튼 글자가 문서마다 다름아래 1번
"설정 버튼 옆"에 둔다는 로그인 버튼 자리가 실제 화면과 맞지 않음아래 2번

4정해 주실 것 (7가지)

화면 둘, 서버 쪽 둘, 문구 하나, dev 문서 하나, 그리고 인계서 승인입니다.

1로그인 선택 창의 버튼 글자는 "네이버 로그인", "카카오 로그인" [안]

명세에는 "네이버로 로그인"·"카카오로 로그인", 화면 흐름에는 "네이버 로그인"·"카카오 로그인"으로 적혀 있었습니다. 카카오의 디자인 지침은 버튼 글자로 "카카오 로그인" 또는 "로그인"만 허용합니다. 그래서 "카카오 로그인"으로 하고, 네이버도 같은 꼴로 맞춥니다.

다른 선택: 카카오는 "카카오 로그인", 네이버는 "네이버로 로그인". 두 버튼의 글자 꼴이 달라집니다.

카카오 로그인 디자인 가이드의 버튼 글자 규칙: research.md 4절 (2026-10-01 확인)

2"로그인" 버튼은 화면 맨 위 줄의 오른쪽 끝에 둠 (상표 "chaekcheck"의 반대편) [안]

화면 흐름 1번에서 "위 오른쪽, 설정 버튼 옆"으로 승인하셨습니다. 그런데 dev 코드를 보니 설정 버튼(⚙)은 맨 위 줄이 아니라 검색 줄 안에 있고, 책 화면에는 ⚙가 없습니다. 제가 화면을 확인하지 않고 "설정 버튼 옆"이라고 적었던 것이 틀렸습니다. "검색 화면과 책 화면 둘 다 같은 자리"를 지키려면 두 화면에 공통으로 있는 맨 위 줄에 두어야 합니다.

검색 화면 (PC·태블릿)

chaekcheck로그인
책 제목, 지은이 검색
⚙

검색 화면 (폰)

chaekcheck로그인
책 제목, 지은이 검색
⚙

책 화면 (폰)

chaekcheck로그인

밑그림입니다. 자리만 보여 줍니다. ⚙는 지금처럼 검색 줄에 남습니다. 로그인하면 같은 자리가 "로그아웃"이 됩니다.

다른 선택: 검색 줄의 ⚙ 옆에 둠. "설정 버튼 옆"이라는 처음 문장과는 맞지만 책 화면에는 그 줄이 없어 버튼을 둘 곳이 따로 필요합니다.

3카카오 대조에서, 대조를 시작한 뒤에 가입한 계정은 그 날 대조에서 뺌 [안]

하루 한 번 카카오에서 "연결된 사용자 목록"을 받아, 우리 쪽에는 있는데 목록에 없는 계정을 지우기로 하셨습니다. 목록을 받는 데는 시간이 걸립니다. 그 사이 새로 가입한 사람은 이미 받은 목록에 없어서 방금 가입했는데 지워질 수 있습니다. 설계에 이 경우가 빠져 있었습니다.

제안: 대조가 목록을 받기 시작한 시각 이후에 만들어진 계정은 그 날 비교에서 뺍니다. 다음 날 대조에서 다시 봅니다.

다른 선택: 더 넉넉하게, 가입한 지 하루가 안 된 계정은 빼기. 규칙이 더 단순하고 안전하지만 놓친 연결 끊김을 하루 늦게 잡습니다.

4하루 한 번 작업 셋은 새벽 4시에 돎 [안]

만료된 토큰 정리, 카카오 대조, 1년 넘게 로그인하지 않은 계정 정리가 하루 한 번 돕니다. 언제 돌지가 정해져 있지 않았습니다. 사용자가 가장 적을 시간으로 새벽 4시(한국 시간)를 제안합니다. 값은 서버 설정으로 두어 바꿀 수 있게 합니다.

알아 두실 점: 새벽 4시는 근거 자료가 있는 값이 아니라 제 제안입니다. 다른 시각이 좋으시면 글 상자에 적어 주세요.

5로그인 기능이 꺼져 있을 때는 약관·처리방침 화면과 화면 아래 링크도 보이지 않음 [안]

로그인 기능을 끄면 로그인 버튼과 설정 창의 "계정" 절이 사라지는 것까지 정하셨습니다. 약관·처리방침 화면과 화면 아래의 두 링크는 정해져 있지 않았습니다. 꺼져 있을 때는 계정이 없고 개인정보를 받지 않으므로, 함께 감추는 것을 제안합니다. 켜면 함께 나타납니다.

다른 선택: 꺼져 있어도 두 화면과 링크는 보임. 로그인을 열기 전에 약관을 먼저 공개해 두고 싶을 때 맞습니다.

6가입 동의 화면의 문구 둘 [안]

상황문구
확인란을 다 표시하지 않고 "가입"을 누르려 할 때, 빠진 항목 옆에"필수 항목이에요"
가입 저장에 실패했을 때"가입하지 못했어요. 잠시 뒤 다시 해 주세요"

화면을 오래 열어 두었을 때의 문구("시간이 지났어요. 처음부터 다시 로그인해 주세요")와 약관이 바뀌었을 때의 문구("약관이 바뀌었어요. 다시 확인해 주세요")는 앞서 승인하신 것을 그대로 씁니다.

다른 선택: 문구를 글 상자에 적어 주시면 그대로 씁니다.

7위 여섯을 반영해 이 인계서를 dev에 넘김 [안]

승인하시면 위 결정을 설계 문서와 인계서에 넣고, 인계서를 dev 프로젝트가 읽는 자리(docs/current/handoff.md)에 놓습니다. 그다음 사이클 05를 "넘김"으로 닫고 커밋을 제안합니다.

인계서에는 dev 문서 수정 요청도 함께 들어갑니다. 이미 넣은 것은 도서관 관리 문서의 깨진 표와 빠진 항목, 절 번호 정리입니다. 여기에 하나를 더 넣으려 합니다. dev의 CLAUDE.md에 "기본 패키지 이름이 아직 정해지지 않았다"는 낡은 줄이 남아 있는데, 실제로는 com.chaekcheck로 정해져 있습니다. 이 줄을 고쳐 달라는 요청입니다. 빼고 싶으시면 글 상자에 적어 주세요.
