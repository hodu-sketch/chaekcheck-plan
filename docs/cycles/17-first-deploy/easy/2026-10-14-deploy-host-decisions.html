첫 배포: 호스트·기간·비밀값 정하기

AWS 신규 계정 무료 크레딧($100~200·6개월)을 쓰기로 하면서 생긴 결정 3가지입니다. 항목마다 승인/미승인/기타를 정해 주세요. 근거는 research.md 12절. (2026-10-14)

1호스트는 EC2 4GB(크레딧)로 [확정] (사용자 승인, 2026-10-14)

첫 배포 서버를 AWS EC2 t4g.medium(램 4GB·서울·Arm)으로 올리고 무료 크레딧으로 결제합니다. 크레딧이면 4GB를 6개월 내내 덮습니다($24×6=$144 < $200).

선택무료 범위비밀값
EC2 t4g.medium 4GB크레딧으로 결제 확실IAM 역할 → 접근 키 없음
Lightsail 4GB무료 평가판은 2GB까지, 4GB는 크레딧 결제(대상인지 콘솔 확인)역할 없음 → 접근 키 필요
Lightsail 2GB(무료 평가판)90일 무료모니터링 빼야 들어감(설계 축소)

추천: EC2 4GB.

2크레딧 한도(최대 6개월)까지, 노트북은 나중에 [확정] (사용자 승인, 2026-10-14)

바뀌는 점: 처음엔 "2주"였습니다. 무료 크레딧을 알게 되어 6개월 한도까지 AWS로 돌리고 집 노트북 이전은 나중에 재검토합니다.

신규 계정 크레딧($100~200)으로 무료 플랜 6개월 또는 크레딧 소진 중 먼저까지 운영합니다. 4GB면 $200 안에서 6개월을 채웁니다.

감수할 것: 부산처럼 AWS IP를 막는 go.kr 사이트는 그 기간 내내 막힌 채입니다(집 가정용 IP로 옮겨야 풀림).

추천: 6개월까지, 노트북 미룸.

3비밀값은 EC2 IAM 역할로(접근 키 없이) [확정] (사용자 승인, 2026-10-14)

EC2를 쓰면 서버에 IAM 역할을 붙여, Parameter Store의 비밀값(카카오 키·DB 비밀번호 등)을 접근 키 없이 읽습니다. ADR-0103의 "Lightsail엔 역할이 없어 접근 키를 둔다"를 이 경우 대체해 키 관리가 사라집니다.

전제: 1번이 EC2일 때만 적용됩니다. Lightsail로 가면 기존 접근 키 방식 그대로입니다.

추천: 적용(EC2 전제).
