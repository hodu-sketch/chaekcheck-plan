1호스트는 EC2 4GB(크레딧)로

첫 배포 서버를 AWS EC2 t4g.medium(램 4GB·서울·Arm)으로 올리고 무료 크레딧으로 결제합니다. Lightsail 무료는 2GB까지라 우리 4GB 설계엔 작습니다. EC2는 크레딧 사용이 확실하고, 3번처럼 IAM 역할을 지원해 관리가 더 단순합니다.

다른 선택 — Lightsail 4GB: 무료 평가판(최대 2GB) 대상이 아니라 크레딧으로 결제해야 하고(크레딧 대상인지 콘솔 확인 필요), IAM 역할이 없어 접근 키를 따로 둬야 합니다.

추천: EC2 4GB.

아직 선택 안 함

2크레딧 한도(최대 6개월)까지, 노트북은 나중에

처음엔 "2주"였지만, 신규 계정 무료 크레딧($100~200)으로 무료 플랜 6개월 한도까지 AWS로 운영하고, 집 노트북 이전은 나중에(크레딧 소진·6개월 무렵) 재검토합니다. 4GB면 $200 안에서 6개월을 채웁니다($24×6=$144).

감수할 것: 부산처럼 AWS IP를 막는 go.kr 사이트는 그 기간 내내 막힌 채입니다(집 가정용 IP로 옮겨야 풀림).

추천: 그대로(6개월까지, 노트북 미룸).

아직 선택 안 함

3비밀값은 EC2 IAM 역할로(접근 키 없이)

EC2를 쓰면 서버에 IAM 역할을 붙여, Parameter Store의 비밀값(카카오 키·DB 비밀번호 등)을 접근 키 없이 읽습니다. ADR-0103의 "Lightsail엔 역할이 없어 접근 키를 둔다"를 이 경우 대체해, 키 관리가 사라져 더 안전합니다.

전제: 1번이 EC2일 때만 적용됩니다. Lightsail로 가면 기존 접근 키 방식 그대로입니다.

추천: 적용(EC2 전제).
