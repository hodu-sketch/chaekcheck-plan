AWS 콘솔 따라 하기

노트북에서 이걸 보면서 AWS 콘솔을 조작하시면 됩니다. 한 단계 끝날 때마다 막히면 그 화면을 캡처해 대화창에 올려 주세요 — 어디를 누를지 짚어 드립니다. (화면 문구는 조금 다를 수 있습니다.)

먼저: 화면 오른쪽 위 리전이 아시아 태평양 (서울) ap-northeast-2인지 확인하세요. 아니면 눌러서 서울로 바꿉니다. 이게 틀리면 다른 지역에 서버가 생깁니다.

1예산 만들기 (Budgets)

약 2분 · 과금 알림 + 추가 크레딧 $20 적립

  1. 위쪽 검색창에 Budgets 입력 → AWS Budgets 클릭.
  2. 예산 생성 (Create budget) 클릭.
  3. 유형은 비용 예산 (Cost budget) 선택 → 다음.
  4. 이름 아무거나(예 chaekcheck), 기간 월간, 예산 금액 10(USD) 정도.
  5. 알림(Alert) 하나 추가: 실제 비용이 예산의 80%를 넘으면, 당신 이메일로 알림.
  6. 예산 생성으로 끝.

2EC2 서버 만들기

약 5분 · 우리 서비스가 돌 서버. 생성이 추가 크레딧 $20 적립

  1. 검색창에 EC2 → EC2 클릭 → 인스턴스 시작 (Launch instance).
  2. 이름: chaekcheck.
  3. 애플리케이션 및 OS 이미지(AMI): Ubuntu 선택 → 버전은 Ubuntu Server 24.04 LTS. 그 아래 아키텍처를 64비트(Arm)로 바꿉니다. (Arm이어야 다음의 t4g를 고를 수 있습니다.)
  4. 인스턴스 유형: t4g.medium (2 vCPU, 4 GiB).
  5. 키 페어(로그인): 새 키 페어 생성 → 이름 chaekcheck-key, 유형 RSA, 형식 .pem → 생성하면 파일이 받아집니다. 이 파일을 잘 보관하세요(서버 접속 열쇠, 다시 못 받음).
  6. 네트워크 설정 → 편집 → 보안 그룹 규칙:
    • SSH(22) 허용, 소스는 내 IP (My IP). (서버 세팅용으로만 잠깐. 나중에 닫습니다.)
    • HTTP(80)·HTTPS(443)는 열지 않습니다 — 우리는 Cloudflare Tunnel로 들어올 거라서요.
  7. 스토리지 구성: 40 GiB, gp3.
  8. 오른쪽 인스턴스 시작. 1~2분 뒤 인스턴스 목록에 실행 중으로 뜹니다.
주소가 바뀌지 않게 고정 IP를 붙입니다: 왼쪽 메뉴 탄력적 IP(Elastic IP) → 탄력적 IP 주소 할당 → 만든 뒤 작업 → 주소 연결에서 방금 만든 chaekcheck 인스턴스에 연결.

3IAM 역할 붙이기

약 4분 · 서버가 비밀값을 접근 키 없이 읽게

  1. 검색창에 IAM → IAM → 왼쪽 역할(Roles) → 역할 생성.
  2. 신뢰할 수 있는 엔터티: AWS 서비스 → 사용 사례 EC2 → 다음.
  3. 권한은 지금 건너뛰고(아무것도 선택 안 해도 됨) 다음 → 역할 이름 chaekcheck-ec2-role → 역할 생성.
  4. 만든 역할을 열고 → 권한 추가 → 인라인 정책 생성 → JSON 탭에 아래를 붙여넣기. <계정ID>만 당신 12자리 계정 번호로 바꾸세요(오른쪽 위 계정 메뉴에 보입니다): 
    {
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": [
      "ssm:GetParametersByPath",
      "ssm:GetParameters",
      "ssm:GetParameter"
    ],
    "Resource": "arn:aws:ssm:ap-northeast-2:<계정ID>:parameter/chaekcheck/prod/*"
  }]
}
    정책 이름 chaekcheck-param-read → 저장.
  5. 이 역할을 서버에 연결: EC2 → 인스턴스 → chaekcheck 선택 → 작업 → 보안 → IAM 역할 수정 → chaekcheck-ec2-role 선택 → 저장.
이 JSON은 "/chaekcheck/prod/ 아래 비밀값만 읽기"를 허용합니다. 비밀값(카카오 키·DB 비밀번호 등)은 나중에 제가 넣는 법을 알려 드립니다.
여기까지 하면 알려 주세요. 그러면 서버에 접속해서 Docker·cloudflared 설치 → 비밀값 넣기 → 서비스 띄우기를 이어서 안내합니다. 중간에 막히면 그 화면을 캡처해 올려 주세요.
