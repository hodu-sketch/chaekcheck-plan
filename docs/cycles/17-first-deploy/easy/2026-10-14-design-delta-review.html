사이클 17 설계 정리와
ADR-0103 초안

설계 결정 10개(2026-10-13~14)를 design-delta.md로 정리하고, 결정 기록 ADR-0103 초안을 만들었습니다. 남은 것은 문서를 확정할지와 작은 값 세 가지입니다. (2026-10-14)

1서버 안 구성 (정한 대로)

컨테이너를 바깥 요청을 받는 무리(edge)와 안에서만 쓰는 무리(app)로 나누고, 어떤 컨테이너도 서버 바깥에 포트를 열지 않습니다. 운영자 SSH와 백업 받기도 Cloudflare Tunnel로 합니다.

design-delta.md "모듈 구성도"를 같은 내용으로 그린 것입니다. 그림에 없는 SSH 길도 같은 터널을 씁니다.

세 가지 흐름 (design-delta의 순서 그림)

흐름순서실패하면
띄우기운영자가 up.sh 실행 → Parameter Store에서 값 받기 → 잠긴 env 파일 → compose로 띄움. env 파일이 이미 있으면 그것을 씀값을 못 받으면 멈추고 지금 컨테이너 그대로
백업03:00 서버가 덤프(수집 책 목록 뺌) → 2개 넘으면 지움 → 내 PC가 Tunnel SSH로 받음 → 7개 넘으면 지움운영 반영 중이면 건너뜀, PC가 못 받으면 다음 실행에 다시
포기 횟수도서관 호출이 자리를 못 받거나 간격 뒤 마감을 넘으면 숫자를 올림 → Grafana-

2바뀌는 것과 바뀌지 않는 것

서비스의 모듈 경계, 공개 API, DB 표는 바뀌지 않습니다. 바뀌는 것은 지표 코드 조금, 운영 설정, 배포 파일입니다.

무엇바뀌는 것
코드 (availability 안쪽)포기 횟수 카운터, 빠진 로그 한 줄, User-Agent에 서비스 주소
운영 설정DB 주소, 시험 데이터 빼기, 지표 포트 8081, 카카오만, 15 기록 꺼짐
배포 파일 (새로)운영 compose, up.sh, 운영 nginx 설정, 접속 기록 형식·14일 정리, 모니터링 설정, 백업 스크립트, Dockerfile, 운영 문서(띄우기·되살리기·노트북 옮기기·공개일 체크리스트)
DB 표·REST API없음

3작은 값 세 가지

1비밀 값은 모두 Parameter Store /chaekcheck/prod/ 아래에 두고, 이름 끝을 그대로 환경 변수 이름으로 씀 [안]

예: /chaekcheck/prod/DB_PASSWORD → DB_PASSWORD. 넣을 값: DB 비밀번호, JWT 키, 카카오 REST API 키·클라이언트 시크릿·어드민 키, 터널 토큰, Grafana 관리자 비밀번호. 범위 정할 때 꼽은 셋(카카오 키, DB 비밀번호, 조회 서버 토큰)보다 많아서 여쭙니다. 조회 서버 토큰은 조회 서버를 꺼 두므로 이번에는 넣지 않습니다.

꼽은 셋만: 나머지(터널 토큰, Grafana 비밀번호, JWT 키)는 서버 파일에 둡니다. 비밀 값이 두 곳으로 나뉩니다.

추천: 모두 Parameter Store.

2도서관 사이트에 보내는 User-Agent의 연락처는 chaekcheck9104@gmail.com [안]

예: chaekcheck/0.0.1 (+https://chaekcheck.com; chaekcheck9104@gmail.com). 이 주소는 사이클 16에서 서비스 안내용 연락처로 정한 것입니다. 개인 메일이 아니라 서비스 메일입니다.

주소만, 연락처 없이: 메일이 드러나지 않습니다. 대신 도서관이 연락할 곳이 서비스 페이지뿐입니다.

추천: 서비스 주소와 메일 둘 다.

3운영 DB에 Claude가 SQL을 넣을 때: Tunnel SSH로 들어가 docker exec db psql, DB 계정은 sitecontent 쓰기만, 사용자가 승인한 SQL만 [안]

사이클 16이 요청한 길입니다. 공지·약관을 운영자 화면 없이 SQL로 넣기 때문입니다. 백업과 같은 SSH 길을 쓰고, 그 계정으로는 다른 표를 고칠 수 없습니다.

DB 관리자 계정으로: 만들 것이 없습니다. 대신 실수하면 다른 표까지 바뀝니다.

추천: 쓰기를 좁힌 계정.

4문서 확정

ADR-0103은 오늘 정한 서버 구성 다섯 가지(네트워크 둘, 비밀 값 스크립트, 지표 포트·카운터·exporter·cAdvisor, 백업 범위·Tunnel SSH, 이미지 옮기기)를 한 기록으로 묶습니다. 이유는 사용자 말씀("해보자 그냥 써보고 싶어", "집 아이피 바뀔 수 있는데? 이거 고정 아니야")과 "제안 → 승인"으로 적었습니다.

4이대로 design-delta.md를 확정하고 ADR-0103을 저장 (처음 상태는 제안됨) [안]

승인하시면 /cycle-close로 넘어가 검토(design-reviewer)를 하고 인계서를 씁니다. 인계서 확정은 사이클 12~14 회고 뒤입니다(범위에서 정한 대로).
