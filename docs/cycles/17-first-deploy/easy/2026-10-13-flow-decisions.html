사이클 17 화면 흐름:
서비스 화면은 그대로, 새로 생기는 상태 세 가지

이번 사이클은 서비스 화면을 바꾸지 않습니다. 공개 주소로 들어오는 길, 한도를 넘었을 때, 서버가 멈췄을 때, 운영자가 보는 Grafana만 정리했습니다. 정할 것은 세 가지입니다. (2026-10-13)

1흐름 한 장

사용자는 chaekcheck.com으로 들어와 지금 화면을 그대로 씁니다. 운영자는 grafana.chaekcheck.com으로 따로 들어갑니다.

flow.md의 Mermaid 그림을 같은 내용으로 다시 그린 것입니다.

2한도를 넘었을 때 보이는 것

검색 쪽 화면은 이미 사이클 08에서 정한 안내가 있습니다. 새로 한도가 걸리는 나머지 화면은 지금 오류 표시를 그대로 쓰자는 안입니다.

화면429를 받으면
수집 목록 검색, 바로 결과, 도서관에서 직접 찾기, 대출 현황, 더 보기받은 결과는 그대로 두고 위에 노란 한 줄 "검색을 너무 자주 했어요. 1분쯤 뒤에 다시 해 주세요." (이미 있음, 사이클 08)
도서관 목록, 지역 목록, 사서 추천, 내 정보·내 도서관 저장, 로그인 시작정한 것 없음. 이 화면들이 지금 오류를 어떻게 보여 주는지는 확인 못 함

1나머지 화면은 429를 받으면 그 자리의 지금 오류 표시를 그대로 쓰고, 새 문구는 만들지 않음 [안]

보통 사람은 1초에 5번·몰아서 30번에 닿지 않아서, 이 상태는 주로 스크립트가 만납니다. 그래서 화면을 새로 만들지 않는 안입니다.

검색 화면과 같은 노란 안내를 모든 화면에: 사람이 만나도 이유를 알 수 있습니다. 대신 화면 다섯 곳 정도를 고쳐야 합니다.

추천: 지금 오류 표시 그대로. dev가 각 화면의 지금 표시를 확인해 알려 주면, 이상하면 그때 고칩니다.

3서버나 터널이 멈췄을 때

서버가 멈추면 우리 화면이 뜨지 않으므로, 사용자는 Cloudflare가 보여 주는 오류 화면을 봅니다. 어떤 화면인지는 배포 때 일부러 멈춰 보고 확인합니다.

2멈췄을 때 보일 우리 화면은 만들지 않고 Cloudflare 기본 오류 화면을 씀 [안]

서버는 다시 켜지면 모두 저절로 다시 뜨게 하고(spec R1), 운영자는 Grafana로 알아챕니다.

Cloudflare에 우리 안내 화면을 따로 걸기: "잠시 점검 중" 같은 문구를 보일 수 있습니다. 무료 요금제에서 되는지와 방법은 확인하지 않았습니다.

추천: Cloudflare 기본 화면. 2주 체험이라 따로 만들지 않습니다.

질문: 2주 클라우드가 끝나고 옮길 때를 미리 대비해 둘 수 있나요?

네. 이번 구성 자체가 옮기기를 대비한 모양입니다. 도메인·카카오 설정은 그대로 두고 터널을 켜는 기계만 바꾸면 되고, 같은 터널에 두 기계를 잠깐 함께 붙여 끊김을 줄일 수 있습니다. 다만 DB를 옮기는 동안의 가입·저장은 잠깐 막아야 합니다.

Cloudflare 문서: 같은 터널에 cloudflared를 여러 대 붙일 수 있고(replica), 요청은 "geographically closest replica"로 감.

  • 이번 사이클에 미리 해 둘 것 [안]: 서버 구성을 compose 파일과 설정으로만 만들어 노트북에서 같은 파일로 띄울 수 있게 함, 옮기는 순서(위 ①~④)를 운영 문서에 적어 둠, DB 덤프·복원은 매일 03:00 백업과 같은 명령을 씀
  • "Cloudflare 자체를 그만 쓸 때"를 말씀하신 것이라면: 그때는 도메인 DNS를 서버 IP로 바로 연결하고, 서버에서 80·443을 열고 인증서(Let's Encrypt)를 받으면 됩니다. Cloudflare에서 산 도메인은 DNS를 Cloudflare에 두어야 해서, 터널만 끄고 DNS 기록을 바꾸는 방식이 됩니다(2026-10-13 조사).
  • 멈췄을 때 보일 화면(2번)은 이 옮기기와 따로입니다. 옮기기 동안 검색은 계속 되므로 Cloudflare 오류 화면이 보일 일은 적습니다.

출처: Cloudflare Tunnel replica https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-availability/ (확인 2026-10-13), Cloudflare Registrar 네임서버 https://developers.cloudflare.com/registrar/faq/ , Let's Encrypt https://letsencrypt.org/about/
