지금 당신이 직접 할 일: 5가지

로그인·결제·계정 설정은 제가 대신 못 합니다. 그 다섯 가지만 당신이 하고, 그 뒤 서버에 서비스를 올리는 건 제가 안내합니다. 순서대로 하면 됩니다. (2026-10-14)

1~3은 AWS 안에서 순서대로. 4·5는 AWS 밖이라 언제 해도 됩니다.

1AWS에서 서버 띄우기 꼭

AWS 콘솔에서 ① 돈 쓰는 걸 지켜볼 예산을 하나 만들고 ② 서버(EC2)를 서울에 하나 만들고 ③ 그 서버에 비밀값을 읽을 권한(역할)을 붙입니다. 이 세 개가 배포의 바탕입니다.

① AWS Budgets에서 예산 1개 만들기

AWS 콘솔 검색창에 Budgets를 치고, 비용 예산(cost budget)을 하나 만듭니다. 금액은 작게(예: $5~10) 두고 알림 이메일을 켭니다.

왜: 무료 플랜이라 크레딧을 넘겨도 자동으로 요금이 나가진 않지만, 크레딧이 얼마나 줄었는지 알림으로 알 수 있습니다. 그리고 예산을 만드는 것 자체가 추가 크레딧 적립 활동 하나입니다(2번 카드).

② EC2 서버 만들기 (서울·t4g.medium)

검색창에 EC2 → "인스턴스 시작". 리전은 서울(ap-northeast-2), 종류는 t4g.medium(램 4GB), 운영체제는 Ubuntu LTS를 고릅니다. 키 페어(접속 열쇠)는 새로 하나 만들어 받아 둡니다.

왜: 우리 설계가 4GB 기준이고, t4g.medium이 크레딧으로 6개월을 덮습니다. 서버 만들기도 추가 크레딧 적립 활동입니다.

보안 그룹(들어오는 연결 허용)·고정 IP는 생성 화면에서 제가 어디를 누를지 짚어 드립니다. 캡처만 주세요.

③ 서버에 IAM 역할 붙이기

IAM에서 역할(role)을 하나 만들어 Parameter Store 읽기 권한만 주고, 그 역할을 ②에서 만든 서버에 연결합니다.

왜: 이렇게 하면 서버가 카카오 키·DB 비밀번호 같은 비밀값을 접근 키 없이 읽습니다. 접근 키를 따로 만들고 보관할 필요가 없어 더 안전합니다(어제 승인한 3번 결정).

권한 범위(어느 경로만 읽게 할지)는 제가 정확한 값을 드립니다.

2크레딧 더 받기 (선택) 선택

가입 때 받은 $100에 더해, 몇 가지 활동을 하면 최대 $100을 더 받습니다. 아래는 제3자 정리라 정확한 목록·금액은 콘솔 "Explore AWS" 위젯에 뜨는 당신 계정 기준으로 보세요. 1번 카드의 예산·EC2가 이미 두 개에 해당합니다.

활동비고
EC2 인스턴스 실행1번 카드 ②에서 이미 함
AWS Budgets 예산 설정1번 카드 ①에서 이미 함
RDS 데이터베이스 하나 구성만들었다 바로 지워도 됨
Lambda 함수 하나 만들기간단한 것 하나
Amazon Bedrock 써 보기플레이그라운드에서 한 번

"각 $20"은 제3자 블로그 기준이라 확정은 아닙니다. 콘솔 위젯이 실제 적립 현황을 보여 줍니다.

3AWS 밖에서 할 일 꼭

도메인 주소를 사고, 카카오 로그인을 운영 주소로 등록합니다. 둘 다 AWS와 상관없어 언제 해도 됩니다.

④ chaekcheck.com 도메인 사기 (Cloudflare)

Cloudflare에서 chaekcheck.com을 삽니다. 이 주소로 사람들이 서비스에 들어옵니다.

왜: 나중에 Cloudflare Tunnel로 이 주소를 서버에 연결합니다. 쓸 수 있는 주소인지(이미 팔렸는지)는 사는 화면에서 확인됩니다.

⑤ 카카오 개발자 콘솔에 운영 주소 등록

카카오 개발자 콘솔에서 우리 앱의 사이트 주소와 Redirect URI를 운영 주소(https://chaekcheck.com)로 등록합니다.

왜: 지금은 로컬 주소로 돼 있어, 운영 주소를 안 넣으면 배포 뒤 카카오 로그인이 막힙니다. 정확히 넣을 Redirect URI 값은 제가 드립니다.

4그다음은 제가 합니다

위 다섯 개가 끝나면, 서버에 서비스를 올리는 일은 제가 단계별로 안내합니다. 당신이 외울 건 없습니다.

서버가 뜨면: 접속해서 Docker·cloudflared 설치 → 비밀값을 Parameter Store에 넣기 → 우리 compose로 서비스·DB·모니터링 띄우기 → 도메인·카카오 연결 확인. 각 단계에서 칠 명령과 누를 곳을 제가 하나씩 드립니다.
