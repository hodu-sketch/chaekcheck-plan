# 사이클 03: 검색 조건 강화

## 목표 (한 문장)

제목뿐 아니라 저자나 출판사로도 검색할 수 있게, 검색할 때 조건 하나(제목/저자/출판사)를 고르게 한다. [안] (문장은 Claude 정리, 방향은 사용자 결정 2026-09-29)

## 포함

세부 규칙은 `spec.md`에서 정합니다. 여기서는 범위만 적습니다.

- 검색 조건: 제목, 저자, 출판사 [확정] (사용자, 2026-09-29)
- **한 번에 조건 하나만 골라 검색** [확정] (사용자: "A만 가고", 2026-09-29). 조사 결과 7종 사이트 모두 저자·출판사 한 조건 검색을 직접 지원함 (spec 3장)
- 검색 API에 조건 파라미터 추가 (ADR-0009의 `field` 제안, 모양은 design-delta에서 정함) [안]
- 조건별 캐시 키 (ADR-0009: 캐시 키에 필드가 이미 있음)
- 화면: 검색 영역에서 조건 선택, URL에 조건을 남겨 새로고침·공유해도 유지 (사이클 01 `filter`, 사이클 02 `scope`와 같은 방식) [안]
- 화면 종류 7개(`KYOBO_V1`, `KYOBO_SUBSCRIPTION_V1`, `YES24_V1`~`V3`, `ELIB_PORTAL_V1`, `GANGNAM_V1`)의 adapter에 저자·출판사 검색 반영

## 범위 변경 기록

- 2026-09-29 처음 범위: 한 조건 검색 + 여러 조건 AND 조합 둘 다 (사용자: "둘 다로 하고 검색 조건에 and조건으로 다양하게 하고")
- 같은 날 조사 결과(필드별 정확한 AND를 해 주는 사이트가 없어 서버가 결과를 걸러야 함)를 본 뒤 **조건 하나만**으로 줄임. 사용자: "조사 결과가 내가 생각하던 것과 달라서", "A만 가고"

## 제외 (backlog.md로 보낸 항목)

- **여러 조건 AND 조합 검색** — 조사 후 제외 (사용자: "A만 가고", 2026-09-29). 사이트마다 가능한 방식과 서버 거르기의 영향은 spec 3장과 backlog에 남김
- **옮긴이 검색** [확정] (사용자: "옮긴이는 제외했으면 해", 2026-09-29). 교보는 저자 칸에 옮긴이가 없음(사이클 01 retro)
- 공공 데이터(도서관 정보나루로 추정)의 도서관별 도서 정보를 AND 검색에 활용하기 — 노트만 (사용자: "다음에 이전에 공공기관 정보 소스 있었자나 … 거기에 도서관별 도서정보가 있거든 … 도서 검색을 보강해서 보여주는게 어떨까해 실시간성은 떨어지지만 이건 노트만 하고", "And검색에 활용하는거지", 2026-09-29, backlog)
- 제목 비교 키(`titleKey`)에 저자·출판사 넣기, 같은 책 묶기(ISBN) — backlog 그대로
- 읽는 코드가 없는 화면 7종 추가, 느리거나 실패하는 도서관 기억하기, `targets` 크기 줄이기, 회원 — 사이클 02 retro "다음 사이클 후보" 그대로
- ISBN·키워드·분야 등 다른 검색 조건

## 완료 기준 (사용자가 화면에서 확인할 수 있는 것)

세부 AC는 `spec.md`에서 정합니다. 핵심은 다음과 같습니다. [안]

1. 조건을 "저자"로 골라 검색하면 그 저자의 책이 나온다.
2. 조건을 "출판사"로 골라 검색하면 그 출판사의 책이 나온다.
3. 제목 검색(기본)은 지금 동작 그대로다.
4. 조건을 바꾸면 첫 묶음부터 다시 검색하고, 새로고침해도 조건이 유지된다.
5. 사이클 01·02의 호출 예의(캐시 3분, 같은 호스트 동시 1건·1초, User-Agent)와 묶음 규칙이 그대로 지켜진다.

## 먼저 조사할 것 [확인 필요]

| 항목 | 확인 방법 |
|---|---|
| 화면 종류 7개마다 저자·출판사 필드 검색을 지원하는지, 파라미터 이름과 값 | 실제 호출 시험 → 2026-09-29 확인, 7종 모두 지원 (spec 3장). 포털 7곳·`YES24_V3` 출판사도 같은 날 추가 조사 완료 (spec 3장 "포털 재조사") |
| 한 번의 요청에 두 조건 이상을 동시에 넣을 수 있는지 | 실제 호출 시험 → 2026-09-29 확인, 필드별 정확한 AND는 없음 (spec 3장). AND는 제외됨 |
| 저자·출판사 부분 일치 여부 | 실제 호출 시험 → 모두 부분 일치 ("김달" → "김달우") |
| 조건별 최소·최대 글자 수 (지금 제목은 정규화 후 2~50자) | 사용자에게 질문 (spec) |
