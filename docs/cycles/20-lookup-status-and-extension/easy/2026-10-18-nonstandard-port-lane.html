포트가 붙은 도서관 주소는 어느 길로 부를까 (2026-10-18)

dev 사이클 20 세션이 나가는 길(Webshare 한국 IP 20개)을 다 만들어 dev main에 넣었고(d5341a6), 실제 Webshare로도 확인했습니다. 그런데 주소에 비표준 포트가 붙은 도서관은 Webshare 길로는 열리지 않고 서버 자기 IP로만 열렸습니다. 이 도서관들을 어느 길로 부를지 정해 주세요.

1비표준 포트 도서관은 처음부터 직접 길만

Webshare가 비표준 포트를 막는다는 공식 문서는 찾지 못했습니다(Webshare 도움말 검색, 2026-10-18). 관찰값만 있어 [확인 필요]로 둡니다. 켜진 도서관 중 비표준 포트를 쓰는 곳이 몇 곳인지는 dev가 세어 알립니다.

[안] 주소 포트가 80·443이 아닌 도서관은 Webshare 길을 쓰지 않고 서버 자기 IP(직접 길)로만 부릅니다. 목록 없이 포트로 자동으로 가르고, 설정 하나로 끌 수 있게 합니다. 「프록시만」 설정일 때 이 도서관들은 「확인하지 못한 도서관」입니다.

다른 선택: (가) 지금대로 둠(막힌 길 규칙이 알아서 처리) / (나) 포트 대신 호스트 목록을 설정에 적어 관리.
