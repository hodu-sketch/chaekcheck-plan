화면별 내용

H 공통 머리말 (모든 화면, /terms·/privacy 제외)

  • 목적: 검색을 누르기 전에 지금 조회가 원활한지 보이기 (spec R1·R2·R5)
  • 보이는 요소: 「책첵」 · 「사서추천도서」 … [점 + 글] · 「로그인/로그아웃」. 점+글은 「로그인」 바로 왼쪽 [확정] (범위 #4)
  • 글 [확정] (명세 #1): 초록 「조회 원활」 / 노랑 「조회 붐빔」 / 빨강 「조회 혼잡」 / 회색 「상태 모름」(R5) / 파란 「내 브라우저에서 조회 중」(확장 모드, 명세 #4·#12)
  • 사용자 동작: 없음(PC). 폰(640px 이하)은 점만 보이고 누르면 설명 한 줄(「지금 찾는 사람이 많아 검색이 거절될 수 있어요」) — 보이는 방식 [안] 말풍선(팝오버) / 머리말 아래 한 줄
  • 호출하는 API: 상태 묻기(이름은 design-delta). 머리말이 있는 화면이 보이는 동안 10초마다, 탭이 숨으면 멈춤, 다시 보이면 즉시 1회 [확정] (R3). 확장 모드면 묻지 않음 [확정] (R10)
  • 상태: 첫 응답 전 빈 자리(명세 #8) / 초록·노랑·빨강 / 회색(30초 넘게 응답 없음, 명세 #7) / 파란(확장)
  • 배치 메모: PC·태블릿은 점(지름 약 10px)+글 한 덩이, 글은 navLink와 같은 크기. 폰은 점만(44px 터치 영역은 다른 머리말 요소와 같은 방식). 신호가 바뀔 때 움직임(깜빡임) 없음, 색·글만 바뀜 [안]

S1 검색 결과 (지금 화면에 더해지는 것)

  • 빨강일 때(R12, 명세 #3): 결과 판 위, 지금 503 안내 줄과 같은 자리(그 아래)에 안내 한 줄 「지금 찾는 사람이 많아요. 도서관 사이트에서 직접 확인할 수 있어요」. 결과 카드는 이미 카드 전체가 도서관 페이지 링크(dev ResultRow.tsx, 2026-10-05부터 「도서관에서 보기」 버튼 없음)라 앞세울 링크가 없음 → 빨강일 때만 카드 상태 칸 아래에 보이는 글 「도서관에서 보기 →」 [안]. 초록·노랑이면 글 없음. 확장 모드에서는 안내 줄·글 모두 없음 [확정] (명세 #12)
  • 줄이 선 도서관(R4, 명세 #2·#5): 그 도서관 결과 줄 이름 옆 「지금 이 도서관 조회가 밀려요」. 폰은 이름 아래 줄 [안]. 그 줄이 실패(library-failed)로 끝나도 표시는 상태 응답을 따름(60초 안에 사라짐)
  • 상태: 503 받음 → 머리말 즉시 빨강(R2) + 지금 503 안내 + 안내 줄
  • 사서추천(S13)·소개(S12)·내 도서관(S10)·가입(S8·S9): 머리말 신호만 보임, 안내 줄·배지 없음 [안]

S3 책 화면 (책 하나의 도서관 목록)

  • S1과 같은 규칙: 빨강 안내 줄(도서관 목록 위) + 「도서관에서 보기」 앞세움, 줄이 선 도서관 배지 [안] (S1과 같게)

흐름

  • F1 상태 묻기: 화면 뜸 → (확장 인사 → 답 없음) → 상태 묻기 → 10초마다 반복. 탭 숨김 → 멈춤. 다시 보임 → 즉시 1회. 응답 없음 30초 → 회색. 503 받음 → 즉시 빨강, 다음 응답으로 복귀 (R1·R2·R5)
  • F2 확장 모드 조회 (위 sequence, R6~R9): 인사 답 있음 → 파란 불, 상태 묻기 없음. 검색마다 계획 → 확장이 받아오기 → 해석. 확장이 못 받아온 도서관은 그 줄 "실패"(서버가 다시 안 부름, 명세 #10). 계획 번호 틀림 → 400 invalid_plan(화면은 "검색하지 못했어요" 일반 오류) [안]. 확장이 중간에 꺼져 첫 주소 요청이 실패 → 그 검색부터 서버 모드 + 파란 불 지움(명세 #9)
  • F3 도서관 줄 몰림: 상태 응답의 줄이 선 도서관 목록 → S1·S3의 해당 줄 배지. 길마다 따로 셈, 막힌 길 제외(R4)
