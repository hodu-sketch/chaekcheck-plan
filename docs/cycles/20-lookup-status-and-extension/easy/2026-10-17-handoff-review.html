53단계 자세히: 계획 요청 하나가 거치는 검사

물으신 「LRU 장부 → HttpOnly 번호 쿠키·번호 잠금 → IP 울타리 둘 → 서버 대행 목록」은 확장 모드 계획 요청이 서버에서 이 순서로 검사받는 것입니다. 목적은 같은 공인 IP 뒤 여러 사람을 브라우저마다 따로 세서, 한 사람의 남용이 다른 사람을 막지 않게 하는 것입니다.

숫자는 모두 이미 정한 값입니다(세 관점 검토 #22·#31~#33, 전반 점검 #10·#12, 설계 검토 #1). 서버 대행 목록은 처음에 비어 있고, 2단계 프로토타입에서 확장이 못 여는 도서관이 나오면 넣습니다.
