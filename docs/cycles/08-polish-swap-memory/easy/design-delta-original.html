구조 그림

모듈 구성도

  • catalog :: normalize는 collection이 빌려 쓰는 제목 다듬기 규칙(named interface, ADR-0060, docs/current/module-map.md)이고 이번에 바뀌지 않습니다. 국가서지 원문도 가져올 때마다 이 규칙으로 다듬습니다(ADR-0069)
  • 모듈 사이 의존 방향은 바뀌지 않습니다(collection → catalog, library, availability → catalog, library, catalog → library → region). 새 이벤트 없음 [확정: 설계 결정 2026-10-11]

주요 흐름

흐름 A: 가져오기 (새 표에 쓰고 바꿔 끼우기, ADR-0065·0069)

흐름 B: 검색 계획과 책 화면 소장 읽기 (ADR-0066)

흐름 C: 막혔을 때

도메인 모델

  • NameOverride는 DB 표가 아니라 seed 스크립트가 읽는 파일입니다. NationalBibliographyRecord·NationalBibliographySource는 collection이 가집니다. 국가서지는 다듬기 전 원문을 남기고 가져올 때마다 지금 정리 규칙으로 다듬으므로, 정리 규칙 판 번호는 두지 않습니다(사용자 질문 "규칙을 db에 남겨야 하나?", "테이블만 바꿔끼우는 거면 굳이 … 할 필요가 없지 않나?" 뒤 고침, 2026-10-11).
