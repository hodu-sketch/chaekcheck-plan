6도서관 이름, 글꼴

8이름을 고친 도서관은 새 이름으로만 찾음 (예전 이름으로는 안 나옴) [안]

내 도서관 화면(S10)의 이름 찾기, 결과 카드, 가입 정보 창 모두 새 이름입니다. 직접 추가해 둔 것은 번호로 이어져 그대로 남습니다.

다른 선택 예전 이름으로도 찾게(도서관 표에 칸 하나 더).

9글꼴을 자주 쓰는 한글만 담은 작은 파일로 줄이고, 줄인 파일은 다른 글꼴 이름으로 둠 [안]

지금 나눔바른고딕 보통·굵게 약 3MB를 처음 화면에서 받습니다. 줄이면 첫 화면이 빨리 뜹니다. 드문 글자는 기기 글꼴로 보일 수 있습니다.

라이선스: dev 글꼴 설정은 나눔바른고딕을 OFL-1.1로 적고 있습니다(dev web/src/styles/fonts.css). OFL 1.1은 고쳐 쓰는 것을 허용하지만, "예약된 글꼴 이름"이 있으면 고친 판은 그 이름을 쓸 수 없습니다(OFL 1.1 원문, 확인 2026-10-06). 나눔바른고딕에 예약된 이름이 있는지는 네이버 페이지를 열지 못해 확인 못 함 → 안전하게 줄인 파일은 다른 이름으로 둡니다.

다른 선택 지금 그대로(3MB).
