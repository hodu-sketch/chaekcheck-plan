# 기능 명세: 도서 제목 검색 → 전자도서관 대출 가능 여부

- 사이클: 01 (`scope.md`)
- 확인일: 2026-09-27. 외부 사실은 공식 페이지 또는 직접 요청 시험으로 확인했고, 출처는 11장에 있습니다.
- 태그: [확정] 사용자 확인 또는 공식 확인 / [안] 제안, 미확정 / [확인 필요] 미확인 (12장에 확인 방법)

## 1. 목적과 사용자 이야기

로그인 없이 책 제목으로 검색하면, 시범 전자도서관들의 보유·대출·예약 현황을 한 화면에서 보여 줍니다. 사용자가 거주·직장 지역을 고르면 **실제로 가입해서 빌릴 수 있는 도서관만** 보여 줍니다. [확정]

- 전자책을 빌리고 싶은 사람은 제목만 입력해서, 어느 전자도서관에 그 책이 있고 지금 빌릴 수 있는지 알고 싶다. 도서관 사이트를 하나씩 찾지 않기 위해서다. [확정]
- 거주·직장 지역을 고른 사람은 자격이 없는 도서관은 보고 싶지 않다. 그 도서관에서는 빌릴 수 없기 때문이다. [확정]
- 서비스는 지금 빌릴 수 있는 책이 같은 조건이면 덜 붐비는 도서관을 먼저 보여 준다. 여러 전자도서관이 골고루 이용되게 하기 위해서다. [확정] (사용자: "전자도서관을 골고루 활성화시키려고")

## 2. 용어

| 용어 | 뜻 |
|---|---|
| 전자도서관 | 전자책을 빌려주는 도서관 사이트 하나. 이 명세에서 "도서관"은 모두 전자도서관을 뜻함 |
| 플랫폼 | 전자도서관 사이트를 운영하는 소프트웨어. 이번 사이클은 교보와 YES24 두 가지이고, 플랫폼마다 adapter를 하나씩 둠 |
| 공급 업체 | 책 한 권을 공급한 업체 (교보문고, YES24, 북큐브 등). 한 플랫폼 사이트에 여러 업체의 책이 섞일 수 있음 (예: 성남시 교보 사이트에 YES24·북큐브 책) |
| 가입 조건 종류 | **누구나 가입**: 자격 규칙이 없음 / **자격 필요**: 자격 규칙이 하나 이상 있음 |
| 자격 규칙 | (근거, 범위) 한 쌍. 근거는 거주·재직·재학·소속 중 하나, 범위는 지역(시도 또는 시군구)이나 기관. 이번 사이클에서 입력과 비교에 쓰는 근거는 거주·재직, 범위는 지역뿐 |
| 내 지역 | 사용자가 고른 거주 지역과 직장 지역 (시군구 단위, 여러 개 가능). 브라우저에만 저장 |
| 빌릴 수 있는 도서관 | 누구나 가입 도서관, 또는 자격 규칙 중 하나가 내 지역과 맞는 도서관 (5.1) |
| 재고 | 대출 가능 권수 = 보유 − 대출 중 |
| 도서관 대출률 | 이번 검색에서 그 도서관이 **첫 요청으로 돌려준 결과**(교보 50건, YES24 10건)의 (대출 중 합계 ÷ 보유 합계). "더 보기"로 결과가 늘어도 다시 계산하지 않음 (5.4). 책 한 권의 비율이 아니라 도서관이 얼마나 붐비는지를 나타냄. 검색어에 걸린 책들만으로 계산한 표본이라, 결과가 적으면 구분력이 거의 없음 |
| 도서관 검색 결과의 원래 순서 | 도서관 사이트가 검색 결과를 보여 준 순서. 다른 기준이 모두 같을 때 순서를 하나로 정하는 마지막 기준 |

## 3. 시범 도서관

| 도서관 | 플랫폼 | 가입 조건 | 자격 규칙 | 가입 방법 | 상태 태그 |
|---|---|---|---|---|---|
| 서울 강서구 전자도서관 | YES24 | 자격 필요 | 거주·서울특별시 / 재직·서울특별시 / 재학·서울특별시 | 도서관 방문 회원증 발급 또는 서울시민카드 간편가입 | [확정] |
| 고흥군립도서관 전자도서관 | 교보 | 누구나 가입 | 없음 | 도서관 홈페이지 가입 후 로그인 | [확정] |

- 강서구는 구립 도서관이지만 자격 범위가 **서울 전체**입니다. 그래서 자격 범위는 시도일 수도 있고 시군구일 수도 있습니다. [확정]
- 고흥군은 사용자가 직접 가입·로그인해서 지역 확인 없이 대출했습니다. 공식 안내에는 "대상: 고흥군립도서관 회원"만 적혀 있습니다. [확정]
- 강서구의 재학 규칙은 이번 사이클에서 저장만 하고, 사용자 입력과 비교하지 않습니다 (8장, 9장).

## 4. 입력과 출력

**입력**

| 항목 | 규칙 | 상태 태그 |
|---|---|---|
| 검색어 | 책 제목만. 앞뒤 공백을 빼고 연속 공백을 하나로 줄인 뒤 2글자 이상, 50자 이하 | [확정] (50자: 사용자 확인, 2026-09-27) |
| 거주 지역 | 선택 입력. 시군구, 여러 개 | [확정] |
| 직장 지역 | 선택 입력. 시군구, 여러 개 | [확정] |

- 지역은 브라우저에 저장해서 새로고침 후에도 유지합니다. 서버에는 저장하지 않고, 검색 요청에 조건으로만 보냅니다. [확정]

**출력 (결과 한 줄 = 도서관 하나의 책 하나)**

| 항목 | 규칙 | 상태 태그 |
|---|---|---|
| 제목, 저자, 출판사, 공급 업체 | 도서관 결과 그대로 | [확정] |
| 도서관명, 가입 조건 종류 | 자격 필요 도서관에는 자격 문구를 붙임 (예: "서울 거주·재직·재학") | [확정] |
| 보유, 대출 중, 예약 인원 | 5.3 | [확정] |
| 대출 가능 여부 | 재고가 1권 이상이면 대출 가능 | [확정] |
| 가입 방법 안내 | 도서관별 한 줄 (3장) | [확정] |
| 도서관으로 이동 | 그 도서관의 검색 결과 페이지 링크. 대출은 도서관 사이트에서 함 | [확정] |
| 조회 시각 | 캐시된 결과면 "N분 전 조회" | [확정] |

- 같은 책이 여러 도서관에 있어도 묶지 않고 도서관별로 따로 보여 줍니다. [확정]
- 도서관별 전체 결과 건수를 보여 줍니다 (5.5). [확정]
- 페이지 바닥에 데이터 출처와 연락처를 한 줄로 둡니다 (10장). [확정]
- 서지 설명문과 표지 이미지는 보여 주지 않습니다 (5.6). [확정]

## 5. 동작 규칙

### 5.1 대상 도서관 고르기 [확정]

| 내 지역 | 조회하고 표시하는 도서관 |
|---|---|
| 고르지 않음 | 사용 중인 시범 도서관 전부. 줄마다 가입 조건 종류를 표시 |
| 고름 | 누구나 가입 도서관 + 자격 규칙이 내 지역과 맞는 도서관. 나머지는 숨김 |

**규칙이 내 지역과 맞는 조건** (둘 다 만족해야 함)
- 근거가 맞아야 합니다. 사용자의 거주 지역은 "거주" 규칙과, 직장 지역은 "재직" 규칙과 비교합니다.
- 범위가 맞아야 합니다. 규칙 범위가 시도면 그 시도의 모든 시군구가 맞고, 시군구면 그 시군구만 맞습니다.
- 예: 거주 경기 고양시 + 직장 서울 중구 → 강서구의 "재직·서울특별시" 규칙과 맞음 → 강서구를 표시

### 5.2 조회 [확정]

- 검색하면 대상 도서관마다 한 번씩, 병렬로 실시간 요청합니다.
  - 교보: 50건 (`recordCount=50`)
  - YES24: 첫 페이지 10건 (페이지 크기 고정, `sort=now`로 대출 가능한 책 먼저)
- 결과는 **먼저 응답한 도서관부터** 화면에 보여 줍니다. 도서관 결과가 들어올 때마다 5.4 순서로 다시 정렬하고, 아직 응답하지 않은 도서관은 로딩으로 표시합니다.
- 타임아웃은 연결 3초, 응답 5초, 검색 전체 8초입니다. 8초가 지나도 응답이 없는 도서관은 "조회 실패"로 표시합니다. 실측 응답은 0.3~1.3초였습니다 (2026-09-27).

### 5.3 수량 읽기 [확정]

| 플랫폼 | 화면 표기 | 보유 | 대출 중 | 예약 |
|---|---|---|---|---|
| YES24 | `보유 N` `대출 N` `예약 N` | 보유 N | 대출 N | 예약 N |
| 교보 | `대출 : X/Y  예약 : Z` | Y | X | Z |

### 5.4 결과 순서 [확정] (사용자, 2026-09-27)

**1단계: 재고로 그룹을 나눕니다** (화면의 그룹 제목)
1. 지금 빌릴 수 있어요: 재고 있음
2. 예약하고 기다려요: 재고 없음

**2단계: 그룹 안에서 가입 가능 여부로 나눕니다**
1. 빌릴 수 있는 도서관의 줄
2. 가입 자격을 알 수 없는 도서관의 줄 ("가입 자격 확인 필요" 배지. 지역을 고르지 않았을 때의 자격 필요 도서관)

- 지역을 고르지 않았을 때는 누구나 가입 도서관을 "빌릴 수 있는 도서관"으로 봅니다.
- 지역을 고르면 자격이 없는 도서관은 숨기므로 2단계의 2번 줄은 나오지 않습니다.

**3단계: 같은 칸 안의 순서**

| 그룹 | 순서 |
|---|---|
| 지금 빌릴 수 있어요 | ① 재고 많은 순 → ② 도서관 대출률 낮은 순 → ③ 도서관 검색 결과의 원래 순서 |
| 예약하고 기다려요 | ① 예약 인원 적은 순 → ② 보유 많은 순 → ③ 도서관 검색 결과의 원래 순서 |

- 예약 그룹의 책은 모두 대출 중이라 도서관 대출률로는 대부분 구분되지 않습니다. 그래서 예약 인원이 같으면 차례가 빨리 오는 보유 많은 곳을 먼저 둡니다. [확정] (사용자, 2026-09-27)
- 도서관 대출률은 그 도서관의 첫 요청 결과로 계산하고, "더 보기"로 결과가 늘어도 바꾸지 않습니다. 더 보기를 누를 때마다 도서관 순서가 흔들리지 않게 하기 위해서입니다. [확정]

### 5.5 더 보기 [확정]

- 도서관의 전체 건수가 가져온 건수보다 많으면 그 도서관에 "더 보기"를 둡니다.
- 누르면 그 도서관의 다음 페이지만 요청하고 (교보 `pageIndex`, YES24 `page_num`), 받은 줄을 5.4 순서에 맞춰 합칩니다.

### 5.6 캐시와 크롤링 예의 [확정] (사용자, 2026-09-27)

| 규칙 | 값 |
|---|---|
| 캐시 | 도서관 + 검색어 + 페이지 단위로 3분 |
| 같은 도서관 동시 요청 | 1건 |
| 같은 도서관 요청 간격 | 1초 이상 |
| User-Agent | 서비스 이름과 서비스 URL이 들어간 식별 문자열 (값은 12장) |
| 원문 | 서지 설명문과 표지 이미지를 저장하거나 보여 주지 않음. 제목·저자·출판사·수량만 씀 |

- 모든 값은 설정으로 빼서 코드를 고치지 않고 바꿀 수 있게 합니다.

### 5.7 도서관별 사용 여부 [확정] (사용자, 2026-09-27)

- 도서관마다 조회를 켜고 끌 수 있습니다. 끈 도서관에는 요청하지 않고 결과에도 넣지 않습니다.
- 주된 목적은 운영입니다. 도서관 사이트가 개편되거나 장애가 나서 수량을 읽지 못할 때 그 도서관만 끕니다.
- 드물겠지만 도서관이 중단을 요청할 때도 같은 설정으로 대응합니다.

### 5.8 지역 목록과 행정구역 변경 [확정]

- 지역(시도 → 시군구)마다 **우리 내부 ID**를 둡니다. 법정동 코드는 속성으로만 가집니다. 도서관 자격 규칙과 브라우저에 저장하는 사용자 선택은 모두 내부 ID를 씁니다. (사용자 제안, 2026-09-27)
  - 이유: 2026-07-01 전남광주통합특별시 출범으로 광주·전남의 법정동 코드가 새로 적용됐고, 같은 날 인천·안양 변경분도 공지됐습니다. 행정안전부 변경 공지는 반년 정도마다 나옵니다 (11장).
- 행정안전부 변경 공지가 나오면 법정동 코드 파일로 목록을 고칩니다 (수동, Liquibase 변경분).
- 없어진 지역은 지우지 않고 "폐지"로 표시하며, 어느 지역으로 바뀌었는지 연결합니다.
- 브라우저에 폐지된 지역이 저장돼 있을 때:
  - 새 지역 하나로 연결돼 있으면 자동으로 바꾸고 "행정구역 변경으로 OO이 △△로 바뀌었습니다"를 보여 줍니다.
  - 둘 이상으로 나뉘었으면 다시 고르라고 안내합니다.

## 7. 수용 기준

**입력과 도서관 고르기**
- AC-1: 검색어가 1글자면 요청을 보내지 않고 "2글자 이상 입력하세요"가 보인다. 51자 이상이면 입력이 거부된다 (문구는 개발 중 결정).
- AC-2: 지역을 고르지 않고 `채식주의자`를 검색하면 강서구·고흥군 결과가 모두 나오고, 줄마다 가입 조건 종류("누구나 가입" / "서울 거주·재직·재학")가 보인다.
- AC-3: 거주 지역으로 서울 마포구를 고르고 검색하면 강서구(서울 전체 자격)와 고흥군 결과가 나온다.
- AC-4: 거주 지역으로 부산 해운대구를 고르고 검색하면 고흥군 결과만 나오고, "선택한 지역에서 자격이 되는 시범 도서관이 없습니다"가 보인다.
- AC-5: 거주 경기 고양시와 직장 서울 중구를 고르고 검색하면 강서구와 고흥군 결과가 나온다.
- AC-6: 고른 지역은 새로고침 뒤에도 유지되고, 지역을 서버에 저장하는 요청은 없다.

**결과 내용과 순서**
- AC-7: 줄마다 제목, 저자, 출판사, 공급 업체, 도서관명, 보유, 대출 중, 예약 인원, 대출 가능 여부, 가입 방법 안내, 도서관 링크가 보이고, 수량은 같은 시점의 도서관 사이트 표시와 같다.
- AC-8: 같은 책이 두 도서관에 있으면 두 줄로 따로 나온다.
- AC-9: 결과가 "지금 빌릴 수 있어요"(재고 있음) → "예약하고 기다려요"(재고 없음) 두 그룹으로 나뉘고, 각 그룹 안에서 가입할 수 있는 도서관의 줄이 "가입 자격 확인 필요" 줄보다 먼저 나온다.
- AC-10: "지금 빌릴 수 있어요" 안에서는 재고 많은 순이고, 재고가 같으면 도서관 대출률이 낮은 쪽이 먼저다. "예약하고 기다려요" 안에서는 예약 인원 적은 순이고, 예약 인원이 같으면 보유 많은 쪽이 먼저다.
- AC-11: 결과 화면과 API 응답에 서지 설명문과 표지 이미지가 없다.
- AC-12: 페이지 바닥에 데이터 출처와 연락처가 보인다.

**조회 방식**
- AC-13: 응답이 빠른 도서관의 결과가 느린 도서관보다 먼저 화면에 나오고, 새 결과가 들어오면 규칙대로 다시 정렬된다.
- AC-14: 한 도서관이 8초 안에 응답하지 않으면 그 도서관은 "조회 실패"로, 다른 도서관은 정상으로 보인다.
- AC-15: `사랑`을 검색하면 도서관마다 전체 건수가 보이고, 처음에는 교보 50건·YES24 10건만 나온다. 그 도서관의 "더 보기"를 누르면 다음 페이지만 요청해서 합친다. (2026-09-27 기준 고흥 103건, 강서 233건)
- AC-16: 같은 도서관·검색어·페이지를 3분 안에 다시 요청하면 도서관으로 요청이 가지 않고 "N분 전 조회"가 보인다. 3분이 지나면 다시 요청한다. (서버 로그로 확인)
- AC-17: 같은 도서관으로 가는 요청은 동시에 1건이고, 요청 사이 간격이 1초 이상이다. (서버 로그로 확인)
- AC-18: 도서관으로 보내는 요청의 User-Agent에 서비스 식별 문자열이 들어 있다. (서버 로그로 확인)
- AC-19: 도서관 사용 여부를 끄면 그 도서관으로 요청이 가지 않고 결과에도 나오지 않는다.

**지역 목록**
- AC-20: 브라우저에 폐지된 지역이 저장돼 있고 그 지역이 새 지역 하나로 연결돼 있으면, 새 지역으로 바뀌고 변경 안내가 보인다. (시험용 폐지 데이터로 확인)

## 9. 다음 사이클을 위한 구조 요구 [확정] (사용자, 2026-09-27)

이번 사이클의 입력 화면과 시범 도서관에는 넣지 않지만, **구조는 지금부터 이것을 담을 수 있게** 설계합니다.

- 자격 규칙의 근거에 **재학**(학교 지역)과 **소속**(대학·회사 전자도서관)이 들어갈 수 있어야 합니다.
- 규칙 범위에 **기관**(예: 서울대, 특정 회사)이 들어갈 수 있어야 합니다.
- 그러면 다음 사이클에서는 사용자 입력(학교 지역, 내 학교·회사)과 시범 도서관만 추가하면 됩니다.
- 참고: 서울대·고려대 교보 전자도서관은 비소속자도 검색과 수량 조회가 가능합니다 (2026-09-27 확인).
