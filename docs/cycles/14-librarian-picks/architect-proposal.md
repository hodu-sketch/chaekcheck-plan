## 먼저 알릴 것: 서비스 DB에 우리 전자책 표지가 없음 [확정] (dev 코드 확인, 2026-10-12)

`catalog.book`·`catalog.holding`에 표지 칸이 없고, `collection` 가져오기도 표지 주소를 읽지 않음(dev `catalog`·`collection` 코드에 cover 없음, 웹 `ResultRow.tsx` "No description or cover"). 표지 주소는 수집 DB(SQLite `holding.cover_url`)에만 있음(`docs/research/ebook-catalog/crawl-method.md` 5절). scope·spec R4-4 ①("수집한 표지 먼저")은 이 사실을 모르고 정한 것.

## 결정 0: 우리 전자책 표지 (R4-4 ①)

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A (추천)** | 이번엔 ①을 빼고 "국립중앙도서관 표지 → 제목 글자". 우리 표지는 backlog | `catalog`·`collection`·가져오기 파일(사이클 11)을 안 건드림, 사이클 12·13과 안 부딪힘. 최근 52권 표지가 모두 열림 | 사용자가 정한 순서와 다름 |
| B | `catalog.book`에 대표 표지 주소 칸 + 가져오기가 수집 DB에서 채움 | 정한 순서 그대로 | 범위 크게 넓어짐(가져오기 파일 형식, 160만 권 다시 가져오기, 도서관 사이트 표지 주소가 여러 호스트·http라 CSP·받기 문제, 표지 저작권 다시 조사) |

## 결정 1: 모듈·스키마 이름, 옛 changeset

| 안 | 내용 |
|---|---|
| A | 이름 `popular` 그대로, `popular/001`을 그 자리에서 새 표로 고침 — 파일 변경 가장 적음, 이름과 뜻이 어긋나고 나중 "인기 도서"가 쓸 이름을 차지 |
| **B (추천)** | 새 모듈·스키마 `picks`, `popular/001` 지우고 `picks/001` 새로 씀(배포 전 규칙). 로컬 DB는 `DROP SCHEMA popular CASCADE` + `databasechangelog`의 `popular-001-*` 줄 지움(인계서 순서, AC-22) |
| C | `picks`로 바꾸되 `popular/002-drop` changeset으로 지움 — 손 작업 없음, 첫 배포 때 만들었다 지우는 쓸모없는 단계 |

## 결정 3: 우리 책과 맞추는 때 (R3-4)

| 안 | 내용 |
|---|---|
| **A (추천)** | 저장하지 않고 공용 캐시를 새로 고칠 때(10분마다, 목록 바뀐 직후) 맞춤 — 사이클 10 ADR-0074와 같음. `catalog`에 새 공개 조회 `BookLookup.byTitleAndAuthor`(가칭), 제목 키·저자 규칙은 `catalog`에 둠 |
| B | 받을 때 맞춰 `book_id` 저장 — 가져오기로 책 번호가 바뀌면 최대 일주일 404, 막으려면 새 이벤트 필요 |

- 주의: spec R3-1 ② 본제목 규칙은 지금 `CatalogText.mainTitleNorm`과 다름 → `catalog`에 새 함수로 더하고 `title_norm`(pg_bigm)으로 후보를 좁혀 Java에서 비교. 표·색인 변경 없음

## 결정 4: 국립중앙도서관 표지 (R4-5)

| 안 | 내용 |
|---|---|
| **A (추천)** | 받아서 폭 200px JPEG로 줄여 저장, 우리 주소로(ADR-0075·0081 방식). CSP 그대로, 폰 데이터 작음, BMP도 JPEG로. 사본 저장이라 이용 조건 확인이 더 중요 |
| B | 주소를 https로 바꿔 그대로 걺. 코드 적음, CSP를 `https://www.nl.go.kr`로 넓힘, 폰에서 한 쪽 수백 KB |

## 그 밖에 사용자에게 물을 것

- 출처 줄 "받은 날": 목록이 같아도 받기가 성공한 날로 바꿀지, 목록이 바뀐 날로 둘지 (초안: 마지막 성공한 받기)
- 모르는 `drCode`(새 분야)가 오면 빼고 수만 셀지, 받기 실패로 볼지 (초안: 빼고 셈)
- 이름 [안]: `picks`, `chaekcheck.picks.*`, `CHAEKCHECK_PICKS_FETCH_ENABLED`, `CHAEKCHECK_PICKS_NLK_API_KEY`, `BookLookup.byTitleAndAuthor`, `PickCategory`, 실패 이유 값
- 값 [안]: 시간 제한 5초/10초, 표지 간격 1초, 표지 본문 상한 5MB, 캐시 10분 (사이클 10 값)
