## 1. 수집 항목, 목적, 보유 기간

- **가입한 경우**: 카카오 회원 식별 번호, 거주·직장 지역, 직접 추가한 도서관
  - 목적: 로그인 유지, 도서관 찾기
  - 보유 기간: 탈퇴 또는 마지막 로그인 뒤 1년
- **자동으로 수집되는 정보**: IP 주소, 브라우저 종류, 접속 기록, 서비스 이용 기록(로그인한 경우 회원 번호 포함), 부정 이용 기록
  - 목적: 이용 통계, 운영과 보안, 책 추천
  - 보유 기간: 1년 (IP 주소·부정 이용 기록 30일, 접속 기록 14일). 회원 번호는 탈퇴하면 바로 지움

기간이 지나거나 탈퇴하면 바로 지웁니다. 지운 정보는 백업에 7일 동안 남았다가 지워집니다. 개인정보를 제3자에게 제공하지 않습니다.

## 2. 처리 위탁과 국외 이전

- **Amazon Web Services**
  - 맡긴 일: 서버·데이터 보관
  - 나라: 호주
  - 보유 기간: 위 1과 같음
- **Cloudflare, Inc.**
  - 맡긴 일: 웹 요청 전달·보안
  - 나라: 미국 및 Cloudflare 네트워크가 있는 나라
  - 옮기는 항목과 방법: IP 주소, 요청 정보 / 접속할 때 네트워크로 전송
  - 보유 기간: 업무에 필요한 기간 동안 보관하고, 기간이 지나면 지웁니다
