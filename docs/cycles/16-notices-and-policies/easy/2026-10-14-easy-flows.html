공지·약관 글이 화면에 나오기까지
네 가지 흐름

사이클 16이 docs/current/flows.md에 더한 흐름 38~41을 순서대로 풀었습니다. (2026-10-14, 설계됨·아직 만들지 않음)

1흐름 38: 공지 목록과 공지 글

숨기지 않았고 게시일이 된 공지만 보입니다. 고정 공지는 1쪽 맨 위에만 나옵니다.

1. 화면공지사항(/notices)을 열면 웹이 "1쪽 주세요"라고 sitecontent에 물음
2. sitecontent오늘(한국 날짜)을 정하고, 숨기지 않았고 게시일이 오늘 이전인 공지를 새 것부터 10개 고름. 1쪽이면 고정 공지를 맨 위에 따로 붙임(10개에 세지 않음)
3. 화면제목과 게시일 목록. 없는 쪽(?page=99)을 열면 마지막 쪽을 보여 줌
4. 글 열기공지 하나를 누르면 그 공지의 지금 판. 고친 공지는 "2026-11-03 · 고침 2026-11-04"와 날짜 고르기 칸
찾을 수 없음없는 번호·숨긴 공지·게시일 전 공지 → "찾을 수 없어요" + 목록 링크. 없는 판 번호 → "찾을 수 없어요" + 지금 판 링크

2흐름 39: 서비스 안내·이용약관·처리방침

세 화면 모두 같은 주소로 그 문서의 지금 판을 읽고, 날짜 고르기 칸으로 옛 판도 엽니다.

1. 화면/terms, /privacy, /about을 열면 웹이 그 문서를 sitecontent에 물음
2. sitecontent본문, 시행일, 바뀐 점, 판 목록을 줌. 시행일이 아직 안 된 판은 목록에도 없음
3. 화면제목 아래 "시행 2026-10-04"와 날짜 고르기 칸. 칸을 열면 "2026-10-04 ~ 2026-11-30 적용", "2026-12-01 ~ 지금"처럼 보임. 바뀐 점이 있으면 접힌 "바뀐 점 보기"
서비스 안내만글 아래에 "가입 조건은 2026년 10월에 조사한 내용입니다." 한 줄. 이 날짜는 사이클 13이 만든 주소에서 따로 받음

로그인 기능을 꺼도 처리방침은 보입니다. 이용약관은 로그인 기능이 켜져 있을 때만 화면에 나옵니다.

3흐름 40: 가입 화면의 약관·동의문

화면에 보인 판과 동의로 기록되는 판이 늘 같게 합니다.

1. 화면카카오 로그인 뒤 가입 화면이 auth에 "무엇에 동의받나요?"를 물음
2. authsitecontent에 지금 판 번호를 물어 "이용약관 1, 동의문 1"을 돌려줌
3. 화면바로 그 판(1)의 이용약관과 동의문 글을 sitecontent에서 읽어 보여 줌
못 불러오면체크 칸과 가입 버튼을 잠그고 "약관 글을 불러오지 못했어요" + 다시 시도
4. 가입 누름auth가 지금 판을 한 번 더 물음. 그사이 새 판이 시행됐으면 "약관이 바뀌었어요. 다시 확인해 주세요". 같으면 계정을 만들고 동의 기록에 1을 남김

4흐름 41: 새 공지나 새 판을 넣을 때

글을 넣는 화면은 없고, 사용자 확인 뒤 Claude가 SQL로 넣습니다. 배포 없이 시행일부터 보입니다.

1. 사용자"점검 공지 올려 줘", "처리방침에 ○○ 넣어 줘"
2. Claude글과 바뀐 점 초안을 보여 드림
3. 사용자확인
4. Claude운영 DB에 새 판을 넣음. 판 번호는 마지막 + 1, 시행일은 앞 판 날짜 이후. 옛 판은 고치거나 지우지 않음
5. 화면시행일이 되면 새로고침만으로 새 글이 보임

이용약관·동의문·처리방침을 바꿀 때는 알리는 공지도 같이 넣습니다. 다시 동의를 받아야 하는 큰 변경은, 다시 동의 화면을 만들기 전까지 넣지 않습니다.
