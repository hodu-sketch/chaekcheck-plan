## 포함

- 대상 [안]: 가입 조건을 조사해 둔 공공도서관 전부 (등록 도서관 + 사이클 07 이후 넣은 공공도서관, 약 400곳 [확인 필요]). 학교·대학·회사·기관(구성원용)은 지금처럼 조사하지 않음
- 단계 [안]:
  1. 페이지 찾기: dev에 이미 있는 `scripts/library/collect_join_evidence.py`를 그대로 씀 [안]. 이 스크립트는 알려진 출처 주소·홈페이지에서 시작해 회원·가입·자격 낱말이 든 같은 사이트 링크를 따라가고(최대 9장, 같은 호스트 1.1초 간격) 가입 자격 문장만 모아 둠. 지금은 사람(Claude 세션)이 그 문장을 읽고 정함 [확정] (dev 코드 확인, 2026-11-26)
     - 이 스크립트가 근거 문장을 하나도 못 찾은 곳만 AI가 사이트 안을 직접 찾아가게 할지(에이전트 단계)는 결정 페이지에서 묻습니다 [안]
  2. 값 읽기: Claude Haiku 5.5가 정해진 칸(근거: 거주·재직·재학·누구나, 범위, 방문 가입, 가입 방법, 출처 주소)과 근거 인용문을 냄
  3. 인용 대조: 스크립트가 인용문이 받아 온 원문에 그대로 있는지 확인. 없으면 "확인 못 함"
  4. 다른 곳 목록: 지금 값과 다른 곳만 보고서로 냄. 지금 값이 있는 곳 [확정] (dev 파일 확인, 2026-11-26):
     - `scripts/library/rules/public_join.tsv` — 사이클 07 이후 넣은 공공도서관 121줄, 인용문·출처 주소 칸 있음
     - `scripts/library/join_overrides.tsv` — 사람이 정한 값 21줄 (등록 도서관 번호), 마지막에 이김
     - 등록 도서관 나머지의 가입 규칙이 어느 파일에 있는지 [확인 필요]
  5. 승인 뒤 반영: 사용자가 승인한 줄만 위 파일에 고치고, 기존 넣기·반영 절차로 서비스에 들어감. 조사 기준일 `join_surveyed_on.txt`도 바뀜
- 먼저 시험 [안]: 공공도서관 20곳으로 2026-10-05 조사값과 얼마나 같은지 잼. 기준을 넘으면 전체 실행
- 돌리는 곳 [안]: 내 PC, Python 스크립트 + Claude API(SDK). LangGraph는 쓰지 않음
- 호출 예절: 지금 `fetch.py`처럼 우리 User-Agent, 같은 호스트 1.1초 이상 간격 [확정] (`docs/research/library-join/candidates.md` 1절의 기존 규칙)
