1로고는 결과 카드(검색 결과·책 화면)와 내 도서관 화면의
도서관 이름 앞에 보입니다 [안]

도서관을 이름보다 빨리 알아보게 하려는 자리 둘입니다. 검색칸 아래 "내 도서관 관리" 작은 창과 가입 정보 창에는 넣지 않습니다(창이 작아서).

다른 선택 ① 결과 카드에만 ② 내 도서관 화면에만. 넣는 곳이 적을수록 일이 줄지만 알아보기 효과도 줍니다.

2로고 크기는 높이만 맞춰 브라우저가 줄입니다(결과 카드 약 20px, 내 도서관 화면 약 24px).
그림 파일은 받은 원본 그대로 둡니다 [안]

"원본 그대로 축소만"을 지키는 방법입니다. 가로가 긴 로고는 길게, 정사각형 로고는 작게 보입니다. 자르거나 색을 바꾸지 않습니다. 줄 높이가 로고마다 달라지지 않게 칸 높이는 고정합니다.

다른 선택 가로·세로 모두 같은 크기 상자에 맞춤. 줄이 고르지만 가로가 긴 로고는 아주 작게 보입니다.

답: "이미 줄인 상태로 이미지를 저장해 두면?"

됩니다. 그리고 그쪽이 더 낫습니다. "원본 그대로 축소만"은 자르거나 색·모양을 바꾸지 말라는 뜻이고, 크기만 줄인 파일을 미리 만들어 두는 것도 축소입니다.

원본 파일 + 브라우저가 줄임 (처음 제안)미리 줄인 파일 (질문하신 방법)
받는 양199곳 합계 약 2.1MB, 큰 것 160KB. 결과 한 쪽에 로고 여러 개면 수백 KB(추정)표시 높이의 2배(선명한 화면용, 약 48px)로 줄이면 한 개 수 KB, 합계 수백 KB 이하(추정, 만들어 봐야 앎)
화질원본표시 크기에서는 차이 없음(2배로 만들어 둠)
할 일없음배포 전에 dev 스크립트로 한 번 만들기. 파일 형식(png·jpg·gif)은 그대로, svg 한 개는 원래 크기가 없어 그대로

브라우저에 한 번 받은 로고는 다시 받지 않도록 오래 보관하라고 알려 줍니다(웹 서버 설정). 그래서 두 방법 모두 두 번째부터는 빠르지만, 처음 받는 양은 미리 줄인 쪽이 훨씬 적습니다. 미리 줄인 파일로 하시려면 이 항목을 미승인하고 기타 없이 "미리 줄인 파일"이라고만 적어 주셔도 됩니다.

3결과 카드에서는 로고도 카드 링크(그 도서관 책 페이지)를 따르고,
내 도서관 화면에서는 로고를 누르면 그 도서관 첫 화면이 새 창으로 열립니다 [안]

결과 카드는 지금 카드 전체가 그 도서관 사이트의 책 페이지로 가는 링크입니다. 그 페이지도 원 전자도서관이므로 "누르면 원 전자도서관으로"를 지킵니다. 내 도서관 화면은 카드 링크가 없어서 로고에 첫 화면 링크를 답니다.

다른 선택 결과 카드에서도 로고만 따로 첫 화면 링크. 원칙에는 더 가깝지만, 카드를 누르려다 다른 곳으로 가는 일이 생깁니다.

4로고 그림을 불러오지 못하면 이름만 보입니다 [안]

깨진 그림 표시 없이 로고 자리를 비웁니다.

다른 선택 회색 빈 상자를 남김. 줄이 고르지만 빈 자리가 눈에 띕니다.

3"서비스 안내" 화면과 로고 내리기

5새 화면 "서비스 안내"(/about)를 만들고, 이용약관·처리방침과 같은
흰 카드 한 장 모양으로 셋을 적습니다: 소개 한두 줄, 제휴·후원 없음 문구, 로고 내림 요청 연락 방법 [안]

문구: "각 도서관의 로고와 이름은 그 기관의 것이며 책첵은 제휴·후원 관계가 없습니다." 모든 화면 바닥글에 "서비스 안내" 링크를 둡니다(이미 정하심). 지금 바닥글에는 이용약관·처리방침 링크가 있습니다.

다른 선택 새 화면 없이 이용약관 안에 절로 넣음. 화면이 늘지 않지만 "서비스 안내" 링크라는 정하신 방식과 다릅니다.

6로고 내림 요청 연락처는 서비스 전용 이메일 주소를 새로 만들어 적습니다 [안]

지금 서비스 공개 연락처가 없습니다(수집기 이름표의 연락처도 같은 문제로 비어 있음). 개인 이메일을 화면에 공개하지 않으려면 서비스 전용 주소가 필요합니다. 주소는 사용자가 만들어 알려 주시면 넣습니다(그 전에는 dev가 자리 글로 둠).

다른 선택 ① 문의 양식(새 화면·서버 저장) ② 이메일 대신 "도서관에서 연락 주시면…"만 적고 연락처는 나중에. 원칙 "요청 오면 바로 내림"을 지키려면 연락 길은 있어야 합니다.

7로고를 내릴 때는 운영자가 그 도서관의 "로고 보임" 값 하나를 끄면,
새로고침한 모든 화면에서 바로 사라집니다 [안]

배포를 기다리지 않고 DB 값만 바꿉니다. 그림 파일은 다음 배포 때 지웁니다. 도서관을 켜고 끄는 지금 방식(운영자가 SQL로 바꿈)과 같습니다.

다른 선택 그림 파일을 지우고 다시 배포. 칸이 하나 줄지만 내리는 데 배포만큼 걸립니다.
