화면 흐름에서
13가지를 정해 주세요.

이번 사이클에서 바뀌는 화면은 넷입니다: S1 검색(로그인 전 줄, 결과 줄), S3 책(결과 줄), S10 내 도서관(로그인 전에도 열림, 후보 도서관 찾기), S11 옮기기 창(도서관도 함께). 그림은 위치와 순서만 보이는 것이고, 실제 모양은 dev의 지금 화면(토스증권 참고 디자인)을 따릅니다.

1화면이 이어지는 길

로그인하지 않아도 S1의 [관리]로 내 도서관 화면에 들어가 도서관을 넣을 수 있게 됩니다. 로그인하면 지역과 넣은 도서관을 계정으로 옮길지 한 번 묻습니다.

다른 선택 설정 창(⚙) 안에 "내 도서관" 항목을 둠. 줄이 짧아지지만 로그인 후와 들어가는 곳이 달라집니다.

3로그인 전 화면 맨 위에 "이 브라우저에만 저장돼요.
로그인하면 계정에 저장할 수 있어요" + [로그인] [안]

다른 기기에서는 보이지 않는다는 것을 미리 알립니다.

다른 선택 안내 없이 둠. 화면이 단순하지만 다른 기기에서 없어진 것처럼 보일 수 있습니다.

4로그인 전에도 "지역으로 자동" 목록을 보입니다.
판정은 S1 "가입 가능한 곳"과 같습니다 [안]

로그인 후 화면과 모양을 같게 해서, 로그인 전후로 다른 화면을 배우지 않게 합니다.

다른 선택 로그인 전에는 직접 추가 두 구역만 보임. 일이 적지만 화면이 로그인 전후로 달라집니다.

5도서관 찾기 결과는 친 글자로 이름이 시작하는 곳 먼저,
그다음 가나다순 [안]

예: "강동"을 치면 "강동대학교 (…)", "강동구립도서관"이 먼저, "서울 강동…"은 그 뒤. 고를 수 있는 도서관이 약 2,700곳이라 순서가 중요합니다.

다른 선택 가나다순만. 단순하지만 원하는 곳이 아래로 밀릴 수 있습니다.

6찾기 결과는 한 번에 20곳까지 보이고,
더 있으면 [더 보기] [안]

예: "대학"을 치면 수백 곳이 맞습니다. 처음 20곳만 보이고 [더 보기]로 20곳씩 더 봅니다.

다른 선택 맞는 곳을 모두 보임(스크롤). 단순하지만 폰에서 길어집니다.

7두 글자 이상 쳐야 찾기 시작합니다 [안]

한 글자("대")로는 너무 많은 곳이 맞아서입니다.

다른 선택 한 글자부터. 짧은 이름을 찾기 쉽지만 결과가 너무 많습니다.

8로그인 전 저장이 막히면(브라우저 저장을 꺼 둔 경우)
"이 브라우저에 저장하지 못했어요" [안]

사생활 보호 모드 등에서 브라우저 저장이 안 될 때입니다. 화면을 닫기 전까지는 넣은 도서관이 검색에 쓰입니다.

다른 선택 다른 문구를 기타에 적어 주세요.

9창 문구: "이 브라우저에 저장된 것을 계정에 저장할까요?"
+ 지역 줄 + "직접 넣은 도서관 N곳: 이름…" [안]

지금 창의 "이 브라우저에 고른 지역이 있어요. 계정에 저장할까요?"를 지역과 도서관을 함께 말하도록 바꿉니다. 지역만 있거나 도서관만 있으면 있는 줄만 보입니다.

다른 선택 지역 창과 도서관 창을 따로 차례로 띄움. 하나씩 고를 수 있지만 창이 두 번 뜹니다.

10[계정에 저장]을 누르면 지역과 도서관을 함께 옮깁니다.
따로 고르지 않습니다 [안]

계정에 이미 있는 쪽은 옮기지 않고 창에도 보이지 않습니다(지금 규칙과 같음). 브라우저 값은 지우지 않습니다.

다른 선택 창 안에 체크 상자 둘. 고를 수 있지만 창이 복잡해집니다.

11옮겨서 20곳을 넘게 되면 넘는 것은 옮기지 않고
"20곳까지만 저장했어요" [안]

계정에 직접 넣은 도서관이 없을 때만 옮기므로 보통은 일어나지 않습니다. 브라우저 값이 20곳을 넘는 일도 없어서, 실제로는 안전장치입니다.

다른 선택 옮기기를 멈추고 안내만. 아무것도 옮겨지지 않습니다.

12도서관 로고는 이번에 넣지 않고 backlog에 둡니다.
다음 화면 사이클에서 자리와 "서비스 안내" 페이지를 함께 정합니다 [안]

수집 세션이 로고를 모으는 중이고, 쓰는 원칙은 이미 정하셨습니다(원본 축소만, 누르면 원 전자도서관으로, 요청 오면 바로 내림, 회사·업체 기본 로고 안 씀, 공공도서관만, 안내 문구는 "서비스 안내" 페이지). 그런데 업체 기본 로고를 가르는 기준(몇 곳 이상 같으면)은 수집이 끝나야 정할 수 있고, "서비스 안내" 페이지가 아직 없습니다. 근거: docs/research/maintenance/library-logos.md

다른 선택 이번에 넣음: 내 도서관 화면 목록과 결과 줄에 로고 자리, 로고 파일 저장, "서비스 안내" 페이지와 모든 화면 아래 링크. 사이클이 더 커집니다.

13가입 조건이 확인된 후보 공공도서관은 등록 도서관처럼
지역·직장으로 판정해 검색에 보이게 합니다 [안]

수집 세션이 사이클 밖에서 후보 도서관 가입 조건을 조사하고 있습니다(docs/research/library-join/candidates.md). 지금 서비스는 도서관마다 가입 규칙 줄을 두는 구조라, 규칙 줄만 더하면 화면을 바꾸지 않고 "가입 가능한 곳"에 들어갑니다. 조사 결과가 이 사이클 인계 전에 오면 이번 가져오기에 넣고, 늦으면 다음 가져오기에 넣습니다.

이번 사이클 범위에서 "후보 도서관 가입 자격 조사"를 뺀 결정(2026-10-05)과 달리, 조사 결과를 받는 길만 열어 둡니다. 조사 자체는 사이클 밖입니다.

다른 선택 이번에는 모든 후보 도서관을 "직접 넣었을 때만"으로 두고, 가입 조건은 다음 사이클에서. 규칙이 하나로 단순하지만, 조사한 공공도서관이 지역에 맞아도 보이지 않습니다.
