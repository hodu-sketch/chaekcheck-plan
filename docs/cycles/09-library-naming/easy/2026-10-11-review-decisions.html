1반드시 고칠 것 7개: 고친 내용

문서끼리 어긋난 곳을 정하신 대로 맞췄습니다.

짚은 것고친 것
명세 R2에 "업체를 칸으로 둘지 설계에서 정함"이 남음"DB 칸, 도서관 수집이 정함"으로
겹침 규칙과 완료 기준 AC-7에 순번이 빠짐"이름·업체·대출 방식·순번이 모두 같으면 거절, 순번만 다르면 들어감"으로. 범위 목표도 같게
"· N번째 사이트" 표시가 화면 흐름·완료 기준에 없음화면 흐름의 모든 자리(결과 카드, 내 도서관 세 목록)와 상태에 더함. 완료 기준 AC-9 새로 더함(지금 데이터엔 없어 테스트 데이터로 확인)
API로 값을 보내는 것, 번호로 고치는 변경 파일, 이름 찾기를 화면에서 하는 것이 ADR에 없음ADR-0071은 이미 Accepted라 고칠 수 없어 새 ADR-0076 초안을 만듦(아래 3번에서 고르심)
고칠 이름 수가 문서마다 다름(285, 293)"번호당 한 줄, 최종 이름 하나. 293은 겹침을 빼기 전 수, 실제 줄 수는 dev가 셈"으로 적음. 예: 1575는 괄호 떼기와 "완주동상초등학교"가 겹쳐 한 줄
진천군립 "대여형" 떼기가 명세에 없음명세 R1-11로 더함
정해진 것에 [안] 표시가 남음[확정]으로 바꿈, 사전 조사 문서 맨 위에 "결과는 명세·설계가 최신" 한 줄

2고치면 좋은 것: 고친 것과 못 고친 것

8개 중 6개는 고쳤고, 2개는 ADR 규칙 때문에 그대로 둡니다.

고친 것
명세·화면 흐름의 낡은 문장(사이클 08이 "진행 중"이라고 쓴 곳)을 회고 결과로 바꿈
범위의 "포함"에 덤 작업 한 줄: 메리츠 이름 오류, 서대문·마산, 진천군립, 수집 DB 이름, dev 도구 정리
명세 R5에 "결과 카드는 이름 다음 줄"을 적음
업체 필수 규칙에 새 이름이 없던 것 → 아래 2번 칩
backlog: "실물 도서관이 생기면 업체가 비어 겹칠 수 있음" 한 줄, "013·014" 표기
dev 웹 테스트 줄 번호(201 → 202)
그대로 두는 것이유
ADR-0071의 대안 순서(A, B, C, F, D, E)Accepted ADR은 상태 줄 말고는 고칠 수 없게 막혀 있음
ADR-0017 본문에 "ADR-0071로 바뀜" 링크같은 이유. ADR 목록(docs/adr/README.md)과 ADR-0071 쪽에 이미 적혀 있음

업체 필수 규칙 이름은 library_vendor_required_check [안]

앞서 정하신 "전자도서관이면 업체가 꼭 있어야 함"을 DB 확인 규칙으로 만들 때의 이름입니다. 업체 값 6개를 확인하는 library_vendor_check와 따로 둡니다. 지금은 도서관이 모두 전자도서관이라 늘 필수이고, 실물 도서관 사이클에서 다시 봅니다.

다른 선택 — 규칙 하나로 합침: 이름이 하나 줄지만 위반이 났을 때 어느 조건인지 덜 분명합니다.

추천: 따로 둠.

3새 ADR-0076 초안

설계에서 정하신 세 가지를 기록으로 남깁니다. 번호는 사이클 10 세션이 0072~0075를 써서 0076입니다.

칸내용
제목도서관 분류 값은 API로 보내고 화면이 글자를 만듦, 이름은 번호로 고치는 changeset, 이름 찾기는 화면에서
결정① 도서관 목록과 검색 스트림에 vendor·lendingModel·orderNo, 글자는 웹이 만듦, 값이 없으면 이름만 ② 이미 있는 이름은 새 변경 파일(library/014)에서 번호와 옛 이름이 맞을 때만 고침, seed는 그대로, 목록은 name_overrides.tsv에 ③ 직접 추가 이름 찾기는 웹에서만(ADR-0058 그대로)
바꾸는 기록docs/current/api.md의 "대출 방식은 웹에 보내지 않음". ADR-0019("화면은 화면 종류로 갈리지 않음")는 그대로 지킴
이유세 결정 모두 "제안 → 승인"(2026-10-11, 설계 결정 페이지)
검토한 대안서버가 글자를 보냄 / 웹이 화면 종류로 업체를 계산 / seed 파일을 직접 고침 / 서버에 찾기 API — 채택하지 않은 이유는 모두 "이유 미확인"(말씀하신 이유가 없어서)
결과DB를 다시 만들지 않음, 화면 문구가 웹 한 곳에. 대신 목록 응답이 커지고 이름 고침 목록이 길어짐(첫 배포 직전 정리 때 합침)

ADR-0076을 이 초안대로 씀 [안]

승인하시면 docs/adr/0076-…md로 쓰고, 결정 자체는 이미 승인하셨으므로 Accepted로 둡니다. 그다음 현재 설계 문서에 사이클 09를 합치고 인계서를 씁니다.
