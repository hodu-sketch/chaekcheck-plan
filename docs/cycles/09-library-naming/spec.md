- 작성: 2026-10-11 (사이클 08 dev 진행 중에 미리 씀). 범위 `scope.md`, 조사 `research.md`, 근거 `../../research/maintenance/library-naming-handoff.md`

## 사용자 이야기

- 이용자는 같은 기관의 전자도서관이 여럿일 때 어느 것이 어느 업체·대출 방식인지 이름 옆에서 바로 알고 싶다. 지금은 두 번째 사이트에만 "(YES24)", "(구독)" 같은 괄호가 붙고 첫 사이트는 알 수 없어서 [확정] (사용자: "각 전자도서관마다 분류를 꼭 했으면 해 어떤 것만 따로 분류 ( ) 안에 붙는게 이상해서", 2026-10-11)

### R5. 화면 표시

- 이름 옆에 작은 글씨로 "· 업체 · 대출 방식". 예: "동대문구립도서관 · 교보 · 소장", 통합 포털은 "부산광역시 전자도서관 · 통합 포털" [확정] (결정 5, `scope.md`)
- 결과 카드(S1·S3)는 모든 폭에서 이름 다음 줄에 "교보 · 소장", 내 도서관(S10)은 이름 옆(폰은 아래 줄) [확정] (`flow.md`)
- 순번 2 이상이면 분류 뒤에 "· N번째 사이트" (모든 자리, R4-4) [확정]
- 보이는 곳: 결과 카드(S1·S3), 내 도서관(S10)의 목록, 직접 추가 결과 [확정] (사용자 승인, 2026-10-11, `easy/2026-10-11-spec-flow-decisions.html`). 화면별 자리는 `flow.md`에서 정함

### R6. S10 직접 추가 이름 찾기

- 지금은 공백을 무시한 부분 일치로 이름만 찾음(`libraryNames.ts`). 괄호를 떼면 "교보", "YES24"로 찾던 것이 안 됨
- 이름과 분류 글자를 함께 찾는다. 예: "동대문 yes24" → 동대문구립도서관 · YES24 [확정] (사용자 승인, 2026-10-11, `easy/2026-10-11-spec-flow-decisions.html`)
- 결과 줄에 분류를 붙여 같은 이름 줄을 구분한다 [확정] (사용자 승인, 2026-10-11, `easy/2026-10-11-spec-flow-decisions.html`)

## 상태별 동작

## 수용 기준

- AC-1: 결과 카드, S10 목록, 직접 추가 결과 어디에도 R1-1의 괄호 표시가 보이지 않는다
- AC-2: "(주)…", "…(임직원)" 같은 기관 이름 속 괄호는 그대로 보인다
- AC-3: 모든 도서관 이름 옆에 업체가 보이고, 통합 포털을 뺀 모든 도서관에 대출 방식이 보인다 (PC·태블릿·폰)
- AC-4: 같은 이름의 두 사이트(예: 군산시립도서관 교보 / YES24 / 북큐브)가 분류로 구분된다
- AC-5: 이름이 바뀌기 전에 내 도서관에 넣은 도서관이 바뀐 뒤에도 그대로 있다(로그인 전 브라우저 저장, 로그인 계정 모두)
- AC-6: S10 직접 추가에서 "동대문 yes24"로 찾으면 YES24 사이트가 나온다
- AC-7: 이름·업체·대출 방식·순번이 모두 같은 도서관을 넣으려 하면 DB가 거절한다(통합 포털끼리 포함). 순번만 다르면 들어간다
- AC-8: 책 검색 결과의 소장·대출 표시가 바뀌기 전과 같다(같은 검색어로 비교)
- AC-9: 순번이 2 이상인 도서관은 분류 뒤에 "· N번째 사이트"가 보인다(결과 카드, S10 목록). 지금 데이터에는 없으므로 테스트 데이터로 확인
