책 묶기 기준 다시 보기를 사이클 11에 넣을까

질문: "책 묶기 기준 다시 보기, 이것 지금 사이클에서 같이 하는 건?" (2026-10-12). 묶기 기준은 다음에 가져올 때 같은 책을 한 권으로 묶는 규칙이고, 지금 규칙과 알려진 문제는 docs/research/ebook-catalog/same-book-isbn.md 5절에 있습니다.

1같이 하면 부딪히는 곳

사이클 11의 힙 줄이기는 "세 방식이 지금 규칙으로 한 권도 다르지 않게, 번호까지 같게" 만드는 일입니다. 같은 사이클에 규칙을 바꾸면 비교할 기준이 움직이고, 바꾼 규칙을 세 방식 모두에 넣어야 합니다.

  • 세 곳에 넣어야 함: 규칙은 지금 Java 코드(BookGrouping)에 있습니다. sql 방식은 같은 규칙을 SQL로 다시 쓰는 것이라, 규칙이 바뀌면 SQL도 바꿔야 합니다.
  • 비교가 흐려짐: "다른 책 0권"은 같은 규칙끼리라서 의미가 있습니다. 규칙과 방식을 동시에 바꾸면, 결과가 달라졌을 때 규칙 때문인지 방식 때문인지 가르기 어렵습니다.
  • 번호가 바뀜: 규칙이 바뀌면 묶음이 갈라지거나 합쳐진 책의 번호가 바뀝니다(ADR-0062는 소장이 같으면 번호를 잇지만, 묶음이 바뀐 책은 새 번호·사라진 번호가 생김). 회원 책 저장 같은 기능이 생기기 전에 하는 편이 낫습니다.

2다시 보기 전에 알아야 할 것 (지금은 숫자만 있음)

알려진 문제 대부분이 "표본을 보지 않음" 상태입니다. 규칙을 고르기 전에 표본 조사가 먼저 필요하고, 이건 코드 없이 plan에서 미리 할 수 있습니다.
