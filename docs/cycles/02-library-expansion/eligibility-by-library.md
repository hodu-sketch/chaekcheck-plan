- 대상: 교보 공식 목록의 공공도서관 216곳 + 웹러브 북스에서 고른 YES24 공공도서관 122곳 (조사 결과가 기록된 곳). 같은 도서관이 두 플랫폼에 있으면 두 줄로 나옵니다.

- 요약과 도서관 묶음은 `eligibility.md`, 조사 방법은 `collection-method.md` 4-3
