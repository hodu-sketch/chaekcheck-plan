  • 순서: ① 책 번호 잇기 — 임시 표(load_*)에 COPY한 뒤 좁은 맞대기 표로 옛 holding과 (library_id, item_key)를 맞대 책 번호와 소장 번호를 확정 ② 준비 스키마 catalog_next에 네 표를 LIKE … INCLUDING DEFAULTS IDENTITY GENERATED STORAGE COMPRESSION으로 만들고(색인·제약 없음) 확정된 책 번호 순으로 INSERT, 소장은 ORDER BY book_id, library_id, holding_id(같은 책 소장 줄이 붙음) [확정] (dev 구현 확인, 2026-10-11). 넓은 줄(소장)은 임시 표에 한 번, catalog_next에 정렬해서 한 번, 두 번 씀(book_id 순 정렬 때문) — 쓰기 시간이 이미 줄어 바꾸지 않음 (dev) [확정] (사용자 승인, 2026-10-11, docs/cycles/08-polish-swap-memory/easy/2026-10-11-midpoint-decisions.html) ③ 색인·제약을 한 번에 만듦(정의는 운영 표에서 pg_get_indexdef·pg_get_constraintdef로 읽어 같은 이름으로, 가져오기 세션만 maintenance_work_mem·work_mem↑) ④ VACUUM (ANALYZE) ⑤ 짧은 트랜잭션에서 옛 표 DROP, catalog_next의 표를 SET SCHEMA catalog. 옛 표는 바로 지움 [확정] (ADR-0065)
