# ADR-0065: 가져오기는 새 표에 쓰고 바꿔 끼운다

Status: Accepted (국가서지 부분은 ADR-0069, 소장 번호 부분은 ADR-0070이 바꿈)
Date: 2026-10-11
Cycle: 08-polish-swap-memory
Supersedes: 없음 (ADR-0062 보완, `catalog-refresh.md` 5.1 방향을 구현 방식으로 정함)

## 배경
가져오기 한 번에 36~41분이 걸리고, 마지막 쓰기 단계(22~27분)에서 `TRUNCATE`가 잡은 잠금 때문에 검색이 멈춘다. 쓰기 때 색인 12개를 줄마다 고치고, 국가서지 TTL 7.7GB를 매번 처음부터 푼다(dev 코드, `research.md` 10-2절). 소장 번호는 가져올 때마다 1부터 다시 매겨, 가져오는 동안 검색이 되면 열린 화면의 "더 보기"가 다른 소장 줄을 가리킬 수 있다. 여덟 방향을 공식 문서와 코드로 비교했다(`research.md` 10절).

## 결정
- 기존 `catalog` 책·사람·소장·도서관별 수집 시각 표는 그대로 두고, 준비 스키마에 새 표를 색인 없이 만들어 책 번호 순으로 쓴다(같은 책 소장 줄이 붙음)
- 책 번호 잇기(ADR-0062)는 옛 표와 맞대어 그대로 한다
- 다 쓴 뒤 색인·제약을 한 번에 만들고(가져오기 세션만 `maintenance_work_mem` 올림) `VACUUM (ANALYZE)`
- 짧은 트랜잭션에서 옛 표를 지우고 새 표를 `catalog`로 옮긴다(`lock_timeout` 짧게, 다시 시도). 옛 표는 바로 지운다
- 소장 번호는 지난번 최대 번호 다음부터 매긴다. 책 번호는 지금처럼 다시 쓰지 않는다
- 국가서지 TTL을 푼 결과는 `collection`이 파일 지문·정리 규칙 판과 함께 남기고, 같으면 다시 쓴다
- 먼저 쓰기 단계 안의 시간(두 번째 읽기, 임시 표, 맞대기, 옮겨 쓰기)을 나눠 잰 뒤, 가장 느린 곳만 더 고친다
- 표 바꾸기는 `catalog` 안, 국가서지 결과는 `collection` 안. 공개 `CatalogLoad` 모양과 모듈 방향은 그대로

## 이유 (사용자 발언)
- "기존 테이블을 냅두고 TEMP 테이블 두었다가 다 되면 TEMP랑 기존이랑 바꿔치기 하는 식으로" (2026-10-05)
- "이거 꼭 이 방향이 아니고 db가져오기? 교체? 시간을 줄이기 위한 것이거든 … 그게 가능한 여러 방향을 조사해봤으면 해" (2026-10-06)
- "업데이트도 생각했지만 데드 튜플 쌓이는게 싫어서" (2026-09-30, `catalog-refresh.md` 5.1)
- 묶음·소장 번호·옛 표 삭제·먼저 재기: 제안 → 승인 (2026-10-10~11, 설계 결정 #1~4)

## 검토한 대안
### A안: 새 표에 쓰고 바꿔 끼우기 + 색인 나중에 + 국가서지 결과 남기기 (채택)
- 장점: 검색 멈춤이 바꿔 끼우는 순간만, 옛 줄이 쌓이지 않음, 같은 책 줄이 붙음, 국가서지 6.5~9분 줄 것으로 봄
- 단점: 바꾸는 동안 디스크 두 벌, 색인·제약 정의를 Liquibase와 같게 유지할 장치 필요
### B안: 바뀐 줄만 고치기 (MERGE)
- 장점: 바뀐 게 적으면 가장 빠름, 검색 안 멈춤
- 단점: 옛 줄이 쌓임, 책 묶기는 전체를 다시 계산, 붙인 줄이 다시 흩어짐
- 채택하지 않은 이유: 사용자 "데드 튜플 쌓이는게 싫어서" (2026-09-30)
### C안: 도서관별 표 나누기 (파티션)
- 장점: 한 도서관만 빠르게 교체
- 단점: 책 번호로 읽는 책 화면이 약 2,650조각을 다 뒤짐
- 채택하지 않은 이유: [이유 미확인] (추천하지 않은 안, 사용자는 A를 승인)
### D안: 지금 흐름에서 색인만 나중에
- 장점: 고칠 곳이 가장 적음
- 단점: 검색은 여전히 멈춤
- 채택하지 않은 이유: [이유 미확인]
### E안: 다른 DB에서 가져와 옮기기
- 단점: 옮기는 단계가 결국 A와 같은 일, 지금 규모에 지나침
- 채택하지 않은 이유: [이유 미확인]

## 결과
- 나중에 분리할 때: 표 바꾸기는 그대로 "catalog 표를 통째로 바꾸는 쓰기 API"가 된다
- 다른 모듈 표가 `catalog` 표를 외래 키로 가리키게 되면 바꿔 끼우기도 고쳐야 한다
