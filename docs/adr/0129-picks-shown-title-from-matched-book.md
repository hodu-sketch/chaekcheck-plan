# ADR-0129: 추천 목록 화면의 책 이름은 맞춘 우리 책 제목에서 판 표시를 덜어 낸 이름 (못 맞추면 목록 이름)

Status: Proposed
Date: 2026-10-16
Cycle: 21-recommended-books
Supersedes: 없음 (ADR-0090의 "화면에는 목록 이름" 부분만 바꿈)

## 배경
추천 목록(사서·이동진·서울대)의 책 이름은 목록을 만든 곳이 적은 이름이다. 서울대 100선은 작품·선집 이름(「셰익스피어: 햄릿 외 3편」, 「일리아스, 오디세이아」)이라, 실제로 빌릴 판(「햄릿(Hamlet)」, 「오디세이아(고대 그리스어 완역본)」)과 다르다(조사 `docs/research/snu-100/picks.md`, 2026-10-15). 설계 결정 #11은 처음에 "화면 이름 = 목록 이름, 저자·출판사는 맞춘 판"으로 정했다.

## 결정
- 우리 책을 맞춘 줄의 화면 이름(글자 표지, 책 창 제목)은 그 책의 제목에서 판 표시를 덜어 낸 이름이다. 덜어 내는 것: 끝 괄호 안의 판·언어 표시, 끝 낱말 "오리지널판", 끝 권 번호(`1`, `(상)`), 앞 `[시리즈]` 표시. 덜어 내 빈 이름이 되면 그대로 둔다 [안: 규칙 세부는 개발 때 다듬음]
- 못 맞춘 줄은 목록 이름이다
- 세 목록 모두 같다. 목록 이름이 화면 이름과 다르면 책 창에 "목록 이름 「…」"을 한 줄로 남긴다
- 운영 서버 캐시가 목록을 메모리에 담을 때 맞춘 책의 제목을 함께 읽어 덜어 낸다(저장하지 않음). 그래서 `catalog` 공개 레코드(`IsbnBook`, `TitleAuthorBook`, 번호로 찾기 결과)에 제목 칸이 더해진다. API 응답에 `listTitle`(다를 때만)

## 이유 (사용자 발언)
- "아 그런대 목록 책 이름 말이야... 우리 것대로 보정해주면 어떨가?" (2026-10-16, 캔버스)
- 책 이름 보정 페이지 #1(판 표시를 덜어 낸 우리 제목)·#2(세 목록 모두) 제안 → 승인 (2026-10-16)

## 검토한 대안
### A안: 판 표시를 덜어 낸 우리 제목 (채택)
- 장점: 화면 이름이 빌릴 책과 같고, 책 검색에 넣어도 같은 책이 나옴. 단점: 덜어 내는 규칙 코드가 생김, 목록 이름은 책 창 한 줄로만 남음
### B안: 우리 제목 그대로
- 단점: 「토지. 1(1부 1권)」처럼 판 표시가 남음. 채택하지 않은 이유: [이유 미확인] (사용자는 A 승인)
### C안: 목록 이름 그대로 (처음 설계 결정 #11)
- 채택하지 않은 이유: 사용자 "우리 것대로 보정해주면 어떨가?" (2026-10-16)
