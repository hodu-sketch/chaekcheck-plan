# ADR-0024: 검색 조건은 이름 있는 파라미터 하나로 받음

Status: Superseded by 0025
Date: 2026-09-29
Cycle: 03-search-conditions
Supersedes: 없음

## 배경
사이클 03은 제목뿐 아니라 저자·출판사로도 검색한다(한 번에 조건 하나, spec). ADR-0009는 내부 `SearchField`(TITLE, AUTHOR, PUBLISHER)와 캐시 키의 필드만 두고, API 파라미터는 나중에 `field=`를 붙이는 안을 제안했다. 세 API(첫 묶음 스트림, 다음 묶음 스트림, 도서관별 더 보기)는 지금 `q`만 받는다. 아직 배포 전이라 외부 호출자는 없다. 여러 조건 AND 검색은 이번에 제외했지만 backlog에 있다.

## 결정
- 세 API는 `q` 대신 `title=` / `author=` / `publisher=` 중 정확히 하나를 받는다.
  - 하나도 없거나 값이 비어 있으면 400 `validation_error`, `errors[].code: required` [안]
  - 둘 이상이면 400 `validation_error`, `errors[].code: too_many` [안]
  - 검색어 글자 수(정규화 후 2~50자) 오류는 지금처럼 400 `invalid_query`
- `q`는 API에서 없앤다. 웹이 옛 주소 `/search?q=…`를 `/search?title=…`로 바꿔 연다.
- `targets` 이벤트는 요청과 같은 이름으로 조건을 돌려준다 (예: `"author":"김달"`). 지금의 `query` 칸은 빠진다.
- 도서관 결과 페이지 객체(`library-result`, 도서관별 더 보기 응답)는 바뀌지 않는다. `query`는 검색어 그대로다.
- 내부 `SearchField`·`SearchQuery(value, field)`·캐시 키(ADR-0009)는 그대로 쓴다.

## 이유 (사용자 발언)
- "나중에 and조건에 그게 나아보임" (2026-09-29)
- `q`를 API에서 없애고 웹 주소만 바꾸는 것: Claude 제안 → 사용자 선택. 사용자 발언 [이유 미확인]
- `targets`에 요청과 같은 이름으로 돌려주는 것: [이유 미확인]

## 검토한 대안
### B안: 이름 있는 파라미터 하나 (`title`/`author`/`publisher`) (채택)
- 장점: 주소가 읽기 쉬움(`?author=김달`). 나중에 AND 조합으로 넓히기 자연스러움
- 단점: "하나만" 규칙과 오류가 새로 생김. 세 API·웹 주소·`targets`와 테스트를 모두 바꿔야 함
### A안: `q` + `field=title|author|publisher` (architect 추천)
- 장점: 옛 주소·기존 호출이 그대로 동작. `filter`·`scope`와 같은 방식. 되돌리기 쉬움
- 단점: 오류 본문이 `{"field":"field"}`처럼 어색함. AND로 넓힐 때 모양을 다시 바꿔야 함
- 채택하지 않은 이유: "나중에 and조건에 그게 나아보임" (B안을 고른 이유로 사용자)
### C안: `q` 안에 접두어 (`q=author:김달`)
- 장점: 파라미터가 바뀌지 않음
- 단점: `:`가 든 제목과 부딪치고 글자 수 규칙이 꼬임
- 채택하지 않은 이유: [이유 미확인]
### `q`를 API에 `title` 별칭으로 남기는 안
- 장점: 옛 API 호출이 그대로 동작
- 단점: 같은 뜻의 파라미터가 둘이 되고 함께 왔을 때 오류 규칙이 하나 더 생김
- 채택하지 않은 이유: [이유 미확인]
### `targets`에 `query` + `field` 두 칸 (추천안)
- 장점: `query` 칸이 그대로라 기존 웹 코드와 페이지 객체의 `query`와 이름이 맞음
- 채택하지 않은 이유: [이유 미확인]

## 결과
- 좋아지는 점: 조건 이름이 요청·주소·`targets`에서 같음. AND 조합을 열 때 파라미터를 더 받는 것으로 넓힐 수 있음
- 감수하는 점: 사이클 02 컨트롤러·스트림·웹 테스트를 고쳐야 함. 옛 `?q=` 주소는 웹이 바꿔 줄 때만 동작하고, API를 `q`로 직접 부르면 400(`required`)
- 나중에 서비스로 분리할 때: 검색 서비스의 공개 파라미터가 그대로 됨. 캐시 키는 ADR-0009대로 필드를 포함
