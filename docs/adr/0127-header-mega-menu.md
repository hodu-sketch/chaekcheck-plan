# ADR-0127: 머리말은 도서관 정보나루식 큰 메뉴: 「도서검색」(전자책 검색)·「추천도서」(이동진 추천도서·사서 추천도서·서울대 100선)·「마이페이지」(내 도서관 관리), PC는 올림 0.5초나 누르면 펼침(덮지 않음), 폰은 머리말 줄을 누르면 펼침

Status: Accepted (사용자 승인, 2026-10-16, 설계 정리 페이지)
Date: 2026-10-16
Cycle: 21-recommended-books
Supersedes: 없음

## 배경
머리말 링크 「사서추천도서」 하나로는 추천 목록 셋을 보일 수 없었다. 사이클 20이 머리말에 조회 상태 점을 더하고, 머리말은 모든 화면에서 같게 하기로 했다(ADR-0121).

## 결정
- 큰 메뉴 둘: 「추천도서」·「마이페이지」. 책 검색은 「책첵」 로고. 「사서추천도서」 링크와 「알림·안내」 큰 메뉴는 없음(알림·안내는 backlog)
- PC: 마우스를 0.5초 멈추면 모든 칸이 함께 펼쳐지고 나간 뒤 0.5초에 닫힘, 아래 화면은 덮지 않고 그림자·선, 큰 메뉴 글자를 누르면 첫 항목, 키보드 Tab·Enter·↓·Esc. 칸은 각 큰 메뉴 아래에 맞춰 정렬(개발 때 실제 사이트 보고 맞춤)
- 폭 640px 이하: ☰로 위에서 펼치고 아래를 어둡게 덮음, 바깥을 누르면 닫힘. 조회 상태 점은 「로그인」 바로 왼쪽(폰은 ☰ 왼쪽)

## 이유 (사용자 발언)
- "현재의 사서추천도서를 추천도서로 바꾸고 마우스를 추천도서에 올리거나 클릭하면 아래 탭이 나오고" (2026-10-15)
- "아니아니 나는 추천도서 탭만 아니라 전체 탭이 아래로 늘어나는 걸 생각해 도서관 정보나루처럼" (2026-10-15)
- "아 너무 많이 보여주는데? 내 도서관은 그렇다쳐도 알림/안내는 아직 아니지 않나?", "흠 내 도서관을 마이페이지로 하고 내 도서관 관리가 아래에 있게 해줘" (2026-10-15)
- "그래서 PC는 그림자·선만, 폰 ☰ 메뉴만 어둡게 덮기로 해줘" (2026-10-15), 폰 A(☰)·화면 결정 #1·#2·#3 제안 → 승인 (2026-10-15)
- #2 메모 "그 pc버전 정렬은 이 예시처럼이면 안 돼.. 개발할 때 조심해.. 다른 사이트 보면서 파악하고" (2026-10-15)

## 검토한 대안
### A안: 정보나루식 큰 메뉴 (채택)
- 장점: 목록 셋과 마이페이지를 한 번에 보임. 단점: 머리말 코드가 커짐
### B안: 「추천도서」만 아래로 펼침
- 채택하지 않은 이유: 사용자 "추천도서 탭만 아니라 전체 탭이 아래로 늘어나는 걸 생각해" (2026-10-15)
### C안: 폰은 탭 줄·아래 탭바·글자 하나
- 채택하지 않은 이유: [이유 미확인] (사용자는 ☰(A) 승인)

## 결과
- 바뀜 (2026-10-16~17, 사용자가 dev 21 화면을 보며 직접 정함, dev `docs/plan-feedback.md` "# 사이클 21" 9단계 "머리말 메뉴 (최종)"·"plan 20 결과 검토" #7·#9; 이 기록 방식은 [확정] (사용자 승인, 2026-10-17, 회고 결정 #1)):
  - 큰 메뉴 셋: 「도서검색」(전자책 검색 `/search`)·「추천도서」(이동진 추천도서·사서 추천도서·서울대 100선)·「마이페이지」(내 도서관 관리). 「도서검색」은 `/`·`/search`·`/books/*`에서 밑줄 (dev `web/src/components/headerMenus.ts`). 사용자: "폰이랑 pc랑 둘 다 탭에 도서검색 넣어줘" (2026-10-16)
  - PC: 큰 메뉴를 누르면 화면을 옮기지 않고 세 칸이 모두 열림, 같은 탭을 다시 누르면 닫힘, 다른 탭은 열린 채. 0.5초 올리기·Esc·바깥 누르기·항목 누르기는 그대로. 위 결정의 "큰 메뉴 글자를 누르면 첫 항목"을 바꿈. 사용자: "pc 탭 말이야 누르면 아래 항목 보이도록", "나는 다 보였으면" (2026-10-16)
  - 폰(640px 이하): ☰ 없음. 머리말 줄 빈 곳을 누르면 메뉴가 펼쳐지고 아래가 어두워짐, 다시 누르면 닫힘. 「로그인」 왼쪽에 작은 ▾(분류 버튼과 같은 `ChevronDown`)가 있어 줄이 메뉴를 연다는 것을 보임(누르면 줄을 누른 것과 같음). 조회 상태 점은 「로그인」 바로 왼쪽(▾ · 점 · 「로그인」 차례, dev `AppLayout.tsx`), 점·「로그인」을 눌러도 메뉴는 열리지 않음(사이클 21 dev 결과 검토 #9, `from-cycle-20-header-light.md`). 사용자: "상단 탭 자체를 누르면 메뉴 보이는 걸로" (2026-10-16), ▾는 결과 검토 #7에서 안 B(로그인 왼쪽) 고름 (2026-10-17)
  - 로고(PC·폰): 메인(`/`)으로만 감, 메뉴를 열지도 닫지도 않음. 사용자: "실사용 해보니 좌상단 로고는 아래 탭 늘려서 보이는 거랑 관계 없이 그냥 메인으로 옮겨주는 걸로만 해" (2026-10-16)
  - 간격(1280px): 로고 → 첫 탭 92px, 탭 글자 사이 64px. 사용자: "책첵이랑 (도서검색, 추천도서, 마이페이지) 이것 사이의 간격은 더 띄워주고 … 요 세 요소들 사이의 간격은 좀 더 줄여줘" (2026-10-17)
