# ADR-0163: 모든 표지 그림은 S3(시드니) + CloudFront 기본 주소에 두고, PC만 올림

Status: Accepted
Date: 2026-10-28
Cycle: 26-book-descriptions
Supersedes: 없음 (ADR-0091의 "사서추천 표지를 `picks.cover`에 저장", ADR-0148의 운영 서버 `/srv/chaekcheck/covers/` 표지 자리를 이 결정이 바꿈)

## 배경
책 상세에 표지를 보이려면 책 134만 권의 표지(장당 약 9~11KB, 합 약 12~15GB [추론])가 필요한데 운영 디스크 여유는 약 11GB. 계정은 AWS 무료 플랜(크레딧). 사서추천 표지만 DB 안 그림(bytea)으로 저장되어 있음.

## 결정
- 판 표지와 추천목록 그림을 비공개 S3 버킷(`covers/<sha1>.jpg`)에 두고, CloudFront 기본 도메인(`<id>.cloudfront.net`)으로 OAC를 거쳐 보낸다. CSP `img-src`에 그 주소를 더한다. DB에는 그림 이름(sha1)만 두고 주소는 설정으로 만든다
- PC만 S3에 올린다(그 버킷 올리기만 되는 IAM 사용자 키). 운영 서버에는 S3 권한을 주지 않는다. "그림 먼저, 연결 나중"
- `picks.cover`의 그림은 파일로 꺼내 함께 올리고 표는 지운다

## 이유 (사용자 발언)
- "디스크는 뭐 따로 S3이라던가 프리티어에서 할 수 있는 거 생각해보자 아니면 라이트세일로옮긴다던가" (2026-10-28)
- "무료 크레딧에서 되는 것들인지 확인하고 그것들만 알려줘" (2026-10-28)
- "S3 + CloudFront 이걸로 하자" (2026-10-28)
- "나는 DB에 이미지를 넣는게 이해가 안 가거든" (2026-10-28)
- 기본 도메인·PC만 올림: [이유 미확인] (설계 결정 #3·#4 승인)

## 검토한 대안
### A안: S3 + CloudFront (채택)
- 근거: S3는 무료 플랜 두 플랜 모두 사용, CloudFront 늘 무료 1TB/월(https://aws.amazon.com/free/, https://aws.amazon.com/free/networking/, 2026-10-28). 시드니 S3 $0.025/GB-월, PUT $0.0055/1,000건(AWS 가격 데이터, 2026-10-28). 저장 월 약 $0.38, 첫 올리기 약 $7.4 [추론]
### B안: 운영 디스크(EBS) 30 → 50GB
- 단점: 무료 플랜에서 30GB 넘게 늘릴 수 있는지 문서에 없음, 월 약 $1.92
- 채택하지 않은 이유: [이유 미확인] (사용자가 S3를 고름)
### C안: 라이트세일로 이사 ($12/월, SSD 60GB)
- 채택하지 않은 이유: [이유 미확인]
### D안: Cloudflare R2
- 채택하지 않은 이유: [이유 미확인]
### E안: WebP로 줄여 지금 디스크에
- 채택하지 않은 이유: [이유 미확인]
### 주소: 그림 전용 하위 도메인 / nginx가 S3로 넘김
- 채택하지 않은 이유: [이유 미확인]
### 올리기: PC + 운영 서버(EC2 역할)
- 채택하지 않은 이유: [이유 미확인] (운영 사서추천 받기가 꺼져 있음, `deploy/prod/compose.yaml:67`)

## 결과
- 좋아지는 점: 운영 디스크를 쓰지 않음, DB 안 그림이 없어짐
- 감수하는 점: S3·CloudFront·IAM 키 관리, CSP 변경. 무료 플랜이 끝나기 전(약 2027-04) 유료 플랜으로 올려야 함(방법과 무관)
