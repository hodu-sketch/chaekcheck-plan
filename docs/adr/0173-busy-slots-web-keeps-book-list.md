# ADR-0173: 동시 검색 자리가 없을 때 서버는 503 그대로, 화면이 책 목록을 지킴

Status: Accepted
Date: 2026-11-07
Cycle: 28-busy-keeps-book-list
Supersedes: 없음

## 배경
동시 검색 자리(`SearchSlots`, `max-concurrent-searches` 60)가 다 차면 대출 조회 스트림(`GET /api/v1/book-availabilities/stream`)은 열리기 전에 503 `server_busy`(`Retry-After: 5`)로 거절된다. 「바로 보기」 화면은 책 목록(`GET /api/v1/books`, DB 조회라 자리를 쓰지 않음, ADR-0030)을 이미 받았는데도 결과 자리를 안내문 한 줄로 바꿔 책 목록을 버렸다(dev `InstantResults.tsx` 131~141행, 2026-11-01 확인). 사용자는 "넘으면 바로 503이 아니라 그냥 대출 결과만 제외하고 알려주려고 … 그냥 목록만… 대출 정보는 알 수 없다고만 하고"(2026-11-01)를 요청했고, 아주 작은 번외 사이클로 하기로 했다. 「결과 더 보기」(다음 묶음)의 거절은 지금도 받은 결과가 남고 다시 물을 수 있어 문제는 첫 조회 한 곳뿐이다.

## 결정
서버·API·스트림 이벤트·오류 코드는 바꾸지 않는다. 「바로 보기」 첫 대출 조회가 503 `server_busy`를 받으면 화면이 이미 받은 책 목록을 책 줄(제목·저자·출판사·연도·보유 도서관 N곳, 누르면 책 화면)로 그리고, 위에 안내 줄 "지금 찾는 사람이 많아 대출 정보는 알 수 없어요. 책 목록만 먼저 보여 드려요."와 「대출 정보 다시 확인」 단추(누를 때만 같은 책들로 다시 조회, 자동 재시도 없음)를 둔다. 책 화면도 같은 안내 줄·단추를 보이고 잘못된 "이 책을 가진 도서관을 모두 조회했습니다"를 숨긴다. 429, 「결과 더 보기」 거절, 추천도서 책 창, 직접 찾기, 거절 세는 법(요약 로그 거절 수·상태 신호 빨강 10초)은 그대로다.

## 이유 (사용자 발언)
- [이유 미확인] — 결정 페이지(`docs/cycles/28-busy-keeps-book-list/easy/2026-11-01-decisions.html`) 10개 모두 말 없이 승인 (2026-11-07). 아키텍트 추천 근거: 문제가 첫 조회 한 곳뿐이고 책 목록은 화면이 이미 들고 있음, 개인 서비스 한 서버 자리 60개라 거절은 드물고 짧음, 사용자가 "아주 간단하게"를 요청함

## 검토한 대안
### 다안: 화면만 고침, 서버 503 그대로 (채택)
- 장점: API 변경 없음, 화면 3~4 파일, 서버 테스트 변화 없음, 블루·그린 전환(ADR-0170) 때 옛·새 판이 섞여도 문제없음
- 단점: 첫 조회 거절 때 도서관별 줄·도서관 책 페이지 링크는 안 보이고 책 줄만 보임
### 가안: 스트림을 열고 이번 묶음 소장마다 `holding-failed`(code `server_busy`) + `stopReason SERVER_BUSY`
- 장점: 도서관별 줄과 링크가 보임
- 단점: 서버 4~5 + 화면 4~5 파일, 사이클 08 AC-18 통합 테스트 기대값 변경, `server_busy`가 HTTP 오류 코드와 스트림 안 실패 코드 두 뜻을 가짐, 옛 화면은 10줄을 "확인하지 못했어요"로 보이고 다시 못 물음
- 채택하지 않은 이유: [이유 미확인] (다안 승인)
### 나안: 스트림을 열고 새 이벤트 `lookups-unavailable` 한 번
- 장점: 소장 상태를 건드리지 않아 「결과 더 보기」가 그대로 다시 물음
- 단점: 스트림 약속이 하나 늘지만 화면이 그릴 수 있는 것은 다안과 같음(`targets`에 `detailUrl` 없음)
- 채택하지 않은 이유: [이유 미확인] (다안 승인)

## 결과
- 좋아지는 점: 바쁜 순간에도 어떤 책이 몇 곳에 있는지 바로 보임. 서버 재배포 없이 화면 판만 올리면 됨
- 감수하는 점: 첫 조회 거절 때 도서관별 줄·링크 없음. 필요해지면 가안으로(`docs/backlog.md`)
- 나중에 되돌리거나 서비스로 분리할 때의 비용: 화면 파일만 되돌리면 됨. 가안으로 갈 때는 이 ADR을 대체하는 ADR과 `api.md` 스트림 행·오류 코드 표 갱신
