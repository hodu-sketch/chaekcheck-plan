# ADR-0035: 같은 책 묶기 ④(정리한 전체 제목·저자·출판사)와 책 번호 체계 공유 범위

Status: Accepted
Date: 2026-09-30
Cycle: 04-and-search
Supersedes: 없음

## 배경

사이클 04 인계서는 같은 책 묶기를 ① 같은 플랫폼 코드 → ② 교보식 코드 ISBN → ③ 국가서지 ISBN까지만 하고, "정리한 글자만으로 묶는 4단계는 이번에 하지 않음"[안]으로 넘겼습니다. 개발 중 dry run에서 「작별하지 않는다」(한강, 문학동네) 서비스 소장 98줄이 ①~③ 뒤에도 4권(교보 ISBN 74줄, YES24 번호 22줄, 강남구 1줄, YES24 다른 번호 1줄)으로 남았습니다. 국가서지에 판이 여럿이라 ③으로도 못 합쳤습니다. 또 ①에서 "어느 화면 종류끼리 같은 번호를 같은 책으로 볼지"가 [확인 필요: 데이터 대조]였습니다. 이 결정은 2026-09-30 개발 중에 내려졌고 2026-10-01에 늦게 기록합니다 (dev `docs/plan-feedback.md` `# 사이클 04` 절). 규칙과 수치는 `docs/research/ebook-catalog/same-book-isbn.md` 5절에 있습니다.

## 결정

1. ①~③ 뒤에 ④를 더한다: 정리한 **전체 제목**(괄호 속 판 표시 포함) + 대표 저자(첫 지은이·역할 모름의 `name_exact`) + 정리한 출판사가 같으면 한 권. 저자나 출판사가 없으면 합치지 않는다.
2. ①의 번호 체계: 교보·교보 구독형·YES24 V1/V2/V3는 한 번호 체계로 묶고, 통합 포털 `book_idx`와 강남구 `book_num`은 그 도서관 안에서만 묶는다. 이 기준은 도서관 목록을 확인할 때마다 같이 점검한다 (dev `docs/library-maintenance.md` 4-11, `scripts/library/check_code_spaces.py`).

## 이유 (사용자 발언)

- ④: "전체 제목+저자+출판사까지 같으면 합침 (추천) 이걸로 해줘" (2026-09-30). 그 전에 사용자가 물은 것: "판마다 전자책 내용이 달라질 수 있지 않아?"
- 번호 체계 점검: "코드 규칙은 언제든지 달라질 수 있으니 도서관 목록 확인할 때 같이 점검하는 걸로 하면 좋을거 같아 그리고 나중에 반영하고" (2026-09-30)
- 번호 체계를 나눈 기준 자체는 dev의 데이터 대조 결과(교보↔YES24 등 같은 번호의 제목 일치 99% 안팎, 포털은 100% 불일치)를 사용자가 받아들인 것. 기준 선택 이유 [이유 미확인]

## 검토한 대안

### A안: ④ 전체 제목 + 저자 + 출판사 (채택)
- 장점: 같은 작품이 교보·YES24 번호가 달라 여러 권으로 나뉘는 것을 합침(dry run 784,994 → 648,267권). 판 표시가 제목에 있으면 따로 남음
- 단점: 판 표시가 없는 개정판은 원판과 합쳐짐. 합친 책 중 대표 출판일이 2년 넘게 차이 나는 11,019권은 판 차이인지 [확인 필요]

### B안: ①~③만 (인계서 원안)
- 장점: 잘못 합칠 위험 없음
- 단점: 같은 작품이 플랫폼별로 따로 나옴
- 채택하지 않은 이유: [이유 미확인] (사용자는 A안을 골랐음)

### C안: ④를 본제목으로 (research 5절 초기 [안] 문안)
- 장점: 부제·판 표시가 달라도 합침
- 단점: 부제만 다른 해설서·요약본, 개정판이 모두 합쳐짐
- 채택하지 않은 이유: [이유 미확인] (사용자에게 제시된 선택지가 "전체 제목"이었음)

### 번호 체계 D안: 모든 화면 종류를 한 체계로
- 채택하지 않은 이유: 포털 `book_idx` 32,449개가 도서관마다 다른 책이라 데이터가 맞지 않음 (dev 대조, 2026-09-30)

### 번호 체계 E안: 모두 도서관 안에서만
- 채택하지 않은 이유: 교보↔YES24 등 같은 번호의 제목 일치가 99% 안팎이라 나눌 이유가 없음 (dev 대조). 사용자 발언 없음 [이유 미확인]

## 결과

- 좋아지는 점: 검색 결과에서 같은 작품이 한 줄로 모임. 번호 체계 점검이 도서관 목록 점검의 일부가 되어 규칙이 조용히 어긋나지 않음
- 감수하는 점: 판 표시 없는 개정판이 합쳐짐(알려진 한계). 점검 비율이 얼마나 바뀌면 기준을 바꿀지는 미정(그때 사용자에게 질문)
- 되돌릴 때의 비용: 원문이 보존되므로 ④를 끄고 다시 가져오면 됨(`TRUNCATE` 뒤 COPY). 책 번호(`/books/{bookId}`)는 바뀜 — 주기 갱신 사이클의 번호 유지 장치(`docs/research/ebook-catalog/catalog-refresh.md` 5.1)와 함께 봐야 함
