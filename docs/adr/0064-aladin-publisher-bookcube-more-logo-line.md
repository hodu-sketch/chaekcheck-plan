# ADR-0064: 알라딘 출판사 검색을 쓰고, 북큐브 직접 찾기에 "더 보기"를 두고, 로고는 이름 위 줄에 두며 없으면 그리지 않는다

Status: Accepted
Date: 2026-10-05
Cycle: 07-candidate-libraries
Supersedes: 없음 (ADR-0056·ADR-0059 일부를 바꿈)

## 배경
ADR-0056은 알라딘 "도서관에서 직접 찾기"의 출판사 검색을 그 도서관 실패로, 북큐브 직접 찾기를 첫 쪽만으로 정했다(쪽 넘기기를 시험하기 전). ADR-0059는 로고를 이름 앞에 두고 없으면 빈 상자를 그리기로 했다. 사이클 07 개발 중 dev가 사이트를 시험해 알라딘 `search_item=publisher`와 북큐브 쪽 넘기기(`itemCount`·`page`)가 되는 것을 확인했고, 사용자가 실제 화면을 보고 세 가지를 바꿨다(dev `docs/plan-feedback.md` 7단계, 16단계). 확정된 ADR은 고칠 수 없어 새 기록으로 남긴다.

## 결정
- 알라딘 직접 찾기의 출판사 검색을 쓴다.
- 북큐브 직접 찾기는 다른 사이트처럼 "더 보기"(한 쪽 10권)를 둔다.
- 로고는 도서관 이름 위 줄에 두고, 로고가 없으면 아무것도 그리지 않는다(빈 상자 없음). 로고가 없는 도서관은 카드의 "홈페이지 (새 창)" 링크로 간다.
- ADR-0056·0059의 나머지(북큐브·알라딘을 상세 페이지로 읽음, 북큐브 대여형 판정, 자체 로고만, 누르면 메인 페이지, DB 값으로 바로 내림 등)는 그대로다.

## 이유 (사용자 발언)
- 알라딘 출판사: "출판사 검색도 씀" (2026-10-05, dev 기록)
- 북큐브 더 보기: 사용자 결정, 원문 없음 [이유 미확인]
- 로고 자리: "실제로 확인해보고 디자인 측면의 안정감때문에" (2026-10-05, 사이클 07 회고 질문 #3)
- 기록: 사이클 07 회고 결정 기록 초안 승인 (2026-10-05)
