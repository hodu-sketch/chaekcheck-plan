# ADR-0072: 인기 도서 출처는 출판유통통합전산망 공개 통계 화면

Status: Superseded by 0089
Date: 2026-10-11
Cycle: 10-popular-books
Supersedes: 없음

## 배경
분야별 인기 도서를 보여 주려면 바깥 순위 데이터가 필요했다. 알라딘 OpenAPI는 2026-09-04에 신규 키 발급이 끝났고 2026-10-30에 기존 이용자까지 종료된다(https://blog.aladin.co.kr/openapi/17486624, 2026-10-11 확인). 도서관 정보나루는 인기 "대출" 목록이다. 출판유통통합전산망은 교보문고·예스24·알라딘·영풍문고·지역서점 종이책 판매를 합친 분야별 월간 Top50을 로그인 없이 보여 주고, 우리 서버가 화면과 같은 조회(쿠키 + 보안 토큰)로 받을 수 있음을 시험했다(2026-10-11, `docs/research/popular-books/kpipa.md`).

## 결정
- 인기 도서는 출판유통통합전산망 "주제분류별 판매량 순위"(1단계 21분류 + 전체, 지난달 Top50)와 "주제분류별 판매량 통계"(분류 순서용 판매 부수)를 매달 한 번 우리 서버가 받아 쓴다
- 회원 전용 Open API는 쓰지 않는다
- 화면 게시 허락은 공개 전까지 이용 문의(kbookdata@kpipa.or.kr)로 받는다

## 이유 (사용자 발언)
- "나는 알라딘/정보나루 안 할 거야 출판유통통합전산망 이걸로 해줘" (2026-10-11)
- "인기 도서 목록이 전자책에서 많이 비어도 괜찮아 10%만 있어도 충분해 전자도서관 사이트에서 신청을 하라고만 하면 되니까" (2026-10-11)

## 검토한 대안
### A안: 출판유통통합전산망 공개 통계 화면 (채택)
- 장점: 서점 다섯 곳 합산 판매 순위, 로그인·키 없음, 분류별 판매 부수도 있음
- 단점: 공개 API가 아니라 화면 조회, 종이책 순위
### B안: 알라딘 OpenAPI
- 단점: 2026-10-30 종료
- 채택하지 않은 이유: "나는 알라딘/정보나루 안 할 거야" (2026-10-11)
### C안: 도서관 정보나루 인기대출도서
- 채택하지 않은 이유: "나는 알라딘/정보나루 안 할 거야" (2026-10-11)

## 결과
- 좋아지는 점: 판매 기준 분야별 순위를 키 없이 받음
- 감수하는 점: 사이트 화면이 바뀌면 받기가 멈춤(그달은 저장하지 않고 앞 달을 보임), 게시 조건 미확인(문의 중), 종이책 ISBN으로 맞춰 2026년 9월 기준 27.8%만 우리 전자책과 맞음
- 나중에 되돌릴 때: 받기 코드(`popular` 안쪽)만 바꾸면 됨
