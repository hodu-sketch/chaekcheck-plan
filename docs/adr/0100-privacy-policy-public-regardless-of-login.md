# ADR-0100: 개인정보 처리방침은 로그인 기능과 상관없이 공개한다 (사이클 05 제약 35 일부 변경)

Status: Accepted (사용자: "회고 15 플랜 세션이 주면 그거 반영해서 /cycle-close하고 dev가 할 수 있게 해줘", 2026-10-14 — 설계 확정, dev main 대조 뒤)
Date: 2026-10-13
Cycle: 16-notices-and-policies
Supersedes: 없음

## 배경
사이클 05에서 로그인 기능이 꺼지면 `/terms`, `/privacy`와 바닥글 링크를 숨기기로 했다(제약 35). 그런데 로그인이 꺼져도 사이클 15의 이용 기록과 nginx 접속 기록에 IP가 남는다(`docs/cycles/16-notices-and-policies/privacy-inputs.md`).

## 결정
`/privacy`와 바닥글의 처리방침 링크는 로그인 기능과 상관없이 늘 보인다. 이용약관(`/terms`)과 그 링크는 지금처럼 로그인 기능이 꺼져 있으면 보이지 않는다.

## 근거
- 개인정보 처리방침 작성지침(2026.4. 개정) 17쪽: "로그인 여부와 상관없이" 확인할 수 있어야 하고 첫 화면에서 바로 찾을 수 있어야 함
- 개인정보 보호법 제30조②, 시행령 제31조②: 홈페이지에 지속적으로 게재
- 출처와 확인일: `docs/cycles/16-notices-and-policies/research.md` 2.2·2.3·5절 (2026-10-12·13)

## 이유 (사용자 발언)
- 처음 사용자 질문: "로그인 방침에 따라서 다르게 보여야 하는 거 아니야?" (2026-10-12) → 지침 확인 뒤 제안 → 승인 (2026-10-12) [이유 미확인]

## 검토한 대안
### A안: 처리방침만 늘 공개 (채택)
- 장점: 지침과 맞음
- 단점: 로그인이 꺼진 때도 처리방침 화면을 유지해야 함
### B안: 둘 다 로그인 기능을 따름 (사이클 05 그대로)
- 단점: 처리방침을 찾을 수 없는 때가 생김
- 채택하지 않은 이유: [이유 미확인] (제안 근거는 지침과 맞지 않음)
