# ADR-0104: 첫 배포 호스트는 AWS EC2 t4g.medium(4GB·서울), 무료 크레딧으로 최대 6개월 운영, 비밀 값은 IAM 역할로 접근 키 없이

Status: Proposed
Date: 2026-10-14
Cycle: 17-first-deploy
Supersedes: 없음

## 배경
사이클 17은 서비스를 AWS 서울 4GB 서버 한 대에 처음 공개 운영한다(ADR-0103 서버 구성). 호스트를 Lightsail로 잡아 두었으나, 배포 준비 중 두 사실이 드러났다. ① AWS 신규 계정(2025-07-15 이후)은 무료 크레딧 $100(최대 $200)과 무료 플랜 6개월을 받는다. ② Lightsail 무료는 "90일 평가판"이고 대상 번들이 최대 2GB라, 우리 4GB 설계엔 작다(`research.md` 12절, 공식 페이지 2026-10-14 확인). 크레딧은 EC2에 쓸 수 있음이 공식으로 확인되고(EC2 사용이 크레딧 적립 활동), EC2는 Lightsail과 달리 서버에 IAM 역할을 붙일 수 있다. 처음 계획한 "2주 뒤 노트북 이전"도 크레딧을 최대로 쓰는 쪽으로 사용자가 바꿨다.

## 결정
- 첫 배포 호스트를 **AWS EC2 t4g.medium(램 4GB·서울 ap-northeast-2·Arm)** 로 하고, 서비스·조회 서버·PostgreSQL+pg_bigm·모니터링을 ADR-0103 구성 그대로 Docker로 올린다.
- **무료 크레딧으로 결제**하며, 무료 플랜 6개월 또는 크레딧 소진 중 먼저까지 운영한다. 집 노트북 이전은 나중에(그 무렵) 재검토한다.
- **비밀 값은 EC2 인스턴스에 붙인 IAM 역할로 읽는다**(Parameter Store `/chaekcheck/prod/`). 접근 키 한 쌍을 두지 않는다 → ADR-0103의 "Lightsail엔 역할이 없어 접근 키를 둔다" 전제를 이 호스트에서 대체한다. `up.sh`가 역할 자격으로 Parameter Store를 읽어 `chmod 600` env 파일로 쓰는 흐름은 그대로.

## 이유 (사용자 발언)
- 기간·크레딧: "무료로 200달러 크레딧 최대로 뽑아먹고 노트북 이전은 나중에 생각해볼래" (2026-10-14)
- 호스트 EC2 4GB·비밀 값 IAM 역할: 제안 → 승인 (2026-10-14, `easy/2026-10-14-deploy-host-decisions.html` #1·#3, 캔버스)

## 검토한 대안
### A안: EC2 t4g.medium 4GB + IAM 역할 (채택)
- 장점: 크레딧 사용 확실, 4GB로 설계 그대로, 접근 키가 없어 비밀 값 관리가 단순·안전, 6개월을 $200 안에서 채움($24×6=$144)
- 단점: Lightsail보다 세팅 손이 조금 더 감(보안그룹·EIP 등), EC2 요금이 Lightsail 고정요금보다 변동적
### B안: Lightsail 4GB (크레딧 결제)
- 채택하지 않은 이유: [이유 미확인] (A안을 승인. 제안 때 근거: 무료 평가판 대상이 2GB까지라 4GB는 크레딧 결제가 필요하고 크레딧 대상인지 미확인, IAM 역할이 없어 접근 키를 둬야 함)
### C안: Lightsail 2GB 무료 평가판
- 채택하지 않은 이유: [이유 미확인] (A안을 승인. 제안 때 근거: 2GB엔 모니터링 묶음을 빼야 들어가 설계 축소)

## 결과
- 좋아지는 점: ADR-0103 설계를 그대로 쓰면서 비밀 값 접근 키가 사라짐, 6개월 체험이 사실상 무료, 4GB로 모니터링까지 올림
- 감수하는 점: 부산처럼 AWS IP를 막는 `go.kr`은 운영 기간 내내 막힌 채(집 가정용 IP로 옮겨야 풀림, `research.md` 12절), EC2 세팅이 Lightsail보다 한 겹 더, Lightsail이 크레딧 대상인지 콘솔 확인은 참고로 남김
- 나중에 노트북·서비스로 옮길 때: 같은 compose·env 파일을 그대로 씀. 노트북엔 IAM 역할이 없어 env 파일을 손으로 두는 ADR-0103 경로를 사용

## 관련
- ADR-0103(운영 서버 구성)의 비밀 값 전달을 이 호스트에서 IAM 역할로 바꿈. ADR-0095(나가는 길)·ADR-0094(교보)는 그대로
