# ADR-0026: 포털 저자·출판사 검색은 검색어 + 정확히 일치하는 거르기

Status: Accepted
Date: 2026-09-29
Cycle: 03-search-conditions
Supersedes: 없음

## 배경
사이클 03은 저자·출판사로도 검색한다(ADR-0025). 통합 전자도서관 포털(`ELIB_PORTAL_V1`, 7곳)에는 저자·출판사 전용 검색이 없다. 2026-09-29 7곳 호출 시험 결과는 다음과 같다(spec 3장 "포털 재조사").
- `search_type`의 AUTHOR/TITLE/PUBLER는 필드가 아니라 자료 종류다(부산 화면 "소장자료/구독자료/학술원문"). 부산·경북·인천·전북·강원은 무시하고, 경기교육청은 0건을 돌려준다.
- 기본 검색(`search_text`)은 제목·저자·출판사를 모두 찾는다.
- `table.do`의 `author_name`·`book_pubname`은 검색어(`search_text`)와 함께 줄 때만 동작하고, 값이 정확히 같은 저자·출판사만 남긴다(부산 "김달" 11→3, 대구 14→3, 경기교육청 18→7). 쪽 넘김이 된다(전북).

## 결정
- 포털의 저자 검색은 1쪽부터 `table.do?search_text={q}&author_name={q}`, 출판사 검색은 `table.do?search_text={q}&book_pubname={q}`로 부른다.
- `search_type`에는 필드 값을 넣지 않는다(지금처럼 빈 값).
- 제목 검색은 지금처럼 기본 검색이다(1쪽 `index.do`, 2쪽부터 `table.do`).

## 이유 (사용자 발언)
- "검색어 + 걸러내기, 이름 정확히 일치" — 선택지 중 사용자 선택 (2026-09-29). 사용자 발언으로 된 이유는 [이유 미확인]

## 검토한 대안
### A안: 검색어 + 정확히 일치하는 거르기 (채택)
- 장점: 그 저자·출판사의 책만 나옴
- 단점: 부분 일치인 다른 사이트와 결과 범위가 다름. 표기가 다른 책("김달 저", 공저)이 빠질 수 있음
### B안: 기본 검색 그대로
- 장점: 빠지는 책이 없음
- 단점: 제목·출판사에 검색어가 든 책이 섞임
- 채택하지 않은 이유: [이유 미확인]
### C안: 포털을 저자·출판사 검색에서 빼기
- 장점: 포털만 다르게 동작하는 일이 없음
- 단점: 포털 7곳의 책을 저자·출판사로 찾을 수 없음. 어떻게 알릴지 따로 정해야 함
- 채택하지 않은 이유: [이유 미확인]

## 결과
- 좋아지는 점: 포털 저자·출판사 검색 결과에 관계없는 책이 섞이지 않음
- 감수하는 점: 포털만 정확히 일치라 "김달"로 김달국·김달우가 나오지 않음. 표기가 다른 책이 빠질 수 있음(얼마나 빠지는지는 개발 때 확인). `table.do`에서 목록 판정 칸이 비는 포털(부산·대구·경기교육청)은 저자·출판사 검색 1쪽부터 상세 판정 요청이 늘 수 있음
- 사이트가 바뀌면 이 방식도 바뀔 수 있음. 새 포털 화면이 나오면 ADR-0023 규칙대로 새 화면 종류로 다룸
