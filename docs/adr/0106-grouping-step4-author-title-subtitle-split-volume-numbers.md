# ADR-0106: 네 번째 묶기 단계 보완 — 본제목이 저자 이름이면 전체 제목, 부제는 같은 도서관이 따로 가질 때만 나눔, 권 숫자는 권·판처럼 보이는 것만

Status: Accepted
Date: 2026-10-14
Cycle: 12-grouping-rules
Supersedes: 없음 (ADR-0082를 보완. ADR-0082의 "권 표시 = 전체 제목의 숫자 목록"과 "로마·한자 숫자는 dev 표본 뒤 결정"을 아래로 정함)

## 배경
ADR-0082 규칙으로 실데이터 dry run·반영을 하며 세 가지를 찾았다(dev `docs/plan-feedback.md` "# 사이클 12"). (1) 부제 안 숫자("10가지 성공 법칙")로 같은 책 19,334그룹이 갈림, 로마 숫자 권 표시로 58권이 잘못 합쳐짐. (2) 「김동인 - 감자」처럼 본제목이 작가 이름이라 168권이 서로 다른 작품 2,776권을 흡수. (3) 부제가 서로 다른 옛 책이 한 권이 된 경우 5,721권 — 한 도서관이 부제 다른 두 책을 따로 가진 2,576권은 대부분 다른 책, 나머지는 대부분 같은 책. 부제마다 나누는 안(`f240d34`)은 「수면의 뇌과학」 같은 같은 책을 여러 줄로 갈라 되돌림. 규칙은 2026-10-12~14 dev 세션에서 사용자와 정했고, 2026-10-14 회고에서 ADR로 기록했다.

## 결정
- 원칙: 보이는 표시가 다른 권·다른 판을 가리키면 나누고, 같은 책을 설명만 다르게 붙인 것은 합친다. 확실하지 않으면 합치지 않는다
- 권 표시 숫자: 본제목과 짧은 부제 조각(공백 빼고 8자 이하)은 모든 숫자, 긴 조각은 권·판처럼 보이는 숫자(권 낱말 앞뒤, 연도)만. 로마 숫자(I~XX, Ⅰ~Ⅻ)와 한자 숫자(一~十·百)는 권 자리에서 숫자로 셈
- 비교 제목: 숫자 앞의 0을 뗌. 본제목이 첫 저자 이름과 같으면 전체 제목(앞 시리즈 표시만 뗌)으로 비교
- 꼬리 목록: `(PC만 열람 가능)`, `(스마트 패드 전용)`, `(잠 못 이루는 밤을 위해)`, `(한국인이 가장 좋아하는 단편소설)`
- 같은 키에 부제가 둘 이상이면(`SubtitleParts`, 세 방식이 같은 함수): 포함 관계면 같은 부제, 서로 다른 부제를 같은 도서관이 따로 가질 때만 나눔, 부제 없는 묶음은 나뉜 묶음이 둘 이상이면 따로
- 판 표시·ISBN 없는 다른 판을 나누는 규칙은 넣지 않음 (ADR-0082 "감수하는 점" 그대로)
- 지금 규칙의 원본은 `docs/research/ebook-catalog/same-book-isbn.md` 5.7절

## 이유 (사용자 발언)
- 원칙: "현재까지 합치기 규칙을 총합했을 때 일관성 있는 방향" (2026-10-12, 사용자와 정리)
- 숫자: "권·판처럼 보이는 숫자만 셈 (Recommended)", 처음 안에 "너무 합쳐지는 거 아니야?" (2026-10-12)
- 로마 숫자: "셈 (Recommended)", 한자 숫자: "그냥 노출되는게 다르면 다른 책으로 해줘" (2026-10-12)
- 꼬리: "이용 안내 (Recommended)", "넣음 (Recommended)" (2026-10-12)

- 숫자 앞의 0을 비교 제목에서도 뗀 것은 dev가 정함 [이유 미확인]

## 검토한 대안
### A안: 위 결정 (채택)
- 장점: 같은 책이 한 줄로, 다른 권·다른 작품은 따로
- 단점: 부제 나누기가 도서관 목록에 달림
### B안: 부제 숫자는 짧은 부제만 셈
- 단점: 「… VOL. 1 / VOL. 2」 같은 다른 권이 합쳐짐
- 채택하지 않은 이유: "너무 합쳐지는 거 아니야?" (2026-10-12)
### C안: 긴 부제 끝 숫자도 셈 / 짧은 부제 글자 수에서 앞의 0 뺌
- 단점: 같은 책이 7,533권·485권 갈림(dry run 3·4)
- 채택하지 않은 이유: [이유 미확인] (dev가 되돌림)
### D안: 서로 다른 부제마다 나눔 (`f240d34`)
- 단점: 같은 책이 부제 표기만 달라 여러 줄(약 3,100권)
- 채택하지 않은 이유: "반영 보류, plan에서 더 나은 규칙 설계 (Recommended)" (2026-10-13)
### E안: 다른 판을 출판일 차이로 나눔
- 단점: 같은 상품 코드·ISBN인데 날짜가 몇 년 다른 예가 흔함
- 채택하지 않은 이유: "규칙 더하지 않음 (Recommended)" (2026-10-14)

## 결과
- 좋아지는 점: 서비스 책 1,619,668 → 1,563,167, 같은 책이 한 줄로·다른 권과 작품은 따로
- 감수하는 점: 부제 나누기가 도서관 목록에 달려 도서관을 더하면 나뉨이 바뀔 수 있음, 8자 경계에서 같은 책 몇 건이 두 줄, 꺾쇠 저자 표기(「<김정은>,<김지혜> 저」)는 이 규칙으로 못 합침(사이클 17 첫 배포 전 사이클 19에서 저자 정리를 고쳐 다시 가져옴 — 사용자 "사이클 17 배포 전에 고치자", 2026-10-14), 판 표시·ISBN 없는 다른 판은 합쳐짐
- 나중에 서비스로 분리할 때: 규칙이 가져오기 쪽에 있어 그대로 함께 감
