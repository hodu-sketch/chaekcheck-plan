Webshare 한국 IP 20개를 사서
도서관 사이트가 열리는지 시험하기

가입·결제·대시보드 설정은 직접 하셔야 합니다(계정 만들기와 결제·비밀번호 입력은 Claude가 할 수 없음). 목록 파일을 받아 위치를 알려 주시면 시험은 제가 돌립니다. 한 달 $6, 시험에 쓰는 데이터는 수 MB입니다.

1Webshare 가입 직접

https://www.webshare.io/register 에서 이메일이나 Google로 가입합니다. 무료 플랜(10개)이 같이 생기는데 미국 IP라 이번 시험에는 쓰지 않습니다.

2한국 정적 주거용 20개 구매 직접

아래 링크는 "정적 주거용(공유) 20개, 한국 20개, 250GB, 월 결제"를 미리 채운 구매 화면입니다.

구매 화면 열기

  • 결제 전에 화면에서 Static Residential, 나라 South Korea 20, 값 $6.00/월인지 봅니다. 나라가 비어 있으면 South Korea를 골라 20으로 맞춥니다.
  • Private(다른 고객 0~2명과 같이)은 $18.52, Dedicated(혼자)는 한국 재고가 없습니다(2026-10-16 Webshare API).

질문 "근데 이거 없나"에 대한 답 (2026-10-16 저녁 다시 확인): Webshare API로 다시 보니 한국은 지금도 공유 759개, Private 253개가 있고, Dedicated(혼자 쓰는 것)만 한국이 0개입니다. 화면에서 South Korea가 안 보이면 두 가지를 봐 주세요. (1) 맨 위 종류가 Static Residential(Proxy Server나 Residential이 아님)인지, (2) 그 아래 Shared / Private / Dedicated 중 Dedicated가 골라져 있으면 Shared나 Private으로 바꾸면 나라 목록에 South Korea가 나옵니다. 그래도 없으면 어느 화면인지 알려 주세요.

3IP Authorization에 집 IP 등록 직접

대시보드 Proxy Settings → IP Authorization에 시험할 PC의 공인 IP를 넣으면, 아이디·비밀번호 없이 그 PC에서만 프록시를 쓸 수 있습니다.

  • 시험용: 집 PC 211.178.70.242 (SK브로드밴드, 2026-10-16 확인)
  • 운영용(나중에): EC2 서버 <서버 IP>로 바꿈. 계정마다 기본 1개 IP만 등록됩니다.

4프록시 목록 내려받기 직접

대시보드 Proxy List → Download로 .txt를 받습니다. 한 줄에 ip:port:username:password 모양입니다. 저장소 밖(예: C:\Users\yujun\Downloads\)에 두고, 파일 경로만 알려 주세요. 파일 내용은 붙여 넣지 마세요.

5접속 시험 Claude

집 PC에서 스크립트를 돌립니다. 프록시마다 나가는 IP의 나라·통신사를 보고, 네 곳에 한 번씩 접속합니다(요청 사이 1초). 비밀번호는 화면에 찍지 않습니다.

python docs/research/deploy/tools/proxy_check.py C:\Users\yujun\Downloads\목록.txt --all

6결과 보고 정하기 함께

  • 잘 된 것: 나라 KR, 통신사가 한국 회사(KT·SK브로드밴드·LG U+ 등), 네 곳이 열림 → 운영 서버 IP를 등록하고 사이클 17 인계에 넣음
  • 안 된 것: 나라가 KR이 아니거나 도서관이 안 열림 → 결제 뒤 48시간 안, 1GB 미만이면 환불 요청

질문 "이거 무료 반품 되나"에 대한 답: 됩니다. 조건이 모두 맞으면 수수료 없이 돌려받습니다(도움말에 수수료 언급 없음).
