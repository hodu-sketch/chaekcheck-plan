대출 조회 IP를 늘리려면
지금 EC2 서버에 IP를 더 붙이는 것이 가장 쌉니다

사용자 말씀(2026-10-16): "조회 서버에서 여러 출처 아이피를 설정으로 하는 것도 고려 중이야 (조회 서버 따로 두지 않고 자체 서버에서 할 때도)", "정적 주거용도 괜찮은 것 같아". 방법별 값을 비교하고, 정할 것 세 가지를 4번 카드에 두었습니다.

1무엇을 하려는가: 서버 한 대가
여러 IP로 나눠 나가기

서버 한 대(본 서비스 서버든 조회 서버든)에 공인 IP를 여러 개 붙이고, 도서관 사이트에 요청을 보낼 때마다 어느 IP로 나갈지 설정에 따라 고릅니다. 도서관 사이트에는 IP가 여러 개로 보이고, 우리는 IP마다 따로 셉니다.

초록 실선은 우리 서버에 붙인 우리 IP, 노란 점선은 업체가 빌려주는 IP(ADR-0095의 업체 프록시)입니다. 도서관 사이트는 맨 끝에서 나간 IP만 봅니다.

  • 이미 정한 것과의 관계: ADR-0095는 나가는 길을 세 가지(서버 직접 / 서버 + 업체 프록시 / 조회 서버)로 정했고, 나가는 IP마다 따로 세며, 막힌 IP만 그 사이트에서 멈춥니다. 서버에 붙인 IP 여러 개도 이 규칙을 그대로 따릅니다.
  • 앱에서 쓰는 방법(시험 안 함): 서버 안에서 IP마다 작은 전달 프록시(tinyproxy, 메모리 약 2MB)를 하나씩 띄우고 각자 다른 IP로 나가게 합니다. 그러면 앱은 업체 프록시 목록과 같은 모양으로 "우리 프록시 목록"을 받기만 하면 됩니다. Java HTTP 클라이언트에서 나가는 주소를 직접 고르는 방법도 있는데, dev가 쓰는 클라이언트가 이를 지원하는지는 확인 못 함.

2방법별 한 달 값과
IP를 몇 개까지 붙일 수 있나

지금 운영 서버(AWS EC2 t4g.medium, 서울)에는 IP를 최대 18개까지 붙일 수 있고, 하나에 한 달 약 $3.65입니다. 같은 AWS라도 Lightsail은 서버 한 대에 IP 하나뿐입니다.

3Webshare "월 $6에 20개"는
한국 IP 값인지 모릅니다

$6은 광고에 나온 가장 싼 값입니다. 한국 IP를 그 값에 살 수 있는지는 가입해서 플랜 화면의 나라 목록을 봐야 압니다.

  • Webshare 공식 도움말: 일부 나라는 $6 정적 주거용 플랜에서 제공되지 않을 수 있고, IP가 바뀌는 주거용 플랜에는 있을 수 있다고 적혀 있습니다.
  • Webshare 요금표 페이지: 데이터센터(공유) 100개 $2.99, 기본 250GB는 보이지만, 정적 주거용 값과 나라 목록은 보이지 않았습니다.
  • 다른 사이트 글(공식 아님): 정적 주거용이 공유 20개 $6, 전용 20개 $42라고 적혀 있습니다. 공유면 다른 사용자와 같은 IP를 씁니다.
  • 이미 조사한 다른 업체: Oxylabs 한국 전용 데이터센터 월 $8.25부터, ISP(고정 주거용) IP당 $1.10~1.50 (2026-10-12 업체 표기, hosting-options.md 4-2절).

4정할 것 세 가지

#1은 이전 결정(ADR-0095)을 바꿉니다. #2·#3은 새로 더하는 것입니다.

#1업체 프록시로 "정적 주거용"도 쓸 수 있게 함

2026-10-13에 정한 ADR-0095는 업체 프록시를 "IP가 바뀌지 않는 고정 IP 상품"만 쓰고, 주거용·IP가 바뀌는 상품은 뺐습니다(G안 기각). 이 제안은 그중 정적 주거용(통신사 가정 대역 IP를 고정으로 빌림)만 허용으로 바꿉니다. 요청마다 IP가 바뀌는 주거용은 계속 뺍니다.

[안] 업체 프록시 목록에 정적 주거용 상품도 넣을 수 있게 하고, 조건은 지금처럼 "IP가 고정"인 상품만으로 둡니다. 사용자 말씀: "정적 주거용도 괜찮은 것 같아" (2026-10-16).

그러면: Webshare 정적 주거용이나 Oxylabs ISP 상품에서 한국 IP를 사서 설정에 주소를 넣으면, 그 IP로 나가고 IP마다 따로 셉니다. 도서관 사이트에는 클라우드 IP가 아니라 통신사 IP로 보입니다.

다른 선택: 지금처럼 데이터센터 고정 IP만 → 값은 비슷하지만, 사이트가 클라우드 대역을 막으면 함께 막힘. / 바뀌는 주거용까지 허용 → IP가 매번 달라져 "IP마다 따로 세기·막힌 IP만 멈추기"가 맞지 않음.

추천: 정적 주거용까지만 허용. 법적 부담(막힌 뒤 다른 IP로 들어가는 모양, 대법원 2021도1533)은 ADR-0095의 "감수하는 점" 그대로입니다.

질문: Webshare 정적 주거용을 찾아보면?

Webshare 정적 주거용은 20개 $6(IP당 $0.30)이 맞습니다. 그런데 공식 페이지에 적힌 통신사가 모두 미국 회사이고, 한국 IP로 살 수 있다는 문구는 찾지 못했습니다. 한국 IP가 꼭 필요하면 Webshare는 가입 화면에서 확인한 뒤에 사야 합니다.

#2서버에 붙인 IP 여러 개를
나가는 길 한 종류로 더함

[안] ADR-0095의 나가는 길에 "서버 자기 IP 여러 개(설정으로 목록)"를 더합니다. 본 서비스 서버와 조회 서버 모두 같은 설정을 씁니다. 사용자 말씀: "조회 서버 따로 두지 않고 자체 서버에서 할 때도" (2026-10-16).

그러면: EC2에 IP B·C를 붙이고 설정 목록에 넣으면, 본 서비스가 IP A·B·C를 나눠 쓰고 IP마다 동시 1건·1초(교보 구독형 서버는 IP마다 동시 3건)로 셉니다. 한 IP가 막히면 그 IP만 그 사이트에서 멈춥니다.

다른 선택: 서버 IP는 하나로 두고 업체 프록시만 → 서버 설정은 쉽지만 업체 값과 약관을 따라야 함. / 조회 서버를 여러 대 띄움 → 서버마다 관리할 것이 늘어남.

추천: 더함. 우리 고정 IP라 원칙 안이고, 업체 프록시 목록과 같은 모양으로 넣으면 dev 일이 적습니다.

#3쓰는 순서: 프록시 없이 → 막히면
EC2에 IP 추가 → 그래도 안 되면 업체

[안] 첫 배포는 프록시 없이 서버 IP 하나로 운영하며 어느 사이트에서 막히는지 봅니다(조회 기록, 사이클 20 상태등). 막히면 EC2에 IP를 2~4개 더 붙입니다(한 달 약 $7~15). 그래도 막히면 업체 고정 IP(#1이 승인되면 정적 주거용 포함)를 사되, 가입 화면에서 한국 IP를 먼저 확인합니다.

그러면: 막힘이 없으면 비용 0입니다. 지금까지 우리를 막은 곳은 교보 구독형 서버 한 곳(집 IP, 2026-10-07, 이틀 약 8만 건·동시 4건)입니다.

다른 선택: 처음부터 정적 주거용을 삼 → 한 달 약 $6부터(한국 IP 값은 확인 못 함), 막힘이 없으면 쓰지 않는 값. / 처음부터 EC2에 IP를 붙임 → 한 달 약 $7~15.

추천: 이 순서. 정적 주거용을 먼저 시험해 보고 싶으시면 둘째와 셋째 순서를 바꿔도 됩니다(기타에 적어 주세요).
