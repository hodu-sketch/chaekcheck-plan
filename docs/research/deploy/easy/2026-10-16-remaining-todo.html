1지금 정하실 것

ADR-0130은 기록만 되어 있고 아직 "제안됨(Proposed)"입니다. 이 결정대로 간다고 정하시면 "확정(Accepted)"으로 바꿉니다.

  • ADR-0130 내용: 첫 배포부터 EC2 서버 자기 IP + Webshare 한국 정적 주거용 20개로 대출 조회를 보냄. 업체 프록시와 서버 공인 IP 여러 개를 둘 다, 본 서비스 직접 조회와 따로 둔 조회 서버 둘 다 개발. 바뀌는 주거용은 나중에. 업체 데이터 80% 경고·90% 멈춤, 업체 오류면 Webshare 길 전체 멈춤, CloudWatch → 메일 알림.
  • 확정되면: ADR 파일은 그 뒤로 고칠 수 없고, 바꾸려면 새 ADR을 씁니다. 사이클 17은 이미 이 ADR 기준으로 맞춰 두었습니다.
