1. 먼저 10분 시험: CloudShell 서울

미국 IP에서는 6곳 중 4곳이 응답하지 않았어요. AWS 서울 IP는 받아 주는지 봐요.

  1. AWS 콘솔 로그인 → 오른쪽 위 리전 아시아 태평양(서울)
  2. 위쪽 막대 >_ (CloudShell)
  3. 아래를 통째로 붙여 넣기
curl -s https://ipinfo.io/json; echo; for u in https://ebook.gangseo.seoul.kr https://www.ghlib.go.kr:446 https://ebook.gangnam.go.kr https://library.busan.go.kr/elib https://kbsmalllibrary.bookcube.biz/FxLibrary http://lib.seojeong.ac.kr:8888; do curl -s -o /dev/null -m 30 -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) chaekcheck-crawler/0.1 (catalog survey)" -w "$u  상태 %{http_code}  %{time_total}초" "$u"; echo "  (종료 코드 $?)"; sleep 2; done

2. 수집 서버 모양

  • 수집기는 사람 없이 끝까지 돌고 요약 파일을 남겨요. Claude는 그 서버에서 요약만 보고, 물어볼 게 있으면 폰으로 물어요 (Remote Control).
  • 가져오기는 지금처럼 내 PC에서 해요(힙 6GB). 그래서 사본을 내 PC로 받아요.
  • 교보 구독형 서버는 우리 IP를 막았으니 새 IP로 다시 가지 않아요.

3. 두 가지 안과 한 달 비용

A안 수집 전용 서버 추천B안 서비스 서버에 같이
모양t4g.small(2GiB) + 디스크 60GiBt4g.medium에 디스크만 100GiB로
좋은 점검색을 느리게 안 함, 서비스 배포 전에도 바로서버 하나
나쁜 점서버 둘수집이 CPU를 써서 검색이 느려질 수 있음, 배포 뒤에야 가능
한 달 (24시간)약 $24
서버 $15.2 + 디스크 $5.5 + IP $3.7		디스크 $5.5 + CPU 넘친 몫

서울 요금, AWS 공식 요금 데이터 (2026-10-09 게시, 2026-10-12 확인). 원화는 환율을 확인하지 않아 안 적었어요. 수집이 없는 날 서버를 멈추면 디스크 요금만 나가요. 사본을 받는 데이터는 매달 100GB까지 무료.

4. 아직 모르는 것

  • AWS 서울 IP를 4곳이 받아 주는지 → 1번 시험
  • 수집기가 2GiB로 되는지 → 다음 집 PC 수집 때 측정
  • 사본을 압축하면 얼마나 줄지
  • Linux 서버에서 Remote Control을 켜 두는 방법
  • 전체 수집 한 바퀴 시간 (늘 켤지, 수집 때만 켤지)
