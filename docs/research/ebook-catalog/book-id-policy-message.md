```

정한 것:
1. 다시 가져올 때, 새로 묶은 책에 그 책의 도서관 책 코드가 가장 많이 겹치는 옛 책이 있으면 그 번호(/books/{bookId})를 이어 씀. 없으면 새 번호
2. 옛 책 둘이 합쳐지면 작은 번호를 남김. 한 책이 나뉘면 코드가 더 많이 겹치는 쪽이 옛 번호
3. 안내표(옛 번호 → 새 번호)는 두지 않음. 없어진 번호는 "책을 찾을 수 없어요". 회원이 저장한 책 번호는 가져올 때 새 번호로 고쳐 씀. 번호는 다시 쓰지 않음
4. 배포는 지금 방식 그대로 하고, 책 번호 유지는 회원이 책을 저장하는 기능(사이클 06·07)보다 먼저 만듦

사이클에서 정할 것(아직 안 정함): 표·API 모양, catalog 모듈이 "번호가 바뀌었다"를 알리고 회원 쪽이 고쳐 쓰는 방식(이벤트 등), 표 통째로 바꾸기(5.1절)와 같이 할지.
사이클 06·07 설계 때 회원 데이터에 bookId를 저장하게 되면, 이 정책이 먼저 들어가 있어야 해.
```
