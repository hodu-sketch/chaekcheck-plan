## 2. 바꿨을 때 겹침 시험 (2026-10-11, 수집 DB 2,917곳)

- 시험한 규칙:
  - 이름 끝의 괄호 표시(위 8가지)를 뗌 → 57곳 이름이 바뀜
  - 업체: 화면 종류에서 정함. 교보, YES24, 북큐브, 알라딘, 통합 포털, 자체
  - 대출 방식:
    - 교보 구독형 화면은 확인 결과 파일 값(소장 1,187, 혼합 196, 대여 47)

## 3. 결정 [확정] (사용자 승인, 2026-10-11, 결정 페이지 6개 모두 승인)

1. 이름(`name`)에는 기관 정식 이름만 둠. 괄호 표시는 모두 뗌 [확정]
2. 분류 칸:
   - 모든 도서관에 **업체**와 **대출 방식**을 채움 [확정]
   - 업체는 화면 종류에서 정해지는 값(교보·YES24·북큐브·알라딘·통합 포털·자체)
   - 대출 방식은 지금 `lending_model`을 모든 도서관으로 넓힘
3. 겹침 규칙: (이름, 업체, 대출 방식) 조합이 겹치지 않게. 지금 `name` UNIQUE를 대신함 [확정]
4. 그래도 겹치는 곳: 위 2절 표대로 처리. 다른 기관이면 정식 이름, 같은 사이트면 받지 않음 [확정]
5. 화면: 이름 옆에 "교보 · 소장"처럼 분류를 작게 붙임 [확정]
6. 이전 결정과의 관계:
   - 사이클 07 seed 규칙("괄호 붙임, 한 번 정한 이름은 바꾸지 않음" [확정])과 ADR-0017 "감수하는 점"을 바꾸는 일 → 새 ADR로 대체 [확정]. ADR은 다음 사이클이 씀 (사용자: "이거 통으로 다음 cycle에 전달하게 md로 다 만들어 줘", 2026-10-11)
   - 도서관 번호는 그대로라 저장된 내 도서관·로그인 계정에는 영향 없음 [확인 필요: dev에서 이름으로 찾는 곳이 있는지]
