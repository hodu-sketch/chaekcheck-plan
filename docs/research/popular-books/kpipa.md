## 2. 서버에서 받는 방법 [확정] (2026-10-11 이 세션에서 curl로 시험)

세션 없이 POST만 보내면 `302 → /home/error/cmmn/accessDenied`. 아래 순서면 됩니다.

1. `GET https://bnk.kpipa.or.kr/home/v3/addition/adiStatsCtgSaleRank` → 쿠키 `JSESSIONID`(Path=/home), `SCOUTER` 받음. 페이지 안 스크립트 `var m_sCsrf = "<uuid>";`가 CSRF 토큰 (헤더 이름은 `var m_hCsrf = "X-CSRF-TOKEN"`)
2. 같은 쿠키로:

```
POST https://bnk.kpipa.or.kr/home/v3/addition/adiStatsCtgSaleRank/search
Content-Type: application/x-www-form-urlencoded
X-CSRF-TOKEN: <1에서 읽은 값>
X-Requested-With: XMLHttpRequest
Referer: https://bnk.kpipa.or.kr/home/v3/addition/adiStatsCtgSaleRank

rdoSearchType=bookType&txtDate=202609&searchCtg=<분류ID>&strTypeArr=&searchOrder=&depth=1depth&gubun=N
```

- 토큰 없이 쿠키만 보내면 `403` (시험함)
- 결과: 22개 목록(전체 + 21분류) 모두 `200`, 각 50권, 서로 다른 ISBN 1,050개 (2026-10-11, 202609, 요청 사이 2초) — 메모의 숫자와 같음
- 응답은 JSON이 아니라 HTML 조각. 책 1권 = `.book-grid-item` 1개

| 항목 | 선택자 | 비고 |
|---|---|---|
| 제목 | `.figcaption` | |
| ISBN | `.info .number` | 하이픈 포함, 종이책 ISBN-13 |
| 저자 | `.info .writer` | 빈 값 많음 |
| 공식 세부분류(Thema) | `.info .category` | |
| 순위 | `.badge-label-rank` | 메모의 파싱에서 NaN → 목록 순서 = 순위로 씀 |
| 표지 | `img[data-originalsrc]` | 출판사 저작물 — 5절 |

## 4. 일치율 측정

2026-10-11 측정. 대상: 202609 Top50 22개 목록의 서로 다른 ISBN 1,050권. 맞댄 곳: 수집 DB `chaekcheck-data\ebook-catalog.sqlite`(읽기 전용, `removed_at IS NULL`, 오디오북 제외). 서비스 DB가 아니라 수집 DB라 서비스 화면 숫자와 조금 다를 수 있음.

| ISBN → 교보식 코드(`480`…, `../ebook-catalog/same-book-isbn.md` 3절 규칙 거꾸로)로 `item_key`·`alt_code` 찾기 | 292 | 27.8% |
| 본제목(`:`·`(`·`[` 앞, 공백·기호 빼고 소문자) 완전 일치 | 444 | 42.3% |

## 5. 주의사항

- **재게시 조건** [확인 필요: 공식 문의]: 공개 통계 화면 데이터를 다른 사이트에 보여도 되는지 명시 조항을 찾지 못함 (메모)
  - 회원 약관 제17조②: 회원은 제공 자료를 자유롭게 이용, 출처 명기 필요 — 비회원 화면에도 적용되는지 불명 (메모)
  - 판매 데이터 리포트: "동의 없이 상업적 목적 사용 불가" 문구 (메모)
  - 도서정보 DB 서비스 쪽은 "상업 이용은 운영위원회 승인, 출처 표시·독립 노출 의무(약관 제8조⑤)" (`../ebook-catalog/same-book-isbn.md` 4절, 2026-09-30 조사)
  - 문의: 고객지원센터 070-8209-4271 / kbookdata@kpipa.or.kr (메모)
- **호출량**: 공공기관 사이트이므로 월 1회, 요청 사이 간격을 둠. 권장 간격 안내는 없음 (메모). 이 세션 시험은 2초 간격 22건
- **표지 이미지**: 출판사 저작물이라 따로 판단. 우리 수집 DB의 전자책 표지(`cover_url`)를 쓰는 길도 있음 [안]
- **Open API(회원 전용)**: 도서 메타데이터 전용, 판매 순위 없음 (메모). 회원 유형에 개인이 없어 가입이 어려울 수 있음 (가입 https://bnk.kpipa.or.kr/home/v3/signup, 메모)
