# 책 표지 이미지를 보여 줄 때의 저작권 (조사, 2026-10-12)

- **법률 자문이 아니라 정보 정리입니다.** 실제 문제가 생기면 변호사나 한국저작권위원회 상담으로 확인합니다.
- 계기: 사이클 10 인기 도서가 출판유통통합전산망 표지(작은 그림)를 매달 받아 우리 서버에 저장하고 보여 줌(ADR-0075). 사용자: "어차피 책 표지는 검색하면 그냥 다 나오는 거니까 올려도 된다고 봐", "수많은 개인 사이트들이 표지 정보를 그냥 쓰던데", 조사 요청 "이거 더 조사해서 알려줄래? 책 표지 정보" (2026-10-12)
- 조사: 서브에이전트가 국가법령정보센터·한국저작권위원회·각 서비스 공식 문서를 읽음(2026-10-12). 직접 다시 확인한 것은 "직접 확인" 표시

## 1. 저작권법 (국가법령정보센터, 시행 2026-08-11 판)

|---|---|

| 제9조 | 법인 이름으로 공표된 업무상저작물은 (계약에 다른 정함이 없으면) 법인이 저작자 |
| 제28조 | 공표된 저작물은 보도·비평·교육·연구 등을 위해 정당한 범위에서 공정한 관행에 맞게 인용 가능 |
| 제35조의5 | 공정이용: 일반적인 이용 방법과 충돌하지 않고 정당한 이익을 부당하게 해치지 않으면 이용 가능. 고려: ① 목적·성격 ② 저작물 종류·용도 ③ 이용 비중·중요성 ④ 시장·가치 영향. 2016년 개정에서 "영리성 또는 비영리성" 문구가 빠짐 |

| 제93조 | 데이터베이스제작자 권리. ②항 개별 소재라도 반복적·체계적 복제는 상당 부분 복제로 봄. ④항 보호는 소재 자체에는 미치지 않음 |
| 제103조 | 권리자가 중단을 요구하면 즉시 중단. 받을 사람을 미리 공지하면 온라인서비스제공자 책임이 줄어듦 |
| 제125조의2 | 법정손해배상: 저작물 하나당 1천만 원 이하(영리 목적 고의는 5천만 원 이하), 침해 전 등록이 있어야 청구 |
| 제136조 | ①항 저작재산권 침해 7년 이하 징역 또는 1억 원 이하 벌금, ③항 3호 DB제작자 권리 침해 3년 이하 또는 3천만 원 이하 |
| 제140조 | 원칙은 고소가 있어야 처벌(친고죄). 영리 목적 또는 상습이면 고소 없이도 |

## 3. 표지는 누구 것인가

- 창작성이 있으면 미술저작물(위 판례). 출판사 직원이 만들고 출판사 이름으로 내면 출판사(제9조), 외주 디자이너·일러스트레이터·사진가면 계약에 따라 그 사람일 수 있음. 책마다 누구인지는 확인 못 함

## 4. 정부 안내

- 문화체육관광부 저작권 Q&A: "일반적인 썸네일 이미지 검색서비스를 제공하는 것은 저작권 침해에 해당되지 않는다" (https://www.mcst.go.kr/kor/s_policy/copyright/netizen/netizen02.jsp, 서브에이전트 확인)
- 한국저작권위원회의 책 표지 전용 상담 사례: 확인 못 함

## 6. 위험을 줄이는 방법 (판단, 서브에이전트 정리)

| 방식 | 근거 | 위험 정도 (판단) |
|---|---|---|
| 원본 크기로 우리 서버에 저장해 표시 | 제136조①, 특허법원 판결(해상도가 핵심) | 높음 |
| **작게 줄인 그림을 저장해 표시 + 출처 표시 + 삭제 요청 대응** (지금 설계: 작은 표지 약 51KB 저장, 출처 줄) | 특허법원 판결, 2005도7793 | 중간 |
| 원 주소로 바로 링크(핫링크), 작게 표시 | 2009다80637 (상대 서버 부담·약관 미확인) | 중간 |
| 정보나루 표지 링크, 비영리, 저장 안 함 | 정보나루 매뉴얼 | 낮음 (단, 사용자가 정보나루를 쓰지 않기로 함, ADR-0072) |
| 표지 없이 제목 글자 카드 | 이용 행위 없음 | 낮음 |

- 공통으로 위험을 줄이는 것: 작은 크기만(확대 보기 없음), 표지 가까이 출처 표시(제37조), 삭제 요청 받는 곳을 공지하고 요청 오면 바로 내림(제103조 구조), 광고·유료화 피하기(영리성), 사이트 데이터 전체를 매달 체계적으로 모으는 것은 제93조② 쟁점이 될 수 있음(표지 자체는 ④항으로 DB권 대상 아님)
