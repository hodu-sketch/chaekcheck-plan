- 공공도서관 이름은 지자체 조례로 정하므로 바꿀 때 조례를 고침. 박성재(2022) 「한국 공공도서관명 변화 분석 연구 - 2015-2020년을 중심으로」(한국문헌정보학회지 56(3), 291-312, https://koreascience.kr/article/JAKO202226258548916.page)는 국가도서관통계시스템에서 **5년 동안 211건**의 이름 변화를 찾아 7가지로 나눔(운영 주체 다툼, 청소년 서비스 강조, 주제 특화, 시민 공모 이름 등) [확정: 초록]. 원문 PDF는 읽지 못해 유형 7가지의 이름은 확인 못 함
- 행정구역 변경: 2026-07-01 전남광주통합특별시 출범으로 광주·전남 기관 이름이 한꺼번에 바뀜(ADR-0003, 행정안전부 변경내역, 2026-09-27 확인). front-out에서 전남교육청 소속 북큐브 사이트 제목이 "전남광주통합특별시교육청 ○○도서관"으로 바뀐 곳 8곳(297·318·325·332·333·372·373·402), 교보 기관 목록 이름도 이미 "전남광주통합특별시…"
- 특정 공공도서관 하나의 2025~2026 조례 개정 예는 이번에 찾지 못함 [확인 필요]

## 3. 얼마나 자주, 왜 우리에게 중요한가

- 빈도
  - 대학 통합: 대학알리미 기준 2021~2026년 8건, 2026년 3월에만 4건. 흡수된 학교 이름은 사라짐
  - 공공도서관: 2015~2020년 211건(5년, 박성재 2022) → 한 해 약 40건 꼴 (계산값)
  - 행정구역: 행정안전부 변경 공지가 반년마다 나옴(사이클 01 spec 11장). 2026-07-01 전남광주 통합처럼 한 번에 여러 도서관 이름이 바뀌기도 함
  - 우리 2,672곳 중 이번에 확인된 개명·소멸 기관만 15곳 남짓. 회사 332곳·학교 1,254곳은 하나씩 보지 않았으므로 더 있을 것 [확인 필요]
- 왜 중요한가
  - 이름 찾기(S10 "이름 찾기", 결과 카드): 이용자는 지금 이름으로 찾음. 옛 이름으로 남아 있으면 못 찾음(예: "경상국립대"로 찾으면 434번 "경상대학교"가 안 나옴)
  - 반대로 이름을 새로 고치면, 옛 이름을 기억하는 이용자는 못 찾음(사이클 08 결정: 새 이름으로만 찾음, 사용자 승인 2026-10-06)
  - 이용자가 저장해 둔 도서관은 서비스 번호로 이어지므로 이름을 바꿔도 끊기지 않음(R4-1, 번호 유지 [확정])
  - 흡수·소멸한 기관(428·429·769·2257·607·895)은 이름만의 문제가 아니라 사이트 자체가 닫히거나 통합 사이트로 옮겨갈 수 있음 → 이름 고치기가 아니라 "주소 바뀜·끄기" 쪽 일일 수 있음
  - seed를 다시 만들면 업체 목록의 이름(옛 이름일 수 있음)으로 돌아갈 수 있음 → R4-3 "이름 고침" 목록이 막음

## 4. 이름 이력을 남기는 방법 [안]

표·API 설계가 아니라 방법만입니다.

| 안 | 내용 | 좋은 점 | 아쉬운 점 |
|---|---|---|---|
| (a) 지금 이름만 고침 (지금 결정) | R4대로 "이름 고침" 목록에 새 이름만. 옛 이름으로는 안 찾음 (사용자 승인 2026-10-06) | 가장 단순. 이미 정한 대로라 다시 할 일 없음 | 왜·언제 바뀌었는지가 seed 목록 밖에는 안 남음. 옛 이름으로 찾는 이용자는 못 찾음 |
| (b) "이름 고침" 목록에 옛 이름·근거·바뀐 날을 함께 적음 | 목록 한 줄에 `옛 이름 / 새 이름 / 바뀐 날 / 출처 URL / 확인일`. 서비스에는 새 이름만 보임 | R4-3의 "근거를 목록에 함께 적음"과 거의 같아 일이 적음. 다음에 다시 확인할 때 이력이 남음. 같은 기관이 또 바뀌어도 줄을 더하면 됨 | 이용자 화면에는 변화 없음(옛 이름 검색은 여전히 안 됨) |
| (c) (b) + 옛 이름으로도 찾게 함 | 옛 이름을 검색어로도 씀. 결과에는 새 이름과 "(옛 이름 ○○)" 정도 표시 | 옛 이름을 아는 이용자도 찾음(통합 직후 대학처럼 이름이 갓 바뀐 곳에 도움) | 저장할 곳이 하나 더 필요(사이클 08 결정 페이지의 "이름 칸이 하나 더 필요"). 흡수된 학교 이름(예: "경남과학기술대")을 어디에 붙일지 정해야 함. 범위가 사이클 08 밖일 수 있음 |

- 추천: (b). 이미 정한 (a)를 바꾸지 않으면서 R4-3 요구(이름 자체 검증·근거 기록)를 채움. (c)는 이용자가 옛 이름으로 못 찾는다는 말이 나오면 backlog에서 다룸 [안]
