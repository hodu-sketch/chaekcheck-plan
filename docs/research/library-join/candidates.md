## 1. 방법

등록 도서관을 조사할 때와 같은 기준을 씀. 원본은 dev `docs/library-maintenance.md`:

- 4-8절 가입 자격 찾기:
  - 원문 우선, 추정 금지
  - 정회원·회원증 발급 대상이 자격
  - 홈페이지 가입은 누구나 되고 회원증만 지역 제한이면 "누구나 + 주의"
- 4-10절 가입 방법과 방문 가입 판단
- 2장 호출 예절

순서:

1. **종류 나누기 (이름으로 1차)**
   - 종류: 공공도서관 / 초·중·고 / 대학 / 회사 / 정부·공공기관 / 협회·단체·아파트 등 / 시험용 / 모름
   - 이름으로 나눈 것이라 원문으로 확인한 것이 아님. 표의 `sure` 칸에 확실한지 적음
2. **공공도서관: 원문으로 가입 자격 조사**
   - 4-8·4-10절 그대로: 본 홈페이지의 회원가입 안내, 회원 구분, 회원증 발급 대상 페이지를 직접 열어 원문을 인용함
   - 적는 것: 근거(거주·재직·재학·누구나), 범위(시군구·시도·인접 지역), 방문 가입 여부, 가입 방법, 출처 URL, 원문 확인 상태
3. **학교·대학·회사·기관: 소속 구성원 전용으로 분류**
   - 이 곳들은 그 기관의 학생·교직원·직원만 쓰는 곳이라 지역 자격이 없음
   - 사이클 07은 "소속 기관(대학·회사) 자격"도 범위에서 뺐음. 그래서 여기서는 종류만 적고, 표본 몇 곳만 로그인 안내 원문으로 확인함
