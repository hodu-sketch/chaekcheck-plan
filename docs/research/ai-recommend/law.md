추론
- **탭 단위 난수 번호(쿠키 없음, 회원 번호·IP와 결합 불가)**: 그 자체로 개인을 알아볼 수 없고 결합 키도 없으므로 개인정보가 아니라고 볼 여지가 큼. 단 같은 기록 줄에 IP(30일)가 있으면 IP+방문 번호 결합으로 나목 가능성 → **추천용 기록에는 IP를 넣지 않거나**, 방문 번호를 탭이 닫히면 사라지게 두는 것이 안전.

- 제2조 7호 나 "인공지능이용사업자: 가목의 사업자가 제공한 인공지능을 이용하여 인공지능제품 또는 인공지능서비스를 제공하는 자". 4호 고영향 인공지능 영역(에너지, 보건의료, 채용·대출 심사, 교통, 학생 평가 등)에 추천은 없음.
- 시행령 제23조① 사전 고지: "이용약관 등에 기재" 또는 "이용자의 화면 … 에 표시". ② 표시: "사람이 인식할 수 있는 방법" 또는 "기계가 판독할 수 있는 방법(이 경우 … 1회 이상 안내 문구 … 제공)". ④ 예외: "생성형 인공지능을 활용한 사실이 명백한 경우" 등.
- 시행령 제29조의 매출·이용자 기준(1조원, 100억원, 1일 100만 명)은 **국내대리인 지정**에만 해당. 제31조에는 규모 면제가 없음.
- 가이드라인 보도자료: "1년 이상 계도기간 … 사실조사 및 과태료 부과가 유예"; "인공지능 생성물이 서비스 환경 내에서만 제공될 때는 사용자 이용 환경(UI)이나 상징(로고) 표출 등을 통해 유연하게 표시할 수 있다"; "인공지능 기술이나 서비스를 단순히 업무나 창작의 '도구'로 활용하는 이용자는 의무 대상에 해당하지 않는다."

확인 못 함: 가이드라인 본문 PDF, 제23조④3호 고시. 공정위 추천·보증 심사지침은 광고·제휴 수익이 없어 조사하지 않음.

추론
- 책첵은 바깥 LLM을 "이용하여 서비스를 제공"하므로 인공지능이용사업자에 해당할 소지가 큼(개인·비영리 면제 조항 없음). 고영향은 아님. 따라서 **① 생성형 AI가 쓰인다는 사전 고지(약관 또는 화면) ② 문구 옆 "AI가 쓴 문구" 표시**. 화면 안에서만 보이면 가이드라인의 "UI·아이콘" 유연 표시로 충분하다고 읽힘. 계도기간(2027-01 이후까지)이지만 넣는 데 비용이 없음.
- 자체 기준을 두고 LLM 없이 고른 "비슷한 책" 목록 자체는 생성형 AI 결과물이 아님(임베딩은 글을 만들지 않음) → 표시 대상은 문구만 [추론].

## 5. 저작권: 책 소개를 LLM 입력으로 써도 되나

출처
- 알라딘 OpenAPI 종료 공지(2026-09-01) https://blog.aladin.co.kr/openapi/17486624 ; 약관(2022-09-01) https://blog.aladin.co.kr/openapi/13851154
- 국립중앙도서관 ISBN 서지정보 Open API https://www.nl.go.kr/NL/contents/N31101030500.do ; 저작권정책 https://www.nl.go.kr/NL/contents/N70600000000.do

확인된 문장 [확정]
- **알라딘 OpenAPI 종료**: "신규 OpenAPI 인증키 발급 … 종료 : 2026년 9월 4일" / "기존 이용자 OpenAPI 서비스 종료 : 2026년 10월 30일" / "10월30일 이후에는 기존 인증키를 이용한 API 호출 및 데이터 조회가 불가능합니다." 대상 "도서 검색 및 도서정보 API 전체". 약관 7.3③은 "무단으로 복제, 저장(캐시 행위 포함), 가공" 금지.
- 국립중앙도서관 ISBN API: 응답에 BOOK_INTRODUCTION(책소개)·BOOK_SUMMARY(서평)·BOOK_TB_CNT(목차) — "21년 2월까지 생성된 데이터 제공". 회원·인증키·담당자 승인 필요. 저작권정책: 도서관이 저작재산권 전부를 보유한 저작물은 공공저작물 자유이용(공공누리 제1유형: 출처표시, 상업·비상업, 2차적 저작물 가능).

확인 못 함: 국립중앙도서관 API의 책소개가 도서관 저작물인지 출판사 제공물인지(출판사 것이면 공공누리 대상 아님). 저작권법상 AI 학습·입력(TDM) 규정.

추론
- 알라딘 API는 2026-10-30에 끝나므로 입력원으로 설계하면 안 됨. 국립중앙도서관 책소개는 2021-02 이전 자료에만 있어 범위가 제한적.
- 권리 부담이 가장 작은 방식: 책 소개 원문을 화면에 싣지 않고, **LLM이 서지(제목·저자·출판사·분야)만으로 1~2문장을 새로 씀**. 출판사 책 소개를 입력으로 쓸 때는 결과에 원문을 복제하지 않도록 길이·표현 제약.
