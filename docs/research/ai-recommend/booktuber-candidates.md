## 2. YouTube Data API 한도 (2차 출처)

공식 페이지 https://developers.google.com/youtube/v3/determine_quota_cost 를 열지 못함. 아래는 공식 표를 인용한 검색 요약·제3자 글(channelcrawler, blotato)이라 [확인 필요: 공식 문서 확인].

| 항목 | 값 |
|---|---|
| 하루 기본 한도 | 10,000단위, 태평양 시간 자정 초기화 |
| `playlistItems.list`·`videos.list`·`channels.list` | 1단위 |
| `search.list` | 100단위 |

채널 30곳의 새 영상을 하루 한 번 읽으면 `playlistItems.list` 30번 + `videos.list` 몇 번으로, 위 값이 맞다면 하루 한도의 1% 안팎 [안: 계산값]. 사이클 21 수집기도 같은 API를 씀(28단위).
