## 1. 진단

첫 사용자의 길: ① 들어옴 → ② 지역을 묻는 자리 → ③ 검색 결과 → ④ 가입 방법 → 도서관. 친구분들은 ①②에서 막혔습니다. 기능은 다 있고, 없는 것은 셋입니다.

1. 첫 화면이 "무엇을 해 주는지"는 말하지만 "왜 필요한지"(전자도서관은 가입 조건이 도서관마다 다름)와 "나에게 무슨 이득인지"(사기 전에 빌릴 수 있는 도서관을 찾음)를 말하지 않음 → "왜 사는 곳을 고르나"가 설명되지 않음.
2. 지역 줄이 "지역 설정 / 조건 수정 / ○○ 거주 조건으로 찾아요"라 검색 필터처럼 읽힘. 지역은 검색 조건이 아니라 가입 자격 정보.
3. 로그인의 이유(폰·PC 같이 쓰기)와 탈퇴 자리(마이페이지 맨 아래 빈 공간 뒤 단추)가 화면에서 설명되지 않음.

③④는 사이클 22(안내 줄·꼬리표·가입 안내 창)가 맡으므로, 이 검토의 안은 첫 화면의 말과 자리에 집중합니다. 서버·API 변경 없음.
