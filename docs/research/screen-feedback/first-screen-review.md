| 화면 | 본 것 |

| 첫 화면 `/` (PC) | 제목 + 검색창 + [상세검색][⚙] + 한 줄: [누구나 가입 \| 전체 도서관] [방문 없이 가입] [내 도서관 설정]. 지역을 묻지 않음 |

## 2. 사용자 관점 문제 (결정 페이지 P1~P9 요약)

1. 기본 범위가 누구나 가입 39곳(전국)이고 첫 화면이 지역을 묻지 않음 → 서울 사람에게 울산·김천 결과가 먼저.
2. 지역 설정까지 일곱 단계(첫 화면 → 내 도서관 설정 → 내 도서관 화면 → 변경 → 창 → 저장 → 돌아가기).
3. 상세검색에 지역·도서관 조건 없음.
4. 같은 스위치 이름이 넷: 누구나 가입 / 가입 가능한 곳 / 내 도서관 / "내 도서관 스위치"(마이페이지 안내문).
5. "방문 없이 가입"의 뜻이 화면에 없고, 켜면 주소 `visit=none`으로 다음 방문까지 남음.
6. 결과 순서가 "지금 빌릴 수 있어요 묶음 → 책 → 책 안에서 직접 추가·가입 등급"이라 내 지역 도서관이 맨 위에 오지 않음. 줄마다 왜 나왔는지(내 지역/누구나 가입) 표시 없음(이름을 눌러야 팝오버).
7. 내 지역 창이 PC·TV에서 작음(고정 너비, 작은 글자, 작은 체크 칸).
8. 폰 첫 화면에 지역이 있다는 힌트가 없음.
9. 지역이 브라우저에만 저장되고, 로그인하면 계정에 옮겨진다는 사실을 저장 순간에 알려 주지 않음.

## 3. 개선안 [안] (자세한 내용·그림은 결정 페이지)

| # | 안 | 바꾸는 이전 결정 |
|---|---|---|
| 1 | 첫 화면 검색창 아래 "어디서 빌리실 건가요?" 시도→시군구 두 단계 고르기. 안 고르면 "전국 누구나 가입 39곳에서 찾아요" 표시 | 없음 (지역 값은 그대로) |

| 3 | 스위치 이름을 늘 "내 도서관 / 전국"으로. 비어 있으면 아래 한 줄 "지금은 누구나 가입 39곳이에요" | 사이클 07 "지역 없음 '누구나 가입', 지역 있음 '가입 가능한 곳'" |

| 5 | 내 지역 창: (가) 크게 / (나) 창 없이 두 단계 고르기. 제안 (나) | 사이클 06 S2 창 구조 |
| 6 | "방문 없이 가입"을 ⚙ 안으로, "직접 가야 가입되는 도서관은 빼기 (125곳)" | 자리와 말만 (기능·기억 동작은 2026-09-29·10-05 결정 그대로) |
| 7 | 폰 첫 화면에 [내 도서관: 서울 강남구 ▾] 칩 늘 보이기 | 사이클 08 "폰은 설정을 ⚙ 안에"는 유지 |
| 8 | 저장 순간 "로그인하면 다른 기기에서도 그대로예요" 한 줄 | 없음 (로그인 없이 쓰기 유지) |
| 9 | 1·2·3·7을 사이클 22로 먼저, 4·5·6·8은 다음 | — |

- 친구분의 "스위치(탭) 없애고 즐겨찾기만 맨 위" 안은 조회 계획이 68곳 → 약 376곳(API 2026-10-18: OPEN 39 + UNKNOWN 276 + UNVERIFIED 61)으로 늘어 동시 검색 자리 40(사이클 20)에 부담이라, 안 2의 다른 선택으로 둠.
- 사용자가 대화에서 낸 "처음 한 번 작은 안내 창" 안은 친구분이 "알려주는 것보다 애초에 사용하기 쉽게"라고 거절해 안 1의 다른 선택으로 둠.
