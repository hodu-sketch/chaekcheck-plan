다른 선택: 새 사이클 23 "첫 사용자 안내"로 따로 — 기록은 깔끔하지만 같은 화면 파일을 두 번 손댑니다.

한 흐름: 안을 모두 적용했을 때 첫 사용자의 길

서울 강남구에 사는 사람이 「경험의 멸종」(사용자가 대화에서 든 예)을 찾는 장면입니다. 어느 단계에서도 "왜?"가 남지 않도록 앞 단계의 말이 다음 단계의 말로 이어지게 했습니다.
첫 화면에 들어옴 (안 1·2)"읽고 싶은 전자책, 사기 전에 빌릴 수 있는 도서관부터 찾아보세요" + "도서관마다 가입 조건이 달라요(사는 곳만 / 일하는 곳도 / 어디 살든)". 여기서 "가입 조건이 다르다"는 말을 처음 봅니다.
지역 줄을 읽음 (안 3)"사는 곳을 알려 주시면 가입할 수 있는 도서관을 골라 드려요 [사는 곳 고르기] · 안 골라도 어디 살든 가입되는 도서관 39곳에서 찾아요". 1단계의 "가입 조건이 다르다"를 이어받아 "그래서 사는 곳을 묻는다"가 됩니다. 급하면 안 고르고 바로 검색해도 됩니다.
[사는 곳 고르기] → 상자 (안 3)맨 위 "왜 묻나요? 도서관마다 가입 조건이 달라서요 … 증명은 도서관이 가입할 때 확인해요". 서울 → 강남구 체크. 즉시 저장되고 줄이 "서울 강남구에 살아요 [바꾸기]"로 바뀝니다. 로그인 전이라 노란 줄 "이 브라우저에만 저장됐어요. 로그인하면 다른 기기에서도 그대로예요 [카카오 로그인]"(사이클 22).
「경험의 멸종」 검색 → 결과 (사이클 22 + 안 4)① "내 도서관에 있어요 · 서울 강남구에서 가입할 수 있는 곳과 직접 추가한 곳" → ② "어디 살든 가입되는 도서관에 있어요 · 온라인으로 바로 가입할 수 있어요" (고흥 같은 다른 지역 도서관이 여기 옴, 줄마다 [어디 살든 가입] 꼬리표) → ④ 확인하지 못한 도서관 → 맨 아래 "가입 조건이 맞지 않는 도서관은 찾지 않았어요 · [전국에서 찾기]". 2단계의 "어디 살든 가입되는 도서관"이라는 말이 묶음 이름으로 다시 나옵니다.
도서관 이름이나 꼬리표를 누름 → 가입 안내 창 (지금 그대로)"○○도서관 가입 안내 · 가입 대상: 어디 살든 가입 · 가입 방법: 온라인 가입 · 준비할 것: 본인인증 수단 · [공식 가입 안내 보기] · 이미 회원이에요 · 책 보기". 3단계의 "증명은 도서관이 확인해요"가 여기 "준비할 것"으로 이어집니다. [대여하기]는 도서관 사이트로.
며칠 뒤 폰에서 다시 옴 (안 5)폰에는 지역이 없어 2단계 줄이 다시 보입니다. 로그인 창을 열면 "로그인하면 사는 곳·… 폰과 PC에서 똑같이 보여요. 로그인하지 않아도 모든 기능을 쓸 수 있어요". 로그인하면 사이클 07의 가져오기 창으로 PC에서 고른 지역이 계정에 들어갑니다.
마이페이지 (안 7)지역 선택 · 직접 도서관 추가 · 직접 추가한 도서관 · 계정(로그인되어 있어요 [로그아웃] / 탈퇴하기) · 돌아가기. 떠날 때도 찾아 헤매지 않습니다.
