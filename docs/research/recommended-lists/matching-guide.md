# 추천 목록 책을 우리 카탈로그 책에 맞추는 방법 (지침)

- 쓴 날: 2026-10-17 (사이클 21 dev 결과 검토 #3·#4·#5, 결정 페이지 `docs/cycles/21-recommended-books/easy/2026-10-17-dev-result-review.html`)
- 대상: 이동진 추천도서·서울대 100선 목록 파일(dev `scripts/crawl/lists/*.tsv`)의 한 줄을 우리 수집 카탈로그의 책 하나(고정 판)에 맞추는 일. 사서 추천도서는 서버가 따로 맞춤(ADR-0090, 사이클 14 `pickTitleKey`·`firstNameExact`)
- 이 문서는 "어떻게 하는가" 지침이고, 결정 원문은 사이클 21 설계(`docs/cycles/21-recommended-books/design-delta.md` "모듈" 맞추기 순서)·ADR-0124·0125·0129입니다. 맞추기 규칙을 바꾸면 이 문서와 그 원문을 함께 고칩니다
- 사용자 요청: "도서 검색 방법을 좀 더 보충해봐.. 다른 ai세션이 해도 잘 하도록 문서화 잘 하고", "다른 ai가 잘 하도록 지침 문서 잘 하고" (2026-10-17)

## 1. 맞추는 차례 [확정] (사이클 21 설계, ADR-0124)

1. 목록 줄의 고정 판 ISBN(`pinned_isbn13`)이 있으면 ISBN으로 찾음
2. 없으면 고정 판 제목 + 저자로 찾고, 결과를 고정 판 출판사의 정리값으로 좁힘 (출판사 정리는 dev `CatalogText.publisherNorm`)
3. 그래도 여럿이면 판 고르기 규칙 (나)(dev `BookChoice`): 세트는 한 판으로 보고, 보유량은 세트의 최댓값, **1권을 보임**, 같으면 번호가 작은 것 (사이클 21 handoff 248행)
4. 고정 판이 비어 있으면 목록 줄의 ISBN → 제목 + 저자
5. 못 맞추면 책 없음(`book_id` 비움) — 화면은 흐린 표지(사이클 21 결과 검토 #2: 그림이 있으면 흐린 그림)

## 2. 제목으로 찾을 때 꼭 보충할 것: 권 표기 [확정] (2026-10-17, 결과 검토 #4)

**사례**: 「카라마조프가의 형제들」은 수집기가 "1권이 우리 카탈로그에 없다"고 보고 2권을 골랐는데, 카탈로그에는 제목이 **「카라마조프가의 형제들. 1」**인 책이 있었습니다(사용자 확인). 권 번호가 제목 끝에 마침표와 함께 붙은 표기를 같은 세트의 1권으로 보지 못한 것입니다.

그래서 제목을 비교하기 전에, 그리고 "1권이 없다"고 판단하기 전에 아래 표기를 모두 **같은 세트 + 권 번호**로 읽어야 합니다.

| 제목 표기 예 | 세트 이름 | 권 |
|---|---|---|
| `카라마조프가의 형제들. 1` | 카라마조프가의 형제들 | 1 |
| `카라마조프가의 형제들 1` | 같음 | 1 |
| `카라마조프가의 형제들 1권` / `제1권` | 같음 | 1 |
| `카라마조프가의 형제들(1)` / `[1]` | 같음 | 1 |
| `토지 1부 1권` | 토지 | 1부 1권 → 가장 앞 권 |
| `상`·`중`·`하`, `상권`·`하권` | 같음 | 상 = 1, 중 = 2, 하 = 3 |

- 위 표의 표기 형태는 이번 사례와 흔한 표기를 모은 것입니다. 실제 카탈로그 집계는 2-1절 (dev 21, 2026-10-17)
- 카탈로그 묶기의 "권 숫자" 규칙(사이클 12 보완, `docs/reference-index.md` 4절의 `same-book-isbn.md` 5.7)과 같은 함수를 쓰려 했으나 쓸 수 없음 → 2-1절 끝 (dev 21 확인, 2026-10-17)

### 2-1. 실제 원인과 보충한 규칙 (dev 21, 2026-10-17) [확정]

- 「카라마조프가의 형제들」의 실제 원인은 권 표기가 아니라 **저자 표기**였습니다: 더클래식 「. 1」은 저자가 "도스토옙스키", 「. 2」는 "표도르 도스토옙스키". 2권에서 출발한 수집기가 저자까지 같은 판만 같은 세트로 보아 1권을 빠뜨림
- 그래서 **같은 출판사 + 같은 본제목의 권은 저자 표기가 달라도 같은 세트**로 넣음 → 1권(책 29171)이 골라지고 화면 이름의 "2"도 없어짐 (dev Java `ShownTitle`과 수집기에 똑같이)
- 권 표기 실제 집계 (카탈로그 책 1,331,194권, dev 21 집계 2026-10-17):

| 꼴 | 수 | 읽음 |
|---|---|---|
| `. N` | 40,816 | 예 |
| ` N` | 132,486 | 예 |
| `N권` | 18,883 | 예 |
| `제N권` | 1,898 | 예 |
| `(N)`·`[N]` | 18,255 | 예 (대괄호는 이번에 보충) |
| `(N권)` | 452 | 예 |
| 상·중·하 | 7,470 | 예 |
| `N부 N권` | 535 | 예 (이번에 보충) |
| 한글에 붙은 숫자 | 6,302 | 예 (이번에 보충) |
| `1 [한글판]` | 22,379 | 예 |
| `1 - 부제` | 14,754 | 예 (이번에 보충) |

- 카탈로그 묶기의 권 규칙(dev `SameTextKey.volumeMarks`)은 쓰지 않음: `collection` 모듈 안쪽이라 `picks`가 의존할 수 없고, 본제목과 권을 돌려주는 함수도 아님 (dev 21 확인). 대신 Java `ShownTitle`(`picks/internal/cache`)과 수집기 `read_title()`을 공용 시험 자료로 묶어 같게 둠 — 권 읽기를 바꾸면 **둘을 같이** 고치고 시험 자료에 경우를 더함
- 2권부터는 화면 이름에 숫자를 남김(「토지 2」), 끝 낱말 "세트"도 덜어 냄(「안나 카레니나 세트」 → 「안나 카레니나」) [확정] (사용자 승인, 2026-10-17, 회고 결정 #4) (dev 21이 정한 것, 화면 확인 뒤 그대로)

## 2-2. 수집기가 "같은 책 판"을 모으는 법 (dev 21 구현, 2026-10-17)

- 시작 판: 지금 고정 판 → 없으면 줄의 ISBN → 없으면 줄의 제목 + 첫 저자
- 같은 책 판: 시작 판과 `main_title_norm`이 같거나 권 번호를 덜어 낸 본제목이 같고, 저자(AUTHOR·UNKNOWN 역할의 `name_exact`)를 하나 이상 공유. 그 판과 같은 출판사·같은 본제목의 세트 권은 저자 표기가 달라도 넣음 (2-1절)
- 거르기: dev `scripts/crawl/lists/collector_words.tsv`의 `excluded_title`(영어원서·원서·어린이·초등·청소년·만화·그림책·논술·"공부가 되는"·"100분 고전"), `excluded_publisher`(어린이), `excluded_name`(번역AI). 부분 일치라 정상 판 제목에 우연히 그 낱말이 있으면 빠질 수 있음 → 4절 `manual`
- 거르고 남은 판이 없으면 **다시 고르지 않고** 고정 판을 비움 → 그 줄은 "못 맞춤"(흐린 표지, 누르면 희망도서 안내) [확정] (사용자 승인, 2026-10-17, 회고 결정 #2). 저자를 보지 않고 같은 본제목 판 전체에서 다시 고르던 dev 21 규칙은 없앰(다른 사람이 쓴 같은 제목 책에 맞출 수 있음, ADR-0124 "결과" 바뀜 줄). 바른 판이 카탈로그에 있으면 사람이 4절대로 `manual`로 고정. dev 할 일 `docs/cycles/21-recommended-books/to-dev-retro-fixes.md` (고치기 전 dev 코드에는 아직 남아 있음, 2026-10-17)
- 고르기: Java `BookChoice`와 같은 공식, 공용 시험 자료 dev `scripts/crawl/testdata/book_choice_cases.json`
- dev 쪽 문서: 규칙 파일 색인 `docs/maintenance/rules-index.md` 4절, 칸 설명 `scripts/crawl/lists/README.md`, 절차 `docs/maintenance/4-picks.md` 6절

## 3. "못 맞춤"이나 "다른 판"으로 끝내기 전에 할 확인

1. **권 표기를 바꿔 다시 찾기**: 2절 표의 표기로 제목을 다시 찾음 (예: `카라마조프가의 형제들. 1`)
2. **부제 떼고 찾기**: 제목의 `:`·` - ` 뒤 부제를 떼고 찾음 (같은 책이 부제만 다르게 들어 있는 경우가 많음 — 사서 목록에서도 대부분 부제만 달랐음)
3. **사람이 눈으로 확인**: 서비스 책 검색(`GET /api/v1/books?title=…`, 화면은 책 기준 검색)으로 제목 앞부분만 넣어 찾아봄
4. **오매칭 신호를 확인**: 제목의 핵심 낱말이 다르면 맞춘 것이 틀린 것입니다. 예: 서울대 48 「체호프 희곡선」이 「체호프 단편선」에 맞춰짐 → **희곡선 ≠ 단편선**. 장르 낱말(희곡·단편·시·선집·전집·평전), 권·부 번호, 번역자가 다르면 다른 책으로 봄

## 4. 사람이 판을 정해 고정하기 (`manual`) [확정] (결과 검토 #5)

- 수집기가 틀렸거나 못 맞춘 책은 사람이 바른 판을 찾아 목록 파일의 고정 판 칸(`pinned_isbn13` 등)에 적고, 고정한 주체를 `manual`로 둡니다. 수집기는 `manual` 줄을 덮어쓰지 않습니다 (사이클 21 handoff 342행)
- 바른 판이 우리 카탈로그에 없으면 "못 맞춤"으로 둡니다(억지로 비슷한 책에 맞추지 않음)
- 고정할 때 목록 파일 메모 칸에 근거를 남깁니다: 무엇을 보고 정했는지(해제집 원문 쪽, 서점 페이지, ISBN), 날짜

## 5. 판을 찾을 수 없는 책 [확정] (결과 검토 #3)

- 원문에 나온 이름의 책이 어디에도 없으면(예: 서울대 「제자백가 선독」) 제목 글자 표지로 두고, **해제집 원문 근거를 목록 파일 메모에 남깁니다**
